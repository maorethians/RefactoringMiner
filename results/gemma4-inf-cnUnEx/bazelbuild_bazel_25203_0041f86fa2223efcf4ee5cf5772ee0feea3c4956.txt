#RTP4Y: The implementation only updates the per-attempt `ExecutionInfo` with the exit code. However, several tests (e.g., #MFSFH, #A05B7, #GCPFY) assert that the aggregate `TestResultData` also contains this exit code. To ensure consistency between the attempt details and the final test result summary, you should also call `result.setExitCode(spawnResult.exitCode())` using the provided `TestResultData.Builder`.
