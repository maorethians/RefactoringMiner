#PDMSZ: In `checkDataStreamMigrationStatus`, the `migrationInfo` object is passed directly to the logger and used in string concatenation for an exception message. Since `SystemDataStreamMigrationInfo` does not override `toString()`, this will result in logging the object's memory address/hash rather than a useful identifier. Use `migrationInfo.getDataStreamName()` or `migrationInfo.getCurrentResourceName()` instead.
