#99QNZ: The use of leading slashes in `TEST_BASE_DIR.resolve("/config")`, `.resolve("/data1/")`, etc., will likely cause these paths to be treated as absolute paths on Unix-like systems. In Java, `Path.resolve(String other)` returns the `other` path directly if it is absolute. Consequently, instead of creating directories within the temporary base directory, the tests will attempt to use root-level directories (e.g., `/config`), which will likely fail due to permission issues or pollute the system root. These should be changed to relative paths (e.g., `.resolve("config")`).
