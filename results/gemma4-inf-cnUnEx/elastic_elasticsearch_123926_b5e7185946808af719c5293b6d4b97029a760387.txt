#C55PY: In the exception message, the `migrationInfo` object is concatenated directly into the string. Since `SystemDataStreamMigrationInfo` does not override `toString()`, this will result in a non-informative class name and hash code (e.g., `...SystemDataStreamMigrationInfo@12345`) being included in the error message. It should instead use `migrationInfo.getDataStreamName()` or `migrationInfo.getCurrentResourceName()`.

#9A3RH: The exception message contains a grammatical error: "response is not acknowledge" should be "response is not acknowledged".
