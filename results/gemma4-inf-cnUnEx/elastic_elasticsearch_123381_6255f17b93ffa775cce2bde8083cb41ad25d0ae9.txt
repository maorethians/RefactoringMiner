#58VK4, #56R62: The `asQuery` implementation is susceptible to a `NullPointerException`. If the foldable expression (`suffix` or `prefix`) evaluates to `null`, `BytesRefs.toString()` returns `null`, which is then passed directly into `QueryParser.escape()`. Since `translatable()` only verifies that the expression is foldable and not that it resolves to a non-null value, this path can be triggered. Consider adding a null check or ensuring that only non-null constants are considered translatable.

#58VK4, #56R62: The use of `FoldContext.small()` for static evaluation is marked with a TODO. While sufficient for simple literals, using a hardcoded "small" context may bypass the intended resource management or configuration provided by the broader optimizer/planner framework. This should be replaced with a proper `FoldContext` passed through the translation process.
