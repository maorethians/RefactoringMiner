#9J41C: The regular expressions used for boundaries (`BEFORE_REGEX` and `AFTER_REGEX`) use capturing groups that consume the matching characters (whitespace or commas). Because these characters are consumed, if two tokens to be replaced appear consecutively separated by a single boundary character (e.g., `"LP LP"`), only the first token will be matched and replaced. To avoid this, consider using zero-width lookarounds: `(?<=^|[\\s,])` for the prefix and `(?=[\\s,]|$)` for the suffix.
