#NRBJJ, #4GXKG, #EHZJ9, #QV4Z1: The `writeTo` methods in these classes are updated to write the actual `source()` instead of `Source.EMPTY`, but they lack the `TransportVersion` check used in other functions (e.g., `#QHVZG`). 
Since `Source.EMPTY.writeTo(out)` always writes a boolean `false`, and `source().writeTo(out)` can write `true` followed by additional data, this change alters the wire format. Without a version gate using `TransportVersions.ESQL_SERIALIZE_SOURCE_FUNCTIONS_WARNINGS`, this will cause serialization mismatches and potential stream corruption when communicating between nodes of different versions.
