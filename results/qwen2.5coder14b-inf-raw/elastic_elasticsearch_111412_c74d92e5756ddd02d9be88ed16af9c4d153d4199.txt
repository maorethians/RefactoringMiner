#MJKRB, #66E9Z: The default value for `enrich.cache.size` is set to `1%` of the JVM's configured max heap size. This is a reasonable default, but it should be clearly documented in the code.
The logic for parsing the `enrich.cache.size` setting value should be more robust. Currently, it only checks if the value ends with `%`, `b`, or `B`. It should also handle cases where the value is a plain number without any unit (e.g., `1000`).
The `FlatNumberOrByteSizeValue` class should have a method to convert its value to a human-readable string for logging and debugging purposes.
