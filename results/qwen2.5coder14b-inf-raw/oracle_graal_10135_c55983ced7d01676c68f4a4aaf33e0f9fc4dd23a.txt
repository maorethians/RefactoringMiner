#5V1ZM, #6QH8K: The method `getCompilationActivityMode` in both `TruffleCompilerRuntime.java` and `HotSpotTruffleRuntime.java` returns a default value of `RUN_COMPILATION` if an exception occurs or if the method handle is not available. This could lead to unexpected behavior if the host VM's compilation activity mode is actually `STOP_COMPILATION` or `SHUTDOWN_COMPILATION`. It would be better to log this error and possibly throw a more descriptive exception.
