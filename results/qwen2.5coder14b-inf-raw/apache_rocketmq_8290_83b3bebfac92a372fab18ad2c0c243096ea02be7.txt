#VHPYF, #SKH80: The initialization of `LOCAL_ADDRESS` has been moved from a static field initializer to a static block. This change introduces conditional logic that checks if the IP is internal or not before converting it to either IPv4 or IPv6 string. While this approach provides more flexibility, it also increases complexity and potential for errors.
1. **Code Complexity**: The static block now contains additional logic to determine whether the IP should be converted to IPv4 or IPv6. This adds complexity to the initialization process.
2. **Potential Issues**: If `UtilAll.getIP()` returns an invalid IP address, the code may throw a `NullPointerException` when trying to convert it to a string.
