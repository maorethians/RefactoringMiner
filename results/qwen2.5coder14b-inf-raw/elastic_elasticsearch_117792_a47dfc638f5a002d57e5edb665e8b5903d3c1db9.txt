#QJXYX, #DD7XH: The introduction of `RowStrideOnlyDocValuesBlockLoader` abstract class seems to be a good way to enforce certain behaviors for block loaders that only support row stride operations. However, the implementation of `supportsOrdinals()` and `ordinals(LeafReaderContext context)` methods in this abstract class throws an `UnsupportedOperationException`. This might lead to unexpected behavior if any subclass does not override these methods properly or if they are called unexpectedly.
