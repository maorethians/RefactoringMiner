#71MC6, #71MC7: The `XLMRobertaTestVocab.MULTILINGUAL_VOCAB` array contains a mix of characters from different languages, but it does not specify which language each token belongs to. This could lead to confusion when debugging or maintaining the test cases.
The `XLMRobertaTestVocab.EXPECTED_TOKENS` array contains expected token IDs for the multilingual texts. However, these token IDs are not commented or documented, making it difficult to understand why certain tokens are expected in specific positions without cross-referencing with the vocabulary file.
It would be beneficial to add comments or documentation that explains the purpose of each test case and the expected behavior of the tokenizer for different languages.
