#5W8KF: The `readNodesFrom` and `writeNodesTo` methods in `NodesFeaturesResponse` are not implemented correctly. They currently call `TransportAction.localOnly()`, which is not appropriate for reading or writing nodes to a stream. These methods should be properly implemented to read from and write the list of `NodeFeatures` objects.

#FHDP8: The `NodeFeaturesFixupListener` class has a method `getNodeFeatures` that uses reflection with `@SuppressForbidden`. This is generally discouraged unless absolutely necessary, as it can lead to maintenance issues and potential security risks. Consider if there's an alternative way to access the node features without using reflection.

#WD7TW: The test cases in `NodeFeaturesFixupListenerTests` are comprehensive, but they could benefit from additional edge case scenarios. For example, testing what happens when all nodes have features already set, or when some nodes fail to respond with their features.
