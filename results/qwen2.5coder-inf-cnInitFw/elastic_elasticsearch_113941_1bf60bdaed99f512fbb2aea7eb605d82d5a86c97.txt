#F4KMX, #1YM5G, #CE1K4: The change from using `VersionUtils.randomVersionBetween` to `VersionUtils.randomCompatibleVersion` might not cover all possible versions that are compatible with the previous version. The original method allowed specifying a range between the minimum compatibility version and the previous version, which could include more versions than just those compatible with the previous version. This change narrows down the range of versions used in testing, potentially reducing test coverage.
