#917KW, #C3XYV: The introduction of a new executor named `NODE_RESTARTER` with a maximum of 5 threads might lead to unexpected behavior if multiple node restart tasks are submitted concurrently. The original setup used a single-threaded executor for "client" activities, which suggests that the intention was to limit concurrent operations. Using up to 5 threads for node restarts could potentially overwhelm the system or cause race conditions if not managed properly.
