#K33S7, #B4JT9, #94Q6X: The method `handleAlreadyShuttingDownWorker()` has been removed, but its functionality is still needed when the worker is already shut down. The new implementation directly calls `shutdownNow()` and then waits for termination, which might not handle all scenarios correctly as the original code did. Specifically, it does not notify any waiting requests in the work queue if the worker was already shut down.

#B4JT9: The use of `awaitTermination(30L, TimeUnit.SECONDS)` introduces a fixed timeout value. This might be too short or too long depending on the context and workload. Consider making this configurable or handling it more dynamically based on the expected shutdown time.
