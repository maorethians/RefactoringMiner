#YNRQX, #8BMN3: The logic for patching JAR files has been moved from a standalone class to an implementation of `TransformAction`. However, there is a potential issue with the exception handling and resource management in the `patchJar` method. The current implementation throws a `RuntimeException` when an `IOException` occurs, which might not be the most appropriate way to handle such exceptions in a Gradle transform action. It would be better to log the error and rethrow it as a `GradleException` or another more specific exception that is suitable for Gradle build scripts.

#YNRQX: The condition `if (jarPatchers.isEmpty() == false)` seems unnecessary and can be simplified to `if (!jarPatchers.isEmpty())`. This change would make the code more readable and idiomatic in Java.
