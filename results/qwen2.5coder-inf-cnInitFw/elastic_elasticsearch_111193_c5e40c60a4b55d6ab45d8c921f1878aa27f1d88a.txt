#1TPMB, #5506R: The method `isPointGeometry` checks if the provided geometries array contains exactly one geometry that is an instance of `XYPoint`. However, the check for `geometry.type() != ShapeType.POINT` in the original code suggests that it was intended to verify if the geometry type is not a point. The new implementation using `isPointGeometry` effectively reverses this logic since `isPointGeometry` returns true only when there is exactly one `XYPoint`. This change might lead to incorrect behavior if the intention was to ensure the geometry is not a point.
