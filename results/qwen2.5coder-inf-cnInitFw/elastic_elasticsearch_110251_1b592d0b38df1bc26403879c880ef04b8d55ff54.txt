#N4HG7, #VJM77: The validation logic for index sort with nested fields has been updated to check if any field specified in `index.sort.field` is under a nested object. However, the test case `testIndexSortWithNestedFields` needs to be adjusted to reflect this change. The original test expected an exception when any nested field was present, but now it should only throw an exception if a specific field in the index sort is under a nested object. Additionally, the assertion for the number of documents and parent-child relationship should be part of a separate test case that verifies the correct behavior when nested fields are present without triggering an exception. The current test mixes validation logic testing with document parsing and structure verification.
