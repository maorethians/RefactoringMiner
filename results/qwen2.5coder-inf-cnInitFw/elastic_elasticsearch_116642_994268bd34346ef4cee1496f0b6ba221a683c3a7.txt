#R7CT8, #93R0T: The change in `checkFullTextQueryFunctions` now disallows `MATCH` functions after both `LIMIT` and `AGGREGATE`. This is a logical extension of the existing rule to cover another command type that should not precede full-text query functions. However, it's important to ensure that this new condition does not inadvertently block valid use cases or introduce any unintended side effects.
The test case added in `testMatchFunctionNotAllowedAfterCommands` correctly reflects the new logic by checking that a `MATCH` function cannot be used after an `AGGREGATE` command. This is good coverage for the change made.
