#DT641, #Y2B46, #RC351, #Z0ZEP: The introduction of the `ENABLE_STACK_OVERFLOW_AVOIDANCE` setting is marked as deprecated and node-scoped. However, there are no checks or warnings in place to enforce this deprecation at runtime. While the tests check for deprecation warnings, it would be beneficial to add a mechanism within the code to log a warning when this setting is used.

#90ZWA: The change in `onConnectionClosed` method removes the explicit fork to a different thread for handling exceptions. This change assumes that all handlers will handle stack overflows themselves. However, there should be documentation or comments explaining why this change was made and what assumptions are being relied upon. Additionally, it might be prudent to add a configuration check to ensure that handlers do not use `DIRECT_EXECUTOR_SERVICE` if the setting is disabled.

#RC351: The test method `testOnConnetionCloseStackOverflowAvoidance` has a typo in its name (`Connetion` instead of `Connection`). This should be corrected for clarity and consistency.
