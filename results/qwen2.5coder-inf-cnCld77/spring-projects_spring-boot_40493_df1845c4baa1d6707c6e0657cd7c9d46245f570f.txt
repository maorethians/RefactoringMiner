#9NA3F, #97B54, #ZMKR4, #88BH9: The `escapeJson` method is introduced to escape JSON strings, but it does not handle all possible characters that need escaping in JSON. According to the JSON specification, there are other control characters (U+0000 through U+001F) that should be escaped. Additionally, the current implementation does not handle Unicode characters properly.

#9NA3F: The `escapeJson` method could benefit from using a well-tested library like Jackson or Gson for JSON escaping to ensure all edge cases are handled correctly and improve maintainability.
