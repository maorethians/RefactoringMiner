#MFSFH, #A05B7, #BDJF8, #Y0328, #FXVJ5, #GCPFY, #VN9JW, #QJNY0: The added assertions for `getExitCode()` should be consistent with the expected exit codes based on the `SpawnResult` status. However, in some cases, the exit code is assumed to be 0 even when the test failed or timed out. This might not align with the actual behavior of `exitCode()` as described in the Javadoc of `SpawnResult`. For example, if a test fails with a non-zero exit code, the assertion should reflect that.
