#1TPMB, #5506R: The method `isPointGeometry` checks if the provided geometries array contains exactly one geometry that is an instance of `XYPoint`. However, this check does not align with the logic in `pointShapeQuery` where it uses `LuceneGeometriesUtils.toXYGeometry(geometry, t -> {})` to convert the `geometry` into `XYGeometry[]`. This conversion might result in multiple geometries even if the original geometry is a point. Therefore, the current implementation of `isPointGeometry` might not accurately reflect whether the original geometry was a single point.
