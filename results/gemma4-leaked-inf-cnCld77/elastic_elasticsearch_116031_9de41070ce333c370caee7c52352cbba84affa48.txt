#HPR4Q: The method `isRolloverOnWrite` calls `metadata.dataStreams().get(indexRequest.index())` without checking if `indexRequest.index()` is null. Since `resolvePipelinesFromIndexTemplates` (which this logic partially replaces/augments) explicitly handles the case where the index name is null, it is likely that `indexRequest.index()` can be null here. This will lead to a `NullPointerException` when accessing the metadata map.
