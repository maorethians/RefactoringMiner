#6V64K: The Javadoc states that the default size is `NettyRuntime.availableProcessors()` and provides a memory usage calculation based on this value. However, the code now caps the capacity at 2 via `Math.min(2, ...)`. This creates a discrepancy between the documentation and the implementation, and it effectively nullifies the system property `io.netty.allocator.centralQueueCapacity` for any value greater than 2.
