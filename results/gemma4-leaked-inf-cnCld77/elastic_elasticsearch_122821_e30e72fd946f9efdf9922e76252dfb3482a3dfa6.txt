#NRBJJ, #4GXKG, #EHZJ9, #QV4Z1: The `writeTo` methods in these classes are updated to serialize the actual `source()` instead of `Source.EMPTY`, but they lack the transport version check (`onOrAfter(TransportVersions.ESQL_SERIALIZE_SOURCE_FUNCTIONS_WARNINGS)`) used in other functions (e.g., `#QHVZG`, `#A9C2C`). 
Without this check, nodes running newer versions of the code will serialize non-empty source data to nodes running older versions. Since older versions expect these functions to only write an empty source (a single boolean `false`), they will encounter a stream misalignment when reading the additional source data, leading to deserialization failures. These should be wrapped in the same version guard used elsewhere in this chapter.
