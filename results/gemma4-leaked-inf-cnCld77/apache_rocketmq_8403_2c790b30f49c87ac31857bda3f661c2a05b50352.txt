#SWRTJ: In `appendMessageUsingFileChannel`, if an exception occurs during `fileChannel.write`, the error is logged but `WROTE_POSITION_UPDATER.addAndGet` is still executed. This advances the write position despite the failure, which will result in data corruption (holes) in the file. The position update should only occur if the write operation completes successfully.

#SWRTJ: The sequence of calling `this.fileChannel.position(currentPos)` followed by `this.fileChannel.write(...)` is not atomic and depends on the shared state of the `FileChannel`'s internal position pointer. To improve thread safety and performance, use the absolute write method: `this.fileChannel.write(ByteBuffer src, long position)`.
