#M14K0, #0P94N: The constant `UPGRADED_TO_VERSION` is declared as `private` in `TransportGetFeatureUpgradeStatusAction`, but it is accessed by `SystemIndices` to define `UPGRADED_INDEX_SUFFIX`. This will result in a compilation error.

#M14K0: The versioning constants (`NO_UPGRADE_REQUIRED_VERSION`, `NO_UPGRADE_REQUIRED_INDEX_VERSION`, and `UPGRADED_TO_VERSION`) are placed within a Transport Action class. These are global configuration values for system index migration and should be moved to a more appropriate location, such as `SystemIndices` or a dedicated versioning utility class, to avoid an architectural inversion where core indices logic depends on the action layer.
