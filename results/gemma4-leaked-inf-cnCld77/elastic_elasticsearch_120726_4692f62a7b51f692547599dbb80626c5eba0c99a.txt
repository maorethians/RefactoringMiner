#0ZM3M: The `wrapSingleValueQuery` method is called within `getQuery(int position)`, meaning it executes for every single position in the input block. This method performs a query rewrite that iterates through all leaves of the index reader to verify if the field contains only single values. Since this property is constant for the entire field within the current search context, performing this check per position introduces significant performance overhead (O(N * Leaves), where N is the number of positions). This logic should be computed once per `QueryList` instance and cached.
