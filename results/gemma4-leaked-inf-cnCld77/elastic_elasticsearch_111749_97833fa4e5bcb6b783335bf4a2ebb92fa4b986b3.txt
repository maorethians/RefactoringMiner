#AYH23: In `processDoubles`, `processInts`, and `processLongs`, there are two critical logic errors when `valuesBlock.mvSortedAscending()` is true:
1. **Incorrect Indexing**: The code uses absolute indices `0` and `valueCount - 1` (e.g., `valuesBlock.getDouble(0)`) instead of offsetting them by the position's start index (`firstValueIndex`). This will result in incorrect values being retrieved for all positions except the first one.
2. **Double Appending**: The sorted path is not wrapped in an `if/else` block or followed by a `return`. Consequently, if the data is already sorted, the function appends the result to the builder and then proceeds to execute the non-sorted path (allocating an array, sorting it, and appending the result again), leading to duplicate values in the output.
