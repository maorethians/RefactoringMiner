#0KTA1: The implementation changes the lookup from `context.rootDoc().getFields()` to `context.doc().getByKey(...)`. In `DocumentParserContext`, `doc()` returns the current document being parsed (which may be a nested sub-document), whereas `rootDoc()` always refers to the top-level document. Since `@timestamp` is a root-level field, using `doc()` instead of `rootDoc()` can cause validation to fail or behave inconsistently when processing documents containing nested structures. This inconsistency is further highlighted by diff #ZV025, which correctly continues to use `rootDoc()` for the same purpose.
