#KY4HM: The method `match(Object value, String pattern, Boolean caseInsensitive)` compiles the regex pattern on every invocation via `Pattern.compile`. Since this replaces the `RegexProcessor` which cached the compiled `Pattern`, calling this method during row-by-row evaluation will introduce significant performance overhead.
