#99QNZ: The use of `TEST_BASE_DIR.resolve("/config")` (and similar calls for `/data1/`, `/data2/`, and `/temp`) is likely incorrect. In Java's `Path.resolve(String other)`, if the `other` path is absolute, the base path (`this`) is ignored and the absolute path is returned. Since these strings start with a leading slash, they are treated as absolute paths on Unix-like systems, meaning `TEST_BASE_DIR` is ignored and the paths resolve to the system root. To correctly append these directories to the temporary base directory, the leading slashes should be removed (e.g., `.resolve("config")`).
