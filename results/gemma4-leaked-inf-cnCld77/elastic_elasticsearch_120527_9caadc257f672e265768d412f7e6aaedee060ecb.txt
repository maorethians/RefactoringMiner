#33VQT, #ENYZX, #CG8GE, #DMX0F: The `PlanningMetrics.command()` method throws a `QlIllegalArgumentException` if the provided `MetricsAware` object returns a null metric name. However, `UnresolvedRelation` (which implements `MetricsAware`) is explicitly instantiated with a `null` command name in several places (e.g., within `visitMetricsCommand` and `visitJoinCommand`), accompanied by comments stating these should not be counted in metrics. This will result in a runtime exception during parsing for those specific query constructs instead of simply skipping the metric collection as intended.
