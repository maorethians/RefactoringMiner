#K9T48: In the `dataStreamMigrationFailed` method, the exception message concatenates the `migrationInfo` object directly: `"error occurred while reindexing data stream [" + migrationInfo + "]"`. This will result in the object's `toString()` representation (likely a memory address or class name) being printed instead of the actual data stream name. It should use `migrationInfo.getDataStreamName()` or `migrationInfo.getCurrentResourceName()`.
