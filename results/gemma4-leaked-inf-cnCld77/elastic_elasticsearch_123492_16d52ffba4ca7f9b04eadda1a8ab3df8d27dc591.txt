#QJ3B4: Changing the registry passed to `ImplicitCasting.cast` from `context.functionRegistry()` to `context.functionRegistry().snapshotRegistry()` may cause a regression in implicit casting for standard functions. Since the string literal conversion mappings were moved from a static map to an instance field (`dataTypesForStringLiteralConversions`), passing the snapshot-specific registry means that only snapshot functions will be resolved during casting, as the snapshot registry's map is populated only with snapshot functions (see #1CQEX).
