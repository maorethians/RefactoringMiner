#1WBMD: The logic for `FN_REVERSE_GRAPHEME_CLUSTERS` is inverted. The accompanying comment states that this feature is "not supported on JDK versions less than 20", but the code sets `enabled` to `true` when `Runtime.version().feature() < 20`. It should be changed to `>= 20`.

#2AJFA: The test logic has been weakened. The error message indicates that the test is verifying if a capability is included in the "enabled list", but the code now checks against `EsqlCapabilities.capabilities(true)`, which returns all known capabilities regardless of whether they are enabled. This should likely remain as `EsqlCapabilities.CAPABILITIES` (or `capabilities(false)`) to ensure the feature is actually enabled on snapshot builds.
