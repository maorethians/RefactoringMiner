#21N6P, #CRDNJ: The changes implement a logic update to allow index templates that define data streams to be applied to hidden indices, even if they use a "match all" pattern (e.g., `*`). This is necessary because the backing indices for data streams are hidden by default.
The modification in `#21N6P` correctly bypasses the restriction that prevents "match all" templates from being applied to hidden indices when a `DataStreamTemplate` is present. The accompanying test case in `#CRDNJ` verifies both the standard (non-hidden) and the new (hidden) lookup scenarios for such templates.
