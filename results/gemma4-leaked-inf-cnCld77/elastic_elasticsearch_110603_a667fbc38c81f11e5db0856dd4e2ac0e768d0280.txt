#0KTA1, #QFEZC, #ZV025: There is an inconsistency in the use of `context.doc()` versus `context.rootDoc()` when accessing the timestamp metadata fields:
- `#0KTA1` changed from using `rootDoc()` to `doc()`.
- `#QFEZC` uses `doc()` to store the metadata.
- `#ZV025` continues to use `rootDoc()` to retrieve the metadata.
Since `@timestamp` is a root-level field for the record, these should consistently use `context.rootDoc()`. Using `context.doc()` may lead to incorrect behavior or missing fields if the parsing context is currently processing a nested document.
