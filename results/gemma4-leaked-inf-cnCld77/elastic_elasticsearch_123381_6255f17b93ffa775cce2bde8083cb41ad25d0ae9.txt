#H7ZRZ, #68BWW: The current implementation does not handle cases where the folded `suffix` or `prefix` evaluates to `null`. According to the function specifications, these functions should return `null` if any argument is `null`. However, the current logic would proceed to create a `WildcardQuery` using the string `"null"` (e.g., `"*null"` or `"null*"`), which is functionally incorrect. The code should ensure the folded value is non-null before constructing the query.

#H7ZRZ, #68BWW: Both functions use `FoldContext.small()` to evaluate constants during translation. As indicated by the accompanying TODOs and the documentation for `FoldContext.small()`, this approach is primarily intended for tests and serves as a signal that a proper shared `FoldContext` should be provided instead of using a temporary small one in production code.
