#KEYHF: The use of `.anyMatch(Block::areAllValuesNull)` to determine `allValuesNull` appears logically incorrect. If a `Page` contains multiple blocks (columns), this flag will be set to `true` if *any* single block is entirely null, even if other blocks in the same page contain valid data. To correctly identify if all values across the entire page are null, `.allMatch(Block::areAllValuesNull)` should be used instead.
