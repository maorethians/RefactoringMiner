#1G21S: The logic in the static initializer is flawed and may cause a crash or incorrect values:
1. **Potential Crash**: `UtilAll.isInternalIP(ip)` throws a `RuntimeException` if the input byte array length is not 4. If `UtilAll.getIP()` returns an IPv6 address (16 bytes), this will trigger an `ExceptionInInitializerError`, preventing the class from being loaded.
2. **Incorrect Mapping**: If the IP is a public IPv4 address, `isInternalIP` returns `false`. The code then calls `UtilAll.ipToIPv6Str(ip)`, which returns `null` for any array that is not exactly 16 bytes long. Consequently, `LOCAL_ADDRESS` will be `null` for all public IPv4 addresses.

#F14HW, #2GFD4: There is a potential `NullPointerException` regression in the local address retrieval flow. `NetworkUtil.getLocalInetAddress()` can return `null` if an exception occurs during its execution. This `null` value is passed directly to `normalizeHostAddress(localHost)`, which will throw a `NullPointerException` when it attempts to call `localHost.getHostAddress()`.
