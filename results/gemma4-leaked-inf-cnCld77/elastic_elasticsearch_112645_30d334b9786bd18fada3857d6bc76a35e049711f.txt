#R6MVQ: The use of `.toString()` on `e.getValue()` and elements of `listValue` is susceptible to `NullPointerException` if the source map contains null values. This creates an inconsistency with the XContent parsing path in `#KJZ2M`, which explicitly skips `VALUE_NULL` tokens. Consider using `String.valueOf()` or adding a null check to ensure that null routing values are handled gracefully (e.g., ignored) rather than causing a crash.
