Since these blocks store data for multiple positions, you must add `firstValueIndex` to every index used in a `getDouble`, `getInt`, or `getLong` call to avoid accessing data from the wrong row or triggering an `ArrayIndexOutOfBoundsException`.

if (percentile == 0) {

} else {
