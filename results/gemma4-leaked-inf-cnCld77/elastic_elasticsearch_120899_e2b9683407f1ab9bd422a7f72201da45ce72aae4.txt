#0ZJ70: The method `RemoteClusterAware.isRemoteIndexName` is called using the `pattern` variable, which contains the `"FROM "` prefix added by the `from()` helper. Since `isRemoteIndexName` expects a raw index expression rather than an ESQL clause, this can lead to incorrect logic; for example, an invalid index name starting with a colon (which should return `false`) would return `true` if prefixed with `"FROM "`. The check should be performed on the index name itself before it is wrapped in the `from()` helper.
