#V4JK1: In `replaceChangeCase`, the variable `foldedRight` is assigned the result of `BytesRefs.toString(bc.right().fold())`, which can return `null`. Subsequently, `changeCase.caseType().matchesCase(foldedRight)` is called, and the implementations of `matchesCase` for both `UPPER` and `LOWER` call `.codePoints()` on the input string. This will trigger a `NullPointerException` if the right-hand side of the comparison folds to `null`. A null check should be added before calling `matchesCase`.
