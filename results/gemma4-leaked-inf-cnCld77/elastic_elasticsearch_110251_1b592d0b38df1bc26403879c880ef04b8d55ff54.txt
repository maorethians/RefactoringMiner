#N4HG7: The check `field.startsWith(nestedObjectMapper.fullPath())` is prone to false positives. If a sort field shares a prefix with a nested object's path (e.g., sort field `username` and nested object `user`), this logic will incorrectly throw an `IllegalArgumentException`. 
To ensure the field is actually contained within the nested object, you should check if the field equals the path or starts with the path followed by the delimiter:
`field.equals(nestedObjectMapper.fullPath()) || field.startsWith(nestedObjectMapper.fullPath() + ".")`
