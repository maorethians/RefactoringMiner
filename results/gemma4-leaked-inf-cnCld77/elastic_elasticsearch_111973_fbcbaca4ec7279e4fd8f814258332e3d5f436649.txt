#9929M: The error message construction is inconsistent regarding the order of indices. When the number of indices is greater than 3, they are explicitly sorted before being appended; however, when there are 3 or fewer indices, the set is appended directly, leaving the order dependent on the `Set` implementation (e.g., non-deterministic for `HashSet`). To ensure consistent and deterministic error messages across all cases, the indices should be sorted regardless of the set size.
