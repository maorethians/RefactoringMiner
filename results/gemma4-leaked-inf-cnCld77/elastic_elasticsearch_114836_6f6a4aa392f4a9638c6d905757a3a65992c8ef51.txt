#1VQ1G: In `distancePointDocValuesAndSource`, there is a redundant calculation when both `leftCount` and `rightCount` are equal to 1. The distance is first calculated in the `if (leftCount == 1 && rightCount == 1)` block, but then it is immediately recalculated inside the nested loops because an `else` block is missing. This differs from the implementation of `distanceSourceAndSource`, which correctly uses an `else` to avoid this duplication.
