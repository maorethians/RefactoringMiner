#N9VGB: In `ordinalAttributes()`, there is a potential `ClassCastException` when casting the grouping expression `g` to `Attribute`. While the method checks that the grouping is not a `Categorize` expression, it does not verify that the expression is actually an instance of `Attribute` before performing the cast. If a complex expression (e.g., an arithmetic operation) is used for grouping, this will cause a runtime crash. It is recommended to use a pattern match or `instanceof` check:
```java
groupings.forEach(g -> {
    if (leaves.contains(g) == false && g instanceof Attribute attr) {
        orginalAttributs.add(attr);
    }
});
```
