#T2D5M: The cell for ingest time has been changed from using `TimeValue.timeValueMillis()` to passing the raw `long` value from `ingestTimeInMillis()`. Since `Table.addCell(Object value)` typically relies on the object type for formatting, this will likely change the output in the CAT API (e.g., removing duration suffixes like "ms"), which may be a regression in user-facing formatting.
