#K8412: In the `dataStreamMigrationFailed` method, the error message for the `ElasticsearchException` uses the `migrationInfo` object directly in string concatenation: `"error occurred while reindexing data stream [" + migrationInfo + "]"`. This will result in the output of the object's `.toString()` method rather than a useful identifier. It should be changed to use `migrationInfo.getDataStreamName()`.
