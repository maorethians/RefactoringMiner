#97B54: The `escapeJson` method is only applied to map values. If any keys in the authentication parameters contain special characters (e.g., double quotes or backslashes), the resulting JSON string will be malformed. Keys should also be escaped.

#9NA3F, #97B54: Implementing manual JSON escaping via string replacement is error-prone and incomplete; for example, it does not handle all required control characters (U+0000 through U+001F) as specified in RFC 8259. Since this is a Spring Boot project, using a standard library like Jackson's `ObjectMapper` would be more robust, maintainable, and ensure full compliance with the JSON specification.

#ZMKR4, #88BH9: The tests are fragile because they use `Map.of(...)`, which does not guarantee iteration order. Comparing the resulting JSON string against a hardcoded expected string will lead to intermittent test failures when the map entries are ordered differently.
