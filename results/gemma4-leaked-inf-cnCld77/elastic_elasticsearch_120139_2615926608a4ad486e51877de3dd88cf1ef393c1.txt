#BXEH1, #0FW1C, #26M5T, #9N9TW, #6RRKB: In the `perPosition` method of the lazy evaluators (e.g., `CoalesceBooleanLazyEvaluator`), the code uses a range-based copy for the first block:
`result.copyFrom(lastFullBlock, p, p + 1);`
Since this PR introduces optimized single-position copy methods in all specific block builders (e.g., `BooleanBlockBuilder#copyFrom(BooleanBlock, int)`), these should be used instead of range copies for a single position to avoid unnecessary overhead.

#WVP9V: The implementation of `CaseEagerEvaluator#eval` contains a comment explicitly noting that using range-based copies (`builder.copyFrom(lhs, p, p + 1)`) is "quite slow compared to using the single valued copy". Given that this PR provides exactly those optimized single-valued copy methods in the block builders, this logic should be updated to utilize them. Note that since `builder` is a generic `Block.Builder`, this would require either casting to the specific builder type or refactoring the evaluator into type-specific implementations similar to how `Coalesce` was handled in this chapter.
