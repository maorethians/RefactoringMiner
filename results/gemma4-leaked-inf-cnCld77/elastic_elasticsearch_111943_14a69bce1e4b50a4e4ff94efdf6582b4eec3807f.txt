By removing the conditional check on `isFragment`, the code now ensures that fragments (which are often elements within a nested array) always produce an object structure `{ ... }`, even if they contain no fields.

#K7P7D: In `#K7P7D` (multiple children), the explicit `startObject`/`endObject` calls are removed because the loop's `write()` calls now handle this internally. This results in a sequence of objects `{...}, {...}`, which is correct when wrapped in an array by the caller.

#125DJ: The addition of `testSyntheticNestedWithEmptyObject` (`#125DJ`) specifically targets the edge case where a nested object has no values, verifying that it produces `{}` instead of being omitted.

#SWA5V: In `#SWA5V`, the restriction on nested fields is now correctly tied to whether sub-objects are disabled, removing a previous workaround that was necessitated by the "empty object" bug.
