#TZZGT: The check `field.startsWith(nestedObjectMapper.fullPath())` is prone to false positives. If a sort field name starts with the same characters as a nested object's path but is not actually contained within it (e.g., sort field `user_name` and nested object `user`), this will incorrectly trigger an `IllegalArgumentException`. 
To correctly identify if a field is under a nested object, you should check if the field is exactly equal to the path or starts with the path followed by the delimiter (e.g., `field.equals(path) || field.startsWith(path + ".")`).
