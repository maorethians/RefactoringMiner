#E60YX, #1HQT3: In `#E60YX`, when building the in-memory stash, `stashContentsMap.get(PathFragment.EMPTY_FRAGMENT)` is used to populate the root entry of the main stash. If no inputs or outputs were processed (or all had null values), this will return `null`, resulting in a mapping from the workspace name to `null` in the `main` stash contents.
Subsequently, in `#1HQT3`, `cleanRecursivelyWithInMemoryStashes` is called using the value of these directory entries. Since that method begins with `Preconditions.checkNotNull(stashContents)`, it will throw a `NullPointerException` (via the precondition) if the workspace entry was mapped to `null`.
Consider adding a null check or ensuring a default empty `StashContents` object is used instead of `null` when populating the main stash.
