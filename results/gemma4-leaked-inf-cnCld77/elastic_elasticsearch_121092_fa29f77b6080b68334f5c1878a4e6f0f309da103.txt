#91T4G: The logic in `newSnapshot` is inconsistent with the changes in `#1N64B` and `#71WX8`. While those diffs ensure that operations are treated as synthetic when inference fields are present, `newSnapshot` only checks `isRecoverySourceSyntheticEnabled()`. 
If `isRecoverySourceSyntheticEnabled()` is false but `inferenceFields()` is not empty, `#1N64B` will trigger a call to `synthesizeSource`, which in turn calls `newSnapshot`. However, `newSnapshot` will return a `LuceneChangesSnapshot` instead of a `LuceneSyntheticSourceChangesSnapshot`, effectively bypassing the synthesis required for inference fields. The condition in `newSnapshot` should be updated to include the check for non-empty inference fields via `engineConfig.getMapperService().mappingLookup().inferenceFields().isEmpty() == false`.
