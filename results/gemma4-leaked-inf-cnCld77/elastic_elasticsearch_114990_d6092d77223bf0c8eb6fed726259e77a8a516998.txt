#FT0CW: The logic for rewriting `TermsQueryBuilder` is incorrect. A terms query should match if *any* of the provided values match. However, the current implementation returns a `MatchNoneQueryBuilder` as soon as it encounters the first value that does not match (`MatchNoDocsQuery`), without checking the remaining values in the list. It should only return `MatchNoneQueryBuilder` if all values in the loop result in `MatchNoDocsQuery`.
