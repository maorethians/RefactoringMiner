#DQ92A: In `#DQ92A`, the addition of a second `try-catch` block in `TDigestState.read` is a correct improvement. Since the initial state allocation (the first `try-catch`) registers memory with the circuit breaker, any subsequent failure during the reading of centroids from the stream would have resulted in a memory leak. Wrapping the data population phase and calling `Releasables.close(state)` on exception ensures that resources are properly released if the input stream is corrupted or interrupted.
