#1SWTS: The call to `Uid.encodeId(context.id())` is performed inside a loop over all non-root documents. Since the root document's ID is constant for all children, this value should be calculated once outside the loop and reused to avoid redundant encoding operations.

#HCC2E, #1SWTS: There is a potential logic error that could lead to duplicate `_id` fields in child documents for time-series indices. 
In `#HCC2E`, if an explicit ID is provided (`idField != null`), the `_id` field is added to the child document immediately. However, `#1SWTS` unconditionally iterates over all non-root documents and adds the `_id` field again during `postParse`. For time-series indices where an explicit ID is present, this results in the same identifier being added twice to every nested document.
