#54YXB: The logic introduces a `TreeMap` to ensure that fields are written in lexicographical order when `ignoredValues` is present. However, if `ignoredValues` is null or empty, the code falls back to iterating over the `fields` list directly:
```java
} else {
    for (SourceLoader.SyntheticFieldLoader field : fields) {
        if (field.hasValue()) {
            field.write(b);
        }
    }
}
```
If the `fields` list is not guaranteed to be sorted, this results in inconsistent output behavior: documents with ignored values will have their synthetic source fields sorted, while documents without them will follow the internal list order. To ensure deterministic reconstruction of the synthetic source, the sorting logic should be applied consistently regardless of whether `ignoredValues` contains elements.
