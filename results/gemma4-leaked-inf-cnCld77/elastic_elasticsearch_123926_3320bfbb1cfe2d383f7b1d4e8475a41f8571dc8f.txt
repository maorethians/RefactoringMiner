#ZS2ET: In `checkDataStreamMigrationStatus`, the logger and the `ElasticsearchException` use the `migrationInfo` object directly in their messages:
- `logger.error("error occurred while reindexing data stream [{}], failures [{}]", migrationInfo, ...)`
- `new ElasticsearchException("error occurred while reindexing data stream [" + migrationInfo + "]")`
Since `SystemDataStreamMigrationInfo` does not override `toString()`, this will result in logs and error messages containing the object's memory address (e.g., `... [org.elasticsearch.system_indices.task.SystemDataStreamMigrationInfo@...]`) instead of a useful identifier. Use `migrationInfo.getDataStreamName()` or `migrationInfo.getCurrentResourceName()` instead.
