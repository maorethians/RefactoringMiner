#HPR4Q: In `isRolloverOnWrite`, there is no check to ensure `indexRequest.index()` is not null before calling `metadata.dataStreams().get(...)`. If the index name is null, this may trigger a `NullPointerException` depending on the map implementation used in `Metadata`. Given that other pipeline resolution methods (e.g., `resolvePipelinesFromIndexTemplates`) explicitly handle null indices, a similar guard should be added here.

#HPR4Q: In `setPipelineOnRequest`, the block:
```java
if (requestPipeline != null) {
    indexRequest.setPipeline(requestPipeline);
}
```
is redundant as it sets the pipeline to the value it already holds. This can be simplified by only calling `setPipeline` in the `else` branch.
