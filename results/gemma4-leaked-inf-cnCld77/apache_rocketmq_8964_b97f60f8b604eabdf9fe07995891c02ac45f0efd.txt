#FC55Q: The exception message `"Broker[" + brokerName + "] master node does not exist"` may be slightly misleading when `brokerName` is `null`, as the code falls back to using `msg.getStoreHost()` to resolve the address. In such a case, the error would report `Broker[null]`, which doesn't clearly indicate that the failure occurred while attempting to resolve the address from the message's store host. Consider a more generic message or one that distinguishes between the two resolution paths.
