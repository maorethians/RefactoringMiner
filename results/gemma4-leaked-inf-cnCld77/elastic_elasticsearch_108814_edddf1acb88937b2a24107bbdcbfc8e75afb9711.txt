#XREA3: The update to `lastSeenClusterState` for cluster state diffs has been changed from a conditional update (`compareAndSet`) to an unconditional update (`set`). In the original implementation, `compareAndSet` ensured that the local state reference was only updated if it hadn't been advanced by a concurrent request. Since these requests are now processed asynchronously via the generic thread pool before being queued in the coordination pool, there is a risk that tasks could be submitted or executed out of order relative to their version numbers, potentially leaving `lastSeenClusterState` in an inconsistent state (e.g., reverting to an older version).
