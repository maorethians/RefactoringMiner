#R7CT8, #93R0T: The change in `checkFullTextQueryFunctions` now prevents `MATCH` functions from being used after `Aggregate` commands, which is a logical extension of the existing check for `Limit`. However, this change should be accompanied by an update to the error message to reflect the new condition. The test case added in `testMatchFunctionNotAllowedAfterCommands` correctly checks for this new condition but uses the same error message as before, which might confuse users or developers reading the tests.
