#EEDYT, #H2DC3, #EKTX5: The method `sendChildRequest` is introduced as a protected method in `AbstractLookupService`. This change requires subclasses to implement or override this method if they need different behavior. However, the implementation in `EnrichLookupService` simply calls the superclass method after stashing the thread context. This suggests that the method could be made final in `AbstractLookupService` and the thread context handling could be moved there to avoid unnecessary overrides.

#965QJ, #VH5BC: The test cases for `testLookupJoinIndexAllowed` have been modified to expect exceptions when aliases are used in a LOOKUP JOIN. However, the two test cases that were expecting successful responses with aliases now both throw the same exception and assert the same error message. This redundancy can be reduced by combining these tests into one, as they are testing the same condition.
