#F6GD5, #GYWFX: The change in `skipExpression` now includes `Case` expressions, which is a logical extension given the new test cases added for `IsNotNull` on `Case`. However, the test case `testIsNotNullOnCase` checks the children of the `Case` expression using `Expressions.names`, which will return the string representations of the conditions and results rather than the actual attribute names. This might not be what is intended if the goal is to verify that the attributes involved in the `Case` expression are correctly identified.
