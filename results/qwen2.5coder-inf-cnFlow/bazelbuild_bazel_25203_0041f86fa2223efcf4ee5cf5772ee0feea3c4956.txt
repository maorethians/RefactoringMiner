#RTP4Y, #MFSFH, #A05B7, #BDJF8, #Y0328, #FXVJ5, #GCPFY, #VN9JW, #QJNY0: The added assertions for `exitCode()` in the test cases assume that the exit code will always be 0 for successful tests and 1 for failed tests. However, the documentation of `SpawnResult.exitCode()` indicates that the exit code is not meaningful unless the subprocess was executed successfully (`setupSuccess()`). The current implementation does not check if `setupSuccess()` returns true before asserting the exit code, which could lead to incorrect test results if `setupSuccess()` returns false.
