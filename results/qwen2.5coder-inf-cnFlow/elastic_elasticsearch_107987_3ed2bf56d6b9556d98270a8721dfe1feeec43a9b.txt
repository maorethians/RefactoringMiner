#YYVEK, #JFC4A: The `Lookup` class and its associated changes introduce a new logical plan node for performing lookups in ESQL. The implementation seems mostly correct but there are some areas that need attention:
- In the `equals` method of `Lookup`, it incorrectly compares `tableName` with `matchFields`. It should compare `tableName` with `lookup.tableName`.
```java
@Override
public boolean equals(Object o) {
    if (this == o) {
        return true;
    }
    if (o == null || getClass() != o.getClass()) {
        return false;
    }
    if (super.equals(o) == false) {
        return false;
    }
    Lookup lookup = (Lookup) o;
    return Objects.equals(tableName, lookup.tableName)
        && Objects.equals(matchFields, lookup.matchFields)
        && Objects.equals(localRelation, lookup.localRelation);
}
```

```java
@Override
protected NodeInfo<? extends LogicalPlan> info() {
    return NodeInfo.create(this, Lookup::new, child(), tableName, matchFields);
}
```
