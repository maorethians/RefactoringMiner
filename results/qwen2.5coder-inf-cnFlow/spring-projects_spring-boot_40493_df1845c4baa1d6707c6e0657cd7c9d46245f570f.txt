#9NA3F, #97B54, #ZMKR4, #88BH9: The `escapeJson` method is introduced to escape JSON strings, which is a good practice to prevent issues when embedding strings within JSON objects. However, the current implementation does not handle all possible characters that need escaping in JSON (e.g., `\uXXXX` for Unicode characters). Additionally, the order of parameters in the test cases (`customizeClientBuilderWhenHasAuthentication`, `customizeAdminBuilderWhenHasAuthentication`) is different from the expected output order, which might lead to flaky tests if the map's iteration order changes.
