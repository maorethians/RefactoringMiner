#VM664, #HWSM3, #Z6RG9: The method `logWarningHeaderThresholdExceeded` is introduced to handle logging for both size and count threshold exceedances. However, the message pattern uses a placeholder `{}` that should be replaced with either an empty string or a formatted string based on whether headers are available. The current implementation might lead to incorrect log messages if `selectedHeaders.isEmpty()` is true because it will include the literal `{}` in the log output.
