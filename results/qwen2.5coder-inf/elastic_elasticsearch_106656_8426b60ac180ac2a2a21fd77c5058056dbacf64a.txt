#7RKWS, #J0VQ2, #EJNAY, #6VFDN, #VRW8F: The variable `provider` is introduced but not used consistently across all branches of the logic. In the new code, `provider` is checked for null before creating an `InstanceType`, but in the obsolete host source handling and tag parsing sections, it is not used similarly. This inconsistency could lead to unexpected behavior or bugs.

#7RKWS, #J0VQ2, #EJNAY, #6VFDN, #VRW8F: The variable `region` is now being set from a new key `"cloud.region"`, but the obsolete host source handling still uses keys like `"ec2.placement.region"` and `"gce.instance.zone"`. This change might break compatibility with existing data sources that do not provide the new key.

#7RKWS, #J0VQ2, #EJNAY, #6VFDN, #VRW8F: The `instanceType` variable is now being set from a new key `"host.type"`, but the obsolete host source handling still uses keys like `"ec2.instance_type"` and `"azure.compute.vmsize"`. This change might break compatibility with existing data sources that do not provide the new key.

#7RKWS, #J0VQ2, #EJNAY, #6VFDN, #VRW8F: The `fromObsoleteHostSource` method is introduced to handle pre-8.14.0 host sources for backwards-compatibility.
