#W07QB, #FSYT3, #98SJ1: The logic for checking if the host string already contains brackets is moved inside the `if (NetUtil.isValidIpV6Address(hostString))` block, which means it will not be executed for non-IPv6 addresses. This change could lead to incorrect behavior for IPv4 addresses that are enclosed in brackets or any other non-IPv6 address format that includes brackets. The check should be outside the IPv6 validation block to ensure it applies universally.
