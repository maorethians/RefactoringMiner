#61T59, #01MPG: The method `deleteDataStream` in `MetadataDataStreamsService` is introduced to handle the deletion of data streams and their backing indices. However, there are a few points to consider:
- The method assumes that all data streams belong to the same project by using `projectState.projectId()`. This assumption might not hold true if data streams can belong to different projects in the future.
- The logging statement uses `LOGGER.info` which is generally appropriate for informational messages. However, ensure that this level of logging does not lead to performance issues or log clutter, especially if this method is called frequently.
