#BATM3, #SA0J7: The `union` method in `Sets.java` now takes a varargs parameter for additional sets, but in `BaseRestHandler#handleRequest`, it is called with three separate arguments (`RestResponse.RESPONSE_PARAMS`, `ALWAYS_SUPPORTED`, `supported`). This will not work as intended because the varargs parameter will treat all arguments after the first as part of the array. The call should be modified to pass an array or use `Sets.union(Arrays.asList(RestResponse.RESPONSE_PARAMS, ALWAYS_SUPPORTED, supported))`.
