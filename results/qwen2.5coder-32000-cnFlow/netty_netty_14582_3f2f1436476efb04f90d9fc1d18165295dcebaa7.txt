#1YCJK: The change to `CENTRAL_QUEUE_CAPACITY` ensures that it is at least 2 by using `Math.min(2, ...)`. However, this contradicts the existing check in the static block where it throws an `IllegalArgumentException` if `CENTRAL_QUEUE_CAPACITY < 2`. The current implementation will never throw this exception because `CENTRAL_QUEUE_CAPACITY` is guaranteed to be at least 2. This makes the check redundant and should be removed.
