#XCFTS, #0C7EF, #8WSF3, #35RH5, #ZHNPY, #080GS, #28MVQ, #70PH1: The introduction of `TreeSet` and the check with `containsAll` is unnecessary and can lead to incorrect behavior. The original code uses `containsInAnyOrder`, which checks if two collections contain the same elements regardless of order. The new logic converts the result into a `TreeSet` and then checks if all elements of `values` are contained in this set, which does not guarantee that both sets have exactly the same elements. This can lead to false negatives if there are duplicate elements in `values` or if the ordering affects the comparison.
