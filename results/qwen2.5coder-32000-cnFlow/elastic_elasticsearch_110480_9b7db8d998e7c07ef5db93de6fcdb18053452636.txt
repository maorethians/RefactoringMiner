#E84CZ, #V661H, #7TMA5, #0M4T8: The use of `String.split(":")` without checking for null is unnecessary since `split` will return an array with at least one element if the delimiter is not found. The check `nameWithType == null || nameWithType.length != 2` can be simplified to just `nameWithType.length != 2`. Additionally, using `isEmpty()` instead of `length() == 0` for strings is more idiomatic in Java.

#E84CZ: The method `resolveAttribute` could benefit from early returns to improve readability. For example:
```java
private Attribute resolveAttribute(UnresolvedAttribute ua, List<Attribute> resolvedList) {
    var named = resolveAgainstList(ua, resolvedList);
    if (named.isEmpty()) {
        return ua;
    }
    if (named.size() == 1) {
        return named.get(0);
    }
    return ua.withUnresolvedMessage("Resolved [" + ua + "] unexpectedly to multiple attributes " + named);
}

#V661H: The transformation of expressions in `doRule` could be more efficient if the list of resolved attributes was built only once and reused. Currently, it is created for each unresolved attribute.
