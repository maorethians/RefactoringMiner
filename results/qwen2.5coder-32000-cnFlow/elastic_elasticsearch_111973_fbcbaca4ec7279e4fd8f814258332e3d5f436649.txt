#9929M, #T9VA8: The logic for handling indices when there are more than three is correct but can be optimized for performance. The `e.getValue().stream().sorted().limit(3).collect(Collectors.toList())` operation sorts the entire set and then limits it to 3 elements. This can be inefficient if the set is large. Consider using a different approach, such as finding the first three elements without sorting the entire set.
