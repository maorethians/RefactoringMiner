#BCR52, #09SM0: The logic for handling ignored source fields in synthetic mode has been moved from `IgnoredSourceFieldMapper.postParse` to `DocumentParserContext.createCopyToContext`. This change introduces redundancy and potential inconsistencies if the logic is not kept in sync between these two methods. It would be better to centralize this logic in one place, possibly by refactoring it into a utility method that both functions can call.
