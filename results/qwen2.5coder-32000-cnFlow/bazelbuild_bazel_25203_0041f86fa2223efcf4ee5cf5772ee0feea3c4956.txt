#RTP4Y, #MFSFH, #A05B7, #BDJF8, #Y0328, #FXVJ5, #GCPFY, #VN9JW, #QJNY0: The added assertions for `exitCode` in the test cases assume that the exit code will always be 0 for successful tests and 1 for failed tests. However, the documentation of `SpawnResult.exitCode()` indicates that the returned value is not meaningful unless the subprocess was executed successfully. This assumption may lead to incorrect test results if the subprocess did not execute successfully (e.g., due to a timeout or out-of-memory error). The test cases should be updated to handle these scenarios appropriately.
