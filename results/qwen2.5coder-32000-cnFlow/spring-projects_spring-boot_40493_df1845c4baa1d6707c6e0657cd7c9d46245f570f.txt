#9NA3F, #97B54, #ZMKR4, #88BH9: The `escapeJson` method is introduced to escape JSON strings, which is a good practice to prevent issues when special characters are present in the input string. However, the current implementation does not handle all possible JSON escape sequences. For example, it does not escape `\f` (form feed) and `\r` (carriage return), which should be included for completeness.

#9NA3F: The `escapeJson` method could benefit from using a more robust solution, such as a library like Jackson or Gson, which are designed to handle JSON escaping correctly. This would reduce the risk of missing any escape sequences and make the code more maintainable.
