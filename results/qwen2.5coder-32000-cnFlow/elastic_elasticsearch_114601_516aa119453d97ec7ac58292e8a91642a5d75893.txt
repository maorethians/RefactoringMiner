#XRSHN, #XDD4E: The logic for handling paths with dots in keys is not correctly implemented. In the example provided in the Javadoc of `insertValue`, the expected result is incorrect. The method should create nested maps instead of concatenating keys with dots. For instance, given the path `"path1.path2.path3.key2"`, the map should be modified to:
```json
{
  "path1": {
    "path2": {
      "key1": "value1",
      "path3": {
        "key2": "value2"
      }
    }
  }
}
```
However, the current implementation results in:
```json
{
  "path1": {
    "path2": {
      "key1": "value1",
      "path3.key2": "value2"
    }
  }
}
```

#XRSHN: The `extractSuffixMaps` method does not handle the case where a path element is found in a map but subsequent elements do not match any keys. In such cases, it should still add a `SuffixMap` for the deepest matching key to allow insertion at that level.
