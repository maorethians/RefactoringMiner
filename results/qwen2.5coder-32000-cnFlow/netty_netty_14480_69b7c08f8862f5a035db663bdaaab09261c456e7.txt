#B9YWS, #TCNQE, #AQN8A: The logic in `checkMaxBytesRead` and the handling of return values in both `read()` and `read(byte[], int, int)` methods has been changed inconsistently. The original code adjusted `numRead` based on whether the underlying stream returned fewer bytes than requested or nothing at all. The new code only increments `numRead` if something was read (`b > 0`). This change is inconsistent with the intended behavior and could lead to incorrect tracking of bytes read.
