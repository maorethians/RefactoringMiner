#6XTQM, #A47B9: The `fromInteger` method in `CompilationActivityMode` throws a `RuntimeException` for invalid values. It might be more appropriate to use an `IllegalArgumentException` since it indicates client error.

#N4H71: In the `submitForCompilation` method, the `stoppedCompilationTime` is reset before checking if compilations should be submitted again. This could lead to incorrect behavior if multiple compilations are attempted in quick succession after a stop period. Consider resetting `stoppedCompilationTime` only after successfully submitting new compilations.

#N4H71: The logging of shutdown compilations uses an assertion (`assert`) which is not suitable for production code as assertions can be disabled at runtime. Use a proper conditional check instead.
