#A623W: The implementation of `addBoolean` in `DocumentDimensions` appears to ignore the `value` parameter, calling only `add(fieldName)`. Since dimensions are critical for calculating the Time Series ID (TSID), failing to pass the actual boolean value to the underlying storage mechanism will likely result in incorrect TSID generation for any implementation relying on this default method. It should be updated to ensure the `value` is properly processed and stored, similar to how it is handled in `TimeSeriesIdFieldMapper`.
