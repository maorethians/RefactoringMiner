#V9347: In the methods `processDoubles`, `processInts`, and `processLongs`, there is a logic error when handling sorted multivalue blocks. If `valuesBlock.mvSortedAscending()` is true, the code appends the calculated percentile value to the builder but then continues execution into the unsorted path, which sorts the values again and appends a second value to the builder for the same position. This will result in corrupted output or an exception. The sorted block logic should be wrapped in an `if/else` structure or end with a `return`.
