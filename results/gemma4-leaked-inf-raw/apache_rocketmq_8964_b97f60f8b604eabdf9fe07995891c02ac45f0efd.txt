#9V489: The exception message `"Broker[" + brokerName + "] master node does not exist"` may be slightly misleading when `brokerName` is null, as the code falls back to using `msg.getStoreHost()` in that scenario. In such cases, the error message will report `Broker[null]`, which doesn't explicitly indicate that the failure occurred while resolving the address from the message's store host.
