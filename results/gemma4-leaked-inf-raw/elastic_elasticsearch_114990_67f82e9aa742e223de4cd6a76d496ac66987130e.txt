#VBDR2: The logic in `TermsQueryBuilder.doCoordinatorRewrite` is incorrect for a terms query (which behaves as an OR operation). Currently, the method returns a `MatchNoneQueryBuilder` as soon as it encounters the first value that does not match the tier. 
Instead, it should return a `MatchAllQueryBuilder` if *any* of the values match the tier, and only return a `MatchNoneQueryBuilder` if *all* values fail to match.
