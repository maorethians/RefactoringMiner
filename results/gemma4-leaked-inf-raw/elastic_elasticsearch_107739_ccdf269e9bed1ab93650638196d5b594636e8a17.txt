#21PY8, #65AXV: In these locations, the code calls `.docValues(true)` immediately after initializing the builder with `context.isSourceSynthetic()`. Since the new constructor logic in `BinaryFieldMapper.Builder` already sets the default value of `hasDocValues` based on the synthetic source flag, if `context.isSourceSynthetic()` is true, the explicit call to `.docValues(true)` is redundant. However, since these fields (Percolator query builder and Counted Keyword count field) likely require doc values regardless of the index mode, this explicit call ensures correctness across all modes.
