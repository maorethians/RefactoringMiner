#M54JY, #V5XK4, #GBH17: In `TDigestState.read(...)`, if an `IOException` occurs during the call to `in.readVLong()` after the `TDigestState` object has been instantiated, the created `state` object is leaked. Since `TDigestState` manages a `TDigest` instance (which may hold significant memory and requires explicit closing), this could lead to memory leaks in scenarios where reading from the stream fails partially.
The `catch` block should check if `state` is non-null and call `state.close()` before rethrowing the exception.
