#0TT71: The `notificationWithPollingStats` method contains a logic error where the `future0` CompletableFuture is only completed if `response.getCode() == ResponseCode.SUCCESS`. If the response code is anything else, the future will remain pending indefinitely, causing the calling thread or process to hang until a timeout occurs (if one is configured externally). You should ensure that `future0` is completed exceptionally or with a default value in all execution paths.
Additionally, creating a manual `CompletableFuture` inside `thenCompose` for synchronous logic is an anti-pattern. This can be simplified by using `thenApply` or returning `CompletableFuture.completedFuture()` / `CompletableFuture.failedFuture()`.
