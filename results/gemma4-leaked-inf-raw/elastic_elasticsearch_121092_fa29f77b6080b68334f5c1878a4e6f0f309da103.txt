#4E85H: The logic in `newSnapshot` does not account for inference fields when deciding which snapshot implementation to instantiate. While the call to `synthesizeSource` is now triggered by either synthetic source being enabled or the presence of inference fields (as seen in #V0ZHA), and `TranslogDirectoryReader` treats both cases identically (#TT2KK), `newSnapshot` only returns a `LuceneSyntheticSourceChangesSnapshot` if `isRecoverySourceSyntheticEnabled()` is true. 
If inference fields are present but synthetic source recovery is disabled, the method will return a `LuceneChangesSnapshot`. This is likely incorrect as inference fields typically require the same synthesis/normalization logic provided by the synthetic snapshot to ensure consistent assertions. The condition in `newSnapshot` should be updated to mirror the logic used in #V0ZHA and #TT2KK.
