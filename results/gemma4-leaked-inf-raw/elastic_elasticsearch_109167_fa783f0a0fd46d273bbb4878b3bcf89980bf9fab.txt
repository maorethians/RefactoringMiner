#AESW2, #QQCXY, #R9D9E, #T1GMH, #0K319: The methods `writeJSONFile`, `setupClusterStateListener`, and `setupClusterStateListenerForCleanup` have been changed to `public static`. However, they continue to call `internalCluster()`, which is typically an instance method provided by the test base class. Calling an instance method from a static context will result in a compilation error. These methods should either remain instance methods or be updated to accept the cluster/test context as a parameter.

#SZWAJ, #Q2S87: The `RoleMappingMetadata` parser is implemented such that role mapping names are lost during deserialization (replaced by `"name_not_available_after_deserialization"`). While this behavior is explicitly tested in `FileSettingsRoleMappingsRestartIT` and `RoleMappingMetadataXContentSerializationTests`, it represents a significant loss of data. If the system relies on these names for identification or lookup, this implementation will cause functional failures. Please confirm that this "name-less" recovery is intended for reserved state settings.
