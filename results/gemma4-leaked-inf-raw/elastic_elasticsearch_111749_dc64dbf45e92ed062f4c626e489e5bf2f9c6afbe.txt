#6C0AH: In the methods `processDoubles`, `processInts`, and `processLongs`, there is a logic error where values are appended to the result builder twice if the input block is already sorted ascending (`valuesBlock.mvSortedAscending()`).
The code checks for sorting and appends the result, but then continues execution into the unsorted logic (which copies the data to an array, sorts it, and appends the result again). This will lead to corrupted output blocks as multiple values are appended for a single input position. 
An `else` block or a `return` statement should be added after the sorted-case logic to prevent the unsorted-case logic from executing.
