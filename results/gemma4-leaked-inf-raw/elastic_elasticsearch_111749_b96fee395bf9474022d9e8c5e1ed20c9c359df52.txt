#V9347: In `processDoubles`, `processInts`, and `processLongs`, there is a logic error when handling sorted blocks (`valuesBlock.mvSortedAscending()`). The code calculates the percentile and appends it to the builder, but then continues execution into the sorting and calculation block below it, appending a second value for the same position. This will result in an incorrect number of values in the resulting block. An `else` block or a `return` statement should be used after the sorted-case logic.
