#RHK61: The `process` method performs `str.utf8ToString()` and `substr.utf8ToString()` on every invocation. Since this function is executed per row in a dataset, converting `BytesRef` (UTF-8) to Java `String` (UTF-16) repeatedly creates significant memory allocation pressure and CPU overhead. 
Given that UTF-8 byte sequences are unique, this could be implemented more efficiently using a byte-level search on the `BytesRef` objects directly, avoiding string allocations entirely. At the very least, if the substring is a constant, it should not be re-converted for every row.
