#TAT9E: The use of `ActionListener.running(getResults)` inside the completion listener lambda appears to be a logic error. 
`ActionListener.running(Runnable r)` is a factory method that returns an `ActionListener` which executes the provided runnable when triggered (e.g., via `onSuccess`). However, in this context:
```java
asyncTask.addCompletionListener(() -> ActionListener.running(getResults))
```
The lambda passed to `addCompletionListener` is executed upon task completion. This execution simply creates a new `ActionListener` object and immediately discards it without ever calling its methods. Consequently, `getResults.run()` will never be invoked when the task completes.
If `addCompletionListener` accepts a `Runnable`, you should pass `getResults` directly:
```java
asyncTask.addCompletionListener(getResults)
```
