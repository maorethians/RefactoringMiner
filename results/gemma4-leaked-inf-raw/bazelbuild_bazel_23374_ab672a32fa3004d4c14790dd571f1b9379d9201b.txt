#K655T, #JZW7P: The logic for filtering artifacts in `RemoteBuildEventUploadMode.MINIMAL` has been moved from `shouldUpload` to `readPathMetadata`. However, the original implementation in `shouldUpload` allowed files where `path.isBuildToolLog()` was true. The new implementation in `readPathMetadata` does not include a check for build tool logs in its "allow" list (it only checks `TEST_LOG_PATTERN` and specific `LocalFileType` values), which may result in build tool logs being incorrectly omitted when in minimal mode.
