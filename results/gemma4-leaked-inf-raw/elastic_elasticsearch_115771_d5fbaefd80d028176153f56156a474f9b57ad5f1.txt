#XRZ19: There is a discrepancy between the implementation and the documentation regarding the version filter for system index mapping versions. The comment mentions that this logic handles cases where the master was upgraded from before version 8.11, and `RestTestLegacyFeatures` associates the feature with `Version.V_8_11_0`. However, the code filters for nodes with a version `.after(Version.V_8_16_0)`. This suggests that nodes between versions 8.11 and 8.16 may be incorrectly skipped during this fixup process. Additionally, using `.after()` excludes version 8.16.0 itself; if the intention is to include it, a method like `onOrAfter` (if available) or a different comparison should be used.
