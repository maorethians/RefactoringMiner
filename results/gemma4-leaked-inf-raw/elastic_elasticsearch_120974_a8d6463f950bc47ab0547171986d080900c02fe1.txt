#370GF: Moving the logic to mark `copy_to` target fields as ignored into `createCopyToContext` may lead to index bloat. Since `createCopyToContext` is called for every source field that has a `copy_to` attribute, if multiple fields copy to the same target field, that target will be added to `ignoredFieldValues` multiple times. This results in redundant stored fields being written to the Lucene document (one for each source field), whereas the previous implementation in `IgnoredSourceFieldMapper.postParse` likely only added the target once per document.
