#D9QWQ: The completion condition `if (valueAssertions.isEmpty())` only checks the value-based assertions map. Since histogram assertions have been moved to a separate `histogramAssertions` map, they are currently ignored when determining if the test has finished. This could allow the test to pass prematurely before all histograms are validated or cause it to ignore pending histogram data.

#GMVW9: The timeout error message uses `Collectors.joining()` without a delimiter, which will concatenate remaining assertion keys into a single string (e.g., `"key1key2"`). Providing a delimiter such as `", "` would significantly improve the readability of failure logs.

#J90HE, #D9QWQ: The assertions are stored in `HashMap` instances and modified within a callback that processes asynchronous metric samples. Because `HashMap` is not thread-safe, this may lead to race conditions or `ConcurrentModificationException` if multiple samples are processed concurrently. Consider using `ConcurrentHashMap` for both `valueAssertions` and `histogramAssertions`.
