#8CTG3: The error message construction is inconsistent regarding element ordering. When the number of indices is greater than 3, the list is explicitly sorted alphabetically; however, when the size is 3 or fewer, the set is appended directly, meaning the order depends on the `Set` implementation used (e.g., insertion order for `LinkedHashSet` or unpredictable order for `HashSet`). To ensure deterministic and consistent error messages across all scenarios, the sorting logic should be applied regardless of the set size.
