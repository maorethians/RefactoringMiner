#JZHSV: The call to `clustersWithNoMatchingIndices.removeAll(...)` will likely throw an `UnsupportedOperationException`. In most common Java utility libraries used in this project (such as Guava), `Sets.difference()` returns an unmodifiable view of the sets rather than a new mutable set. To fix this, wrap the result of `Sets.difference` in a new mutable collection (e.g., `new HashSet<>(Sets.difference(...))`) before attempting to modify it.
