#M737X, #4609P, #JATED, #RQ539: Potential `NullPointerException` when `indexSettings` is null. Several tests (e.g., `#MA4CR`, `#DVQCG`, `#CGVY6`) now pass `null` to the `NestedObjectMapper.Builder`. If these objects are used in a context where `syntheticFieldLoader()` or other logic relying on `IndexSettings` is triggered, the application will crash. Consider adding null checks or providing a default settings object to ensure robustness, especially since the current implementation assumes `indexSettings` is always present.
