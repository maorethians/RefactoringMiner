#0C4MT: The cell for ingest time is now populated with a raw `long` value (`accumulatedStats.ingestStats.totalStats().ingestTimeInMillis()`) instead of being wrapped in a `TimeValue` object as it was in the previous implementation. This will likely cause the CAT API to display a raw number instead of a formatted duration (e.g., "100" instead of "100ms"), resulting in a regression in output formatting.

#09JNS: The assertion `assert configs.size() == accumulatedStatsMap.size();` assumes that there is exactly one unique model ID in the stats for every configuration. If some models are not deployed or lack statistics, this assertion will fail. While assertions are typically disabled in production, this logic may be fragile during testing or in environments where assertions are enabled.
