#H5BNE: The implementation of `toXContent` within `getTruncatedInput()` uses `builder.value(TRUNCATED_RECORD_VALUE)`, which results in the "input" field being serialized as a simple string in the final JSON. However, the intended design (and the corresponding integration tests in `#DCF3H`) expects an object containing the `TRUNCATED_RECORD_KEY`. This will cause a `ClassCastException` in the tests when attempting to cast the resulting string to a `Map`.
