#ESTZ8: The validation logic using `field.startsWith(nestedObjectMapper.fullPath())` is prone to false positives. If a sort field shares a prefix with a nested object path but is not actually a child of that object (e.g., a sort field named `user_name` and a nested object named `user`), the validation will incorrectly throw an `IllegalArgumentException`. 
To ensure correct path matching, you should check if the field is exactly equal to the nested path or starts with the nested path followed by a dot separator:
`field.equals(path) || field.startsWith(path + ".")`.
