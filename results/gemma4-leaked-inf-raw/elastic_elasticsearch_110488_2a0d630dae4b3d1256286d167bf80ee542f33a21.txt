#7XJAN: Changing the return value of `maybeResolveAgainstList` from a list containing an error-carrying attribute to throwing an `IllegalStateException` changes the failure mode from a graceful ESQL analysis error (which can be reported back to the user) to an unchecked exception. If this path can still be triggered by user-provided queries, it may result in internal server errors (500s) rather than descriptive validation messages.
