#QQCXY, #T1GMH, #0K319: The methods `writeJSONFile`, `setupClusterStateListener`, and `setupClusterStateListenerForCleanup` have been changed to `public static`, but they continue to call `internalCluster()`. In the context of Elasticsearch integration tests, `internalCluster()` is an instance method provided by the test base class. Calling it from a static context will result in a compilation error. These methods should either remain instance methods or accept the cluster/service as a parameter.
