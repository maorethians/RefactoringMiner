#7QHJH: #### Logic Error: Duplicate Appends in `MvPercentile`
In the methods `processDoubles`, `processInts`, and `processLongs`, there is a logic error when the input block is already sorted (`valuesBlock.mvSortedAscending()`). 
The code checks if the block is sorted and appends the calculated percentile value to the builder. However, it does not return or use an `else` block after this check. As a result, the execution continues into the sorting logic, which creates a local array, sorts it, and appends the percentile value to the builder a **second time** for the same position.
This will lead to corrupted results in the resulting block (e.g., shifted values or incorrect counts).
Example from `processDoubles`:
```java
if (valuesBlock.mvSortedAscending()) {
    // ... appends value to builder ...
}
// This code executes regardless of whether the above block executed
var values = new double[valueCount]; 
// ... sorts and appends value to builder AGAIN ...
```
This same pattern is repeated in `processInts` (around line 268) and `processLongs` (around line 315).
