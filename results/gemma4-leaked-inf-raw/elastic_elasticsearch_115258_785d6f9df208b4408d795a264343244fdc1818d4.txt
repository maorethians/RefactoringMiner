#T8ZKR: The capability `FN_REVERSE_GRAPHEME_CLUSTERS` is initialized with `Runtime.version().feature() < 20`. This means the capability is enabled when the JDK version is less than 20. However, the accompanying documentation and comments state that this functionality is *not* supported on JDK versions less than 20. The logic should be inverted to `Runtime.version().feature() >= 20` so that the capability is only enabled on supported JDK versions.
