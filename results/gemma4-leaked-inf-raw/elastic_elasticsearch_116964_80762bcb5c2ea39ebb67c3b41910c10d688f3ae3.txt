#M0EZK, #AYHV6, #FM2A1, #CK2P4, #ZKYSY, #6BMAX: #### Potential Unhandled Exception on Circle Geometries
The `SpatialEnvelopeVisitor.visit(Circle circle)` method (in `#M0EZK`) explicitly throws an `UnsupportedOperationException`. However, the ESQL function wrappers (e.g., `StEnvelope`, `StXMax`) and their corresponding generated evaluators only catch and handle `IllegalArgumentException`. 
If a user provides a geometry that is a `Circle` (which is a valid part of the `geo_shape` type), this will result in an unhandled `UnsupportedOperationException` bubbling up through the ESQL execution engine, potentially causing the query to fail with a system error rather than a graceful function-level exception. 
**Recommendation:** Either add `UnsupportedOperationException` to the `@ConvertEvaluator` warning list (so the generator catches it) or handle circles within the visitor by calculating their bounding box based on center and radius.
