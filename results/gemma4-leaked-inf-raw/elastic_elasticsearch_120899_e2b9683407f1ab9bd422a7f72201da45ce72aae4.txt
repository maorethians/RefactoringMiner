#1X90Q: The variable `pattern` is assigned the result of `from("test1")`, which typically returns a full ES|QL clause (e.g., `"FROM test1"`). Passing this entire clause into `RemoteClusterAware.isRemoteIndexName(pattern)` is likely incorrect, as that method expects an index name rather than a query fragment. Since the string starts with the `FROM` keyword, the check will likely always return `false`, rendering the branch for remote cluster error messages unreachable. You should perform this check on the raw index name instead of the formatted clause.
