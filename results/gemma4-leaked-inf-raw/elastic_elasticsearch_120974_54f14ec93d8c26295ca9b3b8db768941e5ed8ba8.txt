#370GF, #MXYWG: The logic for marking `copy_to` target fields as ignored (to prevent them from being synthesized in synthetic source) has been moved from `IgnoredSourceFieldMapper.postParse` to `DocumentParserContext.createCopyToContext`.
However, this change introduces a potential duplication issue. The original implementation in `IgnoredSourceFieldMapper` iterated over the collection of target fields (`context.getCopyToFields()`), ensuring each target was processed once. In contrast, the new implementation adds the target field to `ignoredFieldValues` every time `createCopyToContext` is invoked. 
Since `createCopyToContext` is called for every source field that has a `copy_to` attribute, any target field that is the destination of multiple source fields will be added to `ignoredFieldValues` multiple times. Consequently, `IgnoredSourceFieldMapper.postParse` will write redundant `StoredField` entries to the Lucene document for each occurrence, increasing index size unnecessarily.
