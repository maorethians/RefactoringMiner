#AT5X6: The lookup of `NestedObjectMapper` via `context.nestedLookup().getNestedMappers().get(parentPath)` could potentially return `null` if the `parentPath` is not found in the mappers map. If this happens and `nestedHelper.mightMatchNestedDocs(filterQuery)` evaluates to `true`, a `NullPointerException` will be thrown when calling `mapper.nestedTypeFilter()`. Consider adding a null check for `mapper` or ensuring that the path is validated before this block is reached.
