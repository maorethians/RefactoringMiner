#VR0EF, #B24AY: The refactoring changes how log capturing is implemented: it moves from adding a Log4j appender directly to specific loggers to using a single static `RealMockAppender` that delegates events based on an exact match of the logger name in a map (`mockAppenders`).
This introduces a regression regarding logger hierarchies. In the previous implementation, adding an appender to a logger (e.g., `"org.elasticsearch"`) would capture all logs from that logger and its descendants (e.g., `"org.elasticsearch.common.Settings"`), following standard Log4j behavior. The new implementation only captures events where `event.getLoggerName()` exactly matches the key in the map, meaning package-level or parent-logger capturing no longer works for child loggers.
