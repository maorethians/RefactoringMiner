#VP4W9: The use of `Long.parseLong(attr)` to retrieve the reserve time from attributes may throw an unhandled `NumberFormatException` if the attribute value is not a valid numeric string. Consider wrapping this in a try-catch block or using a utility method that provides a default value upon parsing failure to prevent the configuration update process from crashing.

#VP4W9: The `updateTieredStoreTopicMetadata` method is marked as `synchronized`, which locks the entire `TopicConfigManager` instance. If the underlying `metadataStore` operations (e.g., `getTopic`, `addTopic`, `updateTopic`) involve network I/O or significant latency, this could block all other topic configuration updates across the broker. Consider using a more granular locking mechanism (e.g., based on the topic name) or relying on the thread-safety of the `MetadataStore` implementation if applicable.
