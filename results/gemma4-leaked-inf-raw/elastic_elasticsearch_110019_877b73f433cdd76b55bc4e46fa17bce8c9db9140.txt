#98BJY, #BAS90: The updated Javadoc for `result()` explicitly states that it `@throws IllegalStateException if this future is incomplete`. However, the implementation in `Sync.result()` only performs an `assert isDone()`. Since assertions are typically disabled in production environments, the method will proceed to call `getValue()` instead of throwing the documented `IllegalStateException` when the future is incomplete. To align the code with its contract, a formal check and throw should be added:
```java
if (!isDone()) {
    throw new IllegalStateException("Error, synchronizer in invalid state: " + getState());
}
```
