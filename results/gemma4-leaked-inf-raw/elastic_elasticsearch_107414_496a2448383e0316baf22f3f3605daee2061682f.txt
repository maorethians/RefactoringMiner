#1XN1D, #AN9G7: The surrogate implementation for `count_distinct` over constants returns a value that folds to a constant (e.g., `1`). This is incorrect for empty datasets; an aggregate function should return `0` (for count) or `null` when there are no input rows. Because the current logic replaces the aggregation with a literal, it will return `1` even if the source is empty. It should be tied to the existence of rows (e.g., by checking `count(*)`).

#2ZQNZ, #4HMVP: The surrogate implementation for `median` over constants returns a value that folds to a constant (the median of the constant). This is incorrect for empty datasets; the result should be `null`. Similar to the issue in `CountDistinct`, replacing the aggregate with a literal bypasses the aggregation logic and will return the constant value instead of `null` when no rows are present.
