#5TPQW: The added check for whether the IPv6 address already contains brackets is redundant. The `NetUtil.toAddressString(addr.getAddress())` method should always return a string with brackets around an IPv6 address, so the condition `if (hostString.charAt(0) == '[' && hostString.charAt(hostString.length() - 1) == ']')` will always be true if the code reaches this point. This check can be removed to simplify the logic.
