#13JDE, #Z0FRW, #N7YK8, #HF84T, #E1Z64: The method `flushRemaining` has been introduced to replace `emitOrds`. This change is consistent across multiple classes (`BytesRef3BlockHash.AddWork`, `PackedValuesBlockHash.AddWork`, `IntLongBlockAdd`, and `LongLongBlockAdd`). The new method checks if there are any remaining ordinals to emit and flushes them. However, the logic in `flushRemaining` should be reviewed for correctness.
1. **Check for Incomplete Position**: The check `if (firstOrd != -1)` ensures that no position is left incomplete before flushing. This is a good practice.
2. **Batch Size Check**: The check `if (added % emitBatchSize != 0)` ensures that only non-empty batches are flushed. This prevents unnecessary empty blocks from being emitted, which is an improvement over the previous behavior.
