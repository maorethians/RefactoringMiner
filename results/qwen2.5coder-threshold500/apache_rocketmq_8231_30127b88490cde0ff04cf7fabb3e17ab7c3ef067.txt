#8GZQA, #EWGHG: The introduction of `StringUtils.isNotBlank(request.getGroup().getName())` checks ensures that only valid group names are processed. However, this change introduces a potential issue when `request.getGroup()` returns null. The current implementation does not handle the case where `request.getGroup()` itself is null, which could lead to a `NullPointerException`. A `NullPointerException` can occur if `request.getGroup()` is null -> The code assumes `request.getGroup()` will never be null without checking -> Systematic risk of unhandled exceptions leading to crashes or undefined behavior.
