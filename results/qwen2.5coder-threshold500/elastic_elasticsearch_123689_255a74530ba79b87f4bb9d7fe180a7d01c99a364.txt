#Z5185, #SFMTE: The new implementation of `PATH_ORDER` in `FileUtils.java::FileUtils` does not handle paths with different path separators consistently across operating systems. The original implementation used `Path` objects, which abstract away the differences between path separators on Unix and Windows. The new character-by-character comparison directly compares characters without considering platform-specific path separator rules. This divergence can lead to incorrect sorting of paths on Windows systems where both forward slashes (`/`) and backslashes (`\`) are valid path separators. For example, `/a/b` might be incorrectly sorted before `C:\a\b`, which could disrupt the intended lexicographic order.
