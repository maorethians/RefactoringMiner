#1TPMB, #5506R: The method `isPointGeometry` is introduced to check if the geometries array contains a single point geometry. However, the logic in `pointShapeQuery` now checks for the negation of this condition (`isPointGeometry(luceneGeometries) == false`) before throwing an exception. This approach is correct but can be improved for clarity and maintainability.
The method name `isPointGeometry` suggests that it returns true if all geometries are points, which might mislead someone reading the code into thinking it checks for multiple point geometries rather than a single one. It would be clearer to rename this method to something like `containsSinglePointGeometry`.
