#AQN8A, #TCNQE: The logic for updating `numRead` has been simplified but may not handle all cases correctly. Specifically, when `super.read()` returns `-1`, indicating no more bytes are available, `numRead` should not be decremented as it was in the previous implementation. The current code does not account for this scenario.
