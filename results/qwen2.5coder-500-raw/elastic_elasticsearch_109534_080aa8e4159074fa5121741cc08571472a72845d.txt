#14J54, #0YQ42, #J1SE7, #VGWJP: The changes replace `request.getTimeout()` with `remainingTime.get()`. However, `remainingTime` is a `Supplier<TimeValue>` and should be invoked to get the current remaining time. The correct usage would be `remainingTime.get()` instead of `remainingTime`.

#FE8K2: The test case `testRemainingTime` is flawed because it expects the remaining time to be greater than zero and then immediately equal to zero, which is not realistic unless the timeout is extremely short or the system clock advances significantly between calls. This test should be revised to account for a more reasonable expectation of remaining time.

#VMVCC: The `onTimeout` method uses `request.getTimeout()` in the error message, which might not reflect the actual remaining time when the timeout occurs. It should use the full request timeout or the remaining time at the point of timeout for clarity.
