#E6MZH: The `addLocaleData` method has a hardcoded value for `STANDALONE_MASK` which is not defined anywhere in the provided code. This could lead to confusion or errors if this constant changes in future versions of Java.
```java
final int STANDALONE_MASK = 0x8000;  // value of Calendar.STANDALONE_MASK
```
It would be better to use `Calendar.STANDALONE_MASK` directly.

addLocaleData(csData, 7, 2, List.of("Neděle", "Pondělí", "Úterý", "Středa", "Čtvrtek", "Pátek", "Sobota"), false);
