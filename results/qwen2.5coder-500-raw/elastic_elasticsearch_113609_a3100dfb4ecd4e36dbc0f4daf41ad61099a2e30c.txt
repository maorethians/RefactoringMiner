#DNM54: The use of `alwaysFlushBody ? never() : containsString("the target server failed to respond")` is unconventional and may be confusing. The `never()` matcher will always return false, which means that if `alwaysFlushBody` is true, the assertion will always pass regardless of the exception message. This could lead to false positives in tests.

#0TPPS: The `NeverMatcher` class is a singleton, but it does not enforce thread safety for its instance creation or usage. While this might not be an issue in test scenarios, it's generally good practice to ensure that singletons are thread-safe.
