#MSYSP: The added null check for `brokerController.getPopInflightMessageCounter()` is a good practice to prevent potential `NullPointerException`. However, there is no null check for `brokerController.getPopConsumerService()`, which could also lead to a `NullPointerException` in the same context. It would be consistent and safer to add a similar null check for this service as well.

#MSYSP: The method `commitPullOffset` is called within the loop, but it uses `queueId` instead of `entry.getKey()`. This could lead to incorrect offsets being committed if there are multiple entries in `queueOffsetMap`. The correct queue ID should be used, which is `entry.getKey()`.
