#EDQBP: The optimization in `fromWellKnownBinary` and `fromWellKnownBinaryGeo` that returns the original WKB when the geometry is a `Point` is logically inconsistent with the definition of a spatial envelope. An envelope (or bounding box) should consistently return a rectangle (even if degenerate), whereas this implementation returns a `Point` for point inputs and a `Rectangle` for all other inputs (including `MultiPoint` containing a single point). This inconsistency may cause issues for downstream consumers expecting a rectangular geometry.
