#FT0CW: The coordinator rewrite logic for `TermsQueryBuilder` is incorrect. A `terms` query should match if *any* of the provided values match (logical OR). However, the current implementation returns a `MatchNoneQueryBuilder` as soon as it encounters the first value that does not match, effectively treating the query as a logical AND. It should instead iterate through all values and only return `MatchNoneQueryBuilder` if no matches are found.
