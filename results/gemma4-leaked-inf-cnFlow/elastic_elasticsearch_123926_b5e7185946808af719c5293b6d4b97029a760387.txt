#K8412: In the `dataStreamMigrationFailed` method, the `ElasticsearchException` is constructed by concatenating the `migrationInfo` object directly into the error message:
`"error occurred while reindexing data stream [" + migrationInfo + "]"`. 
This will result in the object's `toString()` representation (likely the class name and hashcode) being printed instead of the actual data stream name. It should use `migrationInfo.getDataStreamName()`.
