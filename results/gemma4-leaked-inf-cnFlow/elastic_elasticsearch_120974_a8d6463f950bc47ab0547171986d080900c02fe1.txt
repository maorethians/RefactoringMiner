#BCR52: The logic moved from `IgnoredSourceFieldMapper#postParse` to `DocumentParserContext#createCopyToContext` introduces potential duplicate entries in the Lucene document. 
In the previous implementation (`#09SM0`), the code iterated over a `Set<String>` of copy-to fields, ensuring that each target field received at most one "void" marker regardless of how many source fields were copied into it. The new implementation adds a marker every time `createCopyToContext` is called for a specific `copyToField`. If multiple source fields are configured to `copy_to` the same target field, this will result in multiple identical stored fields being added to the Lucene document, increasing index size without providing additional value.
