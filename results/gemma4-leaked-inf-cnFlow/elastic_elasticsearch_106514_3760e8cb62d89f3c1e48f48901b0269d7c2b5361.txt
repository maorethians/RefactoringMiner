#886Q5, #FCW1F: A potential `NullPointerException` exists in `IndicesAliasesResponse.build`. In `TransportIndicesAliasesAction#masterOperation`, if an action's index expression matches no indices (and it is not a data stream action), the `actionResult` variable remains `null` and is subsequently added to the `actionResults` list via `actionResults.add(actionResult)`. 
When `IndicesAliasesResponse.build(actionResults)` is called, the stream operation `actionResults.stream().anyMatch(a -> a.success == false)` will throw a `NullPointerException` when it encounters these null elements. This scenario occurs if at least one action in the request matches an index (preventing the `AliasesNotFoundException` from being thrown) but other actions in the same request match none.
