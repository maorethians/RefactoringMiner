#BANQQ: Changing the return value from a list containing an `UnresolvedAttribute` to throwing an `IllegalStateException` shifts the error handling strategy from "error collection" to "fail-fast". This prevents the analyzer from collecting and reporting multiple issues in a single pass, potentially degrading the user experience by only revealing one ambiguity at a time.

#PRR6D, #0TTZ5: The introduction of the member variable `unionFieldAttributes` makes the `ResolveUnionTypes` rule stateful. If this rule instance is shared across threads or reused for different plan analyses, it will cause race conditions and data corruption. This state should be managed within the scope of the `apply` method (e.g., by passing it as a parameter to `doRule`) rather than as a class member.
