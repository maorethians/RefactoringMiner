#W982J: The `resolvedPipelineCache` uses `indexRequest.index()` as its key, but the value is computed using `IngestService.resolveStoredPipelines`, which depends on the `actionRequest` (the original request). 
If a bulk request contains multiple operations targeting the same index name but originating from different indices (for example, when using date math or aliases in the original requests), the cache will incorrectly apply the pipelines resolved for the first request to all subsequent requests targeting that same index. The cache key should incorporate the original request's identity or context if it influences pipeline resolution.
