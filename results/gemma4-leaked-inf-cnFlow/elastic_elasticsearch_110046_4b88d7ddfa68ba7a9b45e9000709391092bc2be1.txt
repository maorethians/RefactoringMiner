#B61NY, #DWC1D: There is an off-by-one error when mapping tokens to parameters. `ParametrizedTokenSource` uses a zero-based counter `param` (initialized to 0 in `#H77H1`), but `QueryParams.get(int index)` treats the input as a one-based index (returning `null` if `index <= 0`). Consequently, the first parameter encountered will be mapped to `null` because `params.get(0)` returns `null`.

#M7NB8: In the `plan` method, the loop variable `i` is initialized to 0 but never incremented within the `while (errors.hasNext())` block. As a result, the condition `if (i > 0)` will always be false, and the semicolon separator (`; `) will never be appended between error messages.
