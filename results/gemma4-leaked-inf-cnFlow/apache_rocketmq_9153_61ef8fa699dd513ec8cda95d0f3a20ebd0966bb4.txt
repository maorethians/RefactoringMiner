#W8DG5: The `updateTopicList` method manually constructs a delimited string by appending the separator to every element, including the last one (e.g., `"topic1;topic2;"`). While `StringUtils.split` handles trailing separators by ignoring empty results, it is more idiomatic and cleaner to use `String.join(TOPIC_NAME_SEPARATOR, topicList)` or a `Collectors.joining` stream. Additionally, the current implementation does not check for null elements within the `topicList`, which would result in the string `"null"` being added to the list.
