#QJ3B4: The change replaces the main function registry with the snapshot registry (`context.functionRegistry().snapshotRegistry()`) for implicit casting. Because the string literal conversion map was converted from a static member to an instance member (#W7EX6), and the snapshot registry only populates this map with snapshot-specific functions (#V3KCB), standard functions will no longer be eligible for implicit casting. This appears to be a regression where standard function casting is disabled in favor of snapshot function casting.
