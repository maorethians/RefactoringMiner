#BXEH1, #0FW1C, #26M5T, #9N9TW, #6RRKB: In the `perPosition` method of the lazy evaluators (e.g., `CoalesceBooleanLazyEvaluator`), the code uses `result.copyFrom(lastFullBlock, p, p + 1)` to copy a single position from the `lastFullBlock`. For consistency and potential performance gains, this should use the newly introduced single-position API `result.copyFrom(lastFullBlock, p)`, as is done for the other evaluators in the same loop.
