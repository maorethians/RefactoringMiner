#FC55Q: When `brokerName` is null, the code falls back to resolving the address via `msg.getStoreHost()`. If this resolution also fails (resulting in a blank `brokerAddr`), the exception message `"Broker[null] master node does not exist"` is thrown. This is slightly misleading as it suggests a lookup failure for a null broker name rather than a missing or invalid store host within the message metadata. Consider using a more descriptive error message when `brokerName` is null.
