#AS5KT: In `EsqlSession#fieldNames` (#AS5KT), the logic is updated to use `p.references()` instead of manually calculating references from top-level expressions via `Expressions.references(p.expressions())`. Since `QueryPlan.references()` is the authoritative source for all attributes a node requires from its input set (and is cached), this change ensures that aliases are not incorrectly removed from the global reference set if they are actually required inputs for the plan node.

#WEKT6: The addition of the capability flag in `EsqlCapabilities` (#WEKT6) serves as a versioning marker for this fix.
