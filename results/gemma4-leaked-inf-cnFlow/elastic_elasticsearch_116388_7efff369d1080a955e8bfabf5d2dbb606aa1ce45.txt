#CZ9YB, #5AQ6E: The use of `shardFailure.toString()` as a key in the `shardFailures` map to deduplicate failures is fragile. Since `ShardSearchFailure` typically contains structured data (like index and shard ID), it would be more robust to use a composite key or a dedicated identity object rather than relying on the string representation, which may change across versions or contain non-unique information.
