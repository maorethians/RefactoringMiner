#NRBJJ, #4GXKG, #EHZJ9, #QV4Z1: The changes to `writeTo` in these classes remove the hardcoded serialization of `Source.EMPTY` in favor of the actual node source. However, unlike the scalar functions reviewed in this chapter (e.g., `#QHVZG`), these are not guarded by a `TransportVersion` check. Furthermore, there are no corresponding changes to the deserialization logic for these classes in this chapter. This introduces a breaking change to the wire format that will cause `StreamCorruptedException` or data corruption when reading data serialized by these updated classes.
