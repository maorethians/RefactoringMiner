#N4HG7: The check `field.startsWith(nestedObjectMapper.fullPath())` may produce false positives. If a sort field shares a prefix with a nested object's path but is not actually contained within it (e.g., sort field "username" and nested object "user"), an `IllegalArgumentException` will be thrown incorrectly. The check should verify that the field is either exactly the nested path or starts with the nested path followed by a delimiter (e.g., `.`).
