#TZZGT: The check `field.startsWith(nestedObjectMapper.fullPath())` is prone to false positives. If a nested object path is a prefix of a root-level field name (e.g., nested object "user" and sort field "username"), the validation will incorrectly throw an `IllegalArgumentException`. The logic should verify that the match is either exact or followed by the path delimiter (e.g., `field.equals(path) || field.startsWith(path + ".")`).

#JQKD7, #17F0B, #TZZGT: The feature flag `INDEX_SORTING_ON_NESTED` is defined and registered in `MapperFeatures`, but it is not used to gate the updated validation logic in `DocumentMapper.validate`. If this functionality is intended to be a toggleable feature, the new validation rules should only apply when this feature is enabled.
