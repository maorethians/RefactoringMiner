#9929M: The logic introduces an inconsistency in how index names are ordered in the error message based on the number of indices. When there are 3 or fewer indices, the code relies on the `Set` implementation's default `toString()` order (which may be non-deterministic for `HashSet`). However, when there are more than 3 indices, it explicitly sorts them alphabetically before picking the first three. For consistent and deterministic error messages, sorting should be applied regardless of the set size.
