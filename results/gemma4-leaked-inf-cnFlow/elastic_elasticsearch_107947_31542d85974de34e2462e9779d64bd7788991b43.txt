#T47P8: In `testSerializationWithConfig`, the call to `assertSerialization(expr)` uses the default `EsqlTestUtils.TEST_CFG` for deserialization via the overloaded method defined in `#3KM8G`. Since `expr` was constructed with a random `config`, and equality for configuration-dependent functions now includes the configuration (`#W5ZM2`), this test will likely fail because the original expression and the deserialized expression (using the default config) will not be equal. The call should be updated to `assertSerialization(expr, config)` to ensure the same configuration is used for both construction and deserialization.
