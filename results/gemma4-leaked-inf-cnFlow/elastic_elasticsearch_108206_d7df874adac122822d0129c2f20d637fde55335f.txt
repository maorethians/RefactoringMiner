#W9TG2: The implementation of `RealMockAppender.append` performs a direct lookup in the `mockAppenders` map using `event.getLoggerName()`. This breaks the hierarchical logging behavior previously provided by Log4j's native appender system (where an appender attached to a logger also captures events from all its descendants). For example, calling `capturing("org.elasticsearch")` will now only capture logs from that exact logger name and no longer capture logs from classes within that package (e.g., `org.elasticsearch.common.SettingsFilter`), which is likely a regression in functionality.

#W9TG2, #7JDG5: The introduction of a single global `RealMockAppender` attached to the root logger means that every log event generated across the entire test suite now incurs the overhead of a map lookup and list iteration, regardless of whether any mock appenders are currently active or relevant to the specific logger.
