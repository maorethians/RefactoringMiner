#9415T: The code performs a direct cast to `Attribute` on the result of `aliases.resolve(attr, attr)`. However, `Alias.unwrap(ne)` returns an `Expression`, which may not necessarily be an `Attribute` (e.g., if the projection defines an alias for a constant or a function call like `eval x = 1 + 1`). If such an alias is used in the groupings, this will trigger a `ClassCastException`. Consider checking if the resolved expression is an instance of `Attribute` before casting.
