#E60YX, #1HQT3: A potential `NullPointerException` exists in the in-memory stash logic. In `filterInputsAndDirsToCreate` (#E60YX), if there are no inputs or output directories, `stashContentsMap.get(PathFragment.EMPTY_FRAGMENT)` will return `null`. This null value is then stored in the `main` stash contents under the workspace name. 
When this sandbox is later reused, `cleanRecursivelyWithInMemoryStashes` (#1HQT3) iterates over the directory entries and passes the value (which would be `null`) into a recursive call. The first line of `cleanRecursivelyWithInMemoryStashes` is `Preconditions.checkNotNull(stashContents)`, which will trigger an exception if the stashed sandbox was empty.
