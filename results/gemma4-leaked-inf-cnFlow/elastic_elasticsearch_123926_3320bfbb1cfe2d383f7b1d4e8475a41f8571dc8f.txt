#ZS2ET: In `checkDataStreamMigrationStatus`, the `migrationInfo` object is used directly in a log message and an exception message:
- `logger.error("error occurred while reindexing data stream [{}], failures [{}]", migrationInfo, ...)`
- `new ElasticsearchException("error occurred while reindexing data stream [" + migrationInfo + "]")`
Since `SystemDataStreamMigrationInfo` (and its parent) does not override `toString()`, this will result in the default Object representation being logged and thrown. It should be replaced with a call to `migrationInfo.getDataStreamName()` or `migrationInfo.getCurrentResourceName()` for clarity.
