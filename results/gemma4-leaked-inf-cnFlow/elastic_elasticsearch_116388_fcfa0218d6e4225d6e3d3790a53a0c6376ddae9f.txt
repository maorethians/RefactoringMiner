#MAWDJ: The `declareObjectArray` call for `SHARD_FAILURES` in the `EqlSearchResponse` parser is incorrectly implemented. The provided lambda `(p, c) -> ShardSearchFailure.EMPTY_ARRAY` acts as the element parser but returns a constant empty array instead of parsing an actual `ShardSearchFailure` object from the input stream. This prevents shard failures from being correctly deserialized when reading the response from XContent.

#CZ9YB, #5AQ6E: Deduplicating shard failures by using `shardFailure.toString()` as a map key is fragile and potentially inefficient. While noted with a TODO, it is recommended to use a more robust identification method or a dedicated deduplication utility if available.
