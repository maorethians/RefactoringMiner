#BANQQ: The change from returning a `singletonList` containing an `UnresolvedAttribute` to throwing an `IllegalStateException` replaces a graceful semantic error reporting mechanism with a runtime exception. This likely degrades the user experience by replacing a descriptive query analysis error (which can be collected and returned to the user) with a server-side crash or generic 500 error. Additionally, `IllegalStateException` is typically used for internal state violations rather than invalid user input/queries.

#K3TR6: The use of a double cast `(List<Alias>) (List)` to bypass type checking when calling `mergeOutputExpressions` is a code smell. This indicates that the return type of `mergeOutputExpressions` (`List<NamedExpression>`) is too generic for this call site. While it may work at runtime if only `Alias` objects are passed in, it is fragile and suppresses compiler warnings that should be addressed via generics in the utility method rather than casting at the call site.
