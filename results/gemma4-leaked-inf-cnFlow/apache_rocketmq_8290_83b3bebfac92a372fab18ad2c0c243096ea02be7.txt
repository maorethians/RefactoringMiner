#1G21S: The logic in the static block will cause a `RuntimeException` when an IPv6 address is retrieved. `UtilAll.getIP()` can return either an IPv4 (4 bytes) or IPv6 (16 bytes) address, but `UtilAll.isInternalIP(ip)` explicitly throws a `RuntimeException("illegal ipv4 bytes")` if the input array length is not exactly 4. Consequently, the `else` block intended to handle IPv6 addresses via `UtilAll.ipToIPv6Str(ip)` is unreachable for IPv6 addresses.
