#XCFTS, #0C7EF, #8WSF3, #35RH5, #ZHNPY, #080GS, #28MVQ, #70PH1: Converting the result to a `TreeSet` before assertion introduces potential runtime exceptions that would have been handled as graceful test failures by Hamcrest. Specifically:

2. If the returned object is not a `Collection` (e.g., when only one value is present and it's returned as a single object), a `ClassCastException` occurs.
3. Since `TreeSet` requires elements to be `Comparable`, any non-comparable elements would cause a `ClassCastException`.

#XCFTS, #0C7EF, #8WSF3, #35RH5, #ZHNPY, #080GS, #28MVQ, #70PH1: The use of `TreeSet` is unnecessary for these containment checks. A `HashSet` would be more performant and avoid the requirement that elements implement `Comparable`.
