#BXEH1, #0FW1C, #26M5T, #9N9TW, #6RRKB: In the `perPosition` method of the lazy evaluators (e.g., `CoalesceBooleanLazyEvaluator`), the code uses the range-based copy:
`result.copyFrom(lastFullBlock, p, p + 1);`
Since this pull request introduces optimized single-position copies (e.g., `copyFrom(block, position)`), it would be more consistent and slightly more efficient to use the new method directly:
`result.copyFrom(lastFullBlock, p);`
This is especially relevant given that other parts of the PR (like the Eager evaluators) specifically adopt these single-position copies for performance gains.
