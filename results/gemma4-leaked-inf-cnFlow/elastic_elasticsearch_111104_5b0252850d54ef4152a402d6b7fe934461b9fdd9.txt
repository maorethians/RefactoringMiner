#3WQHE: The constructor for async GET requests attempts to retrieve the request ID using `getRequest.param("id")`. In Elasticsearch, `RestRequest.param()` retrieves query string parameters, but the ID for async result retrieval is typically provided as a path parameter (e.g., `/_query/async/{id}`). Consequently, this will likely return `null`, causing the logs in `#FKP8Q` and `#EDZA5` to report a null ID instead of the actual request identifier.
