#MH1SV: In `FieldAttribute#info`, both `dataType()` and the null qualifier are removed from the properties list passed to `NodeInfo.create`. This differs from `MetadataAttribute` (#CFE7Y) and `ReferenceAttribute` (#8NQFK), where only the null qualifier is removed and `dataType()` is retained. If `FieldAttribute`'s data type can change independently of the `field` object, removing it from the properties list will prevent `NodeInfo` from detecting those changes during transformations.
