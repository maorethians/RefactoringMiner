In `DataStreamTimestampFieldMapper#postParse` (#0KTA1), the code was updated to use `context.doc().getByKey(...)`, whereas in `TsidExtractingIdFieldMapper#createField` (#ZV025), it continues to use `context.rootDoc().getByKey(...)`. For consistency and to ensure they are accessing the same document instance where metadata keys are stored, `context.doc()` should be used consistently across both mappers.
