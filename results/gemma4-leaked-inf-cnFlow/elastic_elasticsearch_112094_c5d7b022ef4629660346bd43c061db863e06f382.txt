#8VWXS: #### Logic Error in Reflection Filter
The logic used to filter fields in `getDeclaredVersions()` is incorrect and will likely cause an `IllegalArgumentException` if any public non-static fields are added to the class. 
The current condition:
```java
if (false == Modifier.isStatic(mod) && Modifier.isFinal(mod) && Modifier.isPublic(mod)) {
    continue;
}
```
only skips fields that are simultaneously non-static, final, and public. If a field is simply `public` and non-static (but not final), it will pass this check and proceed to `field.get(null)`. Since `field.get(null)` can only be called on static fields, the JVM will throw an `IllegalArgumentException`.
To correctly filter for public static final fields, the condition should skip any field that does not meet all three criteria:
```java
if (!Modifier.isStatic(mod) || !Modifier.isFinal(mod) || !Modifier.isPublic(mod)) {
    continue;
}
```
