#PWYN9: The method chain for the search request contains a redundant call to `.setFetchSource(true)`. This is immediately overridden by the subsequent call to `.setFetchSource(new String[] { request.getField() }, null)`, which implicitly enables source fetching. Removing the first call would improve clarity.

#PWYN9, #WKPJC, #DHJMZ, #0F43S: There is an inconsistency in how thread pool dispatching is handled across the text structure actions. `TransportFindMessageStructureAction` and `TransportFindStructureAction` have been updated to use the new `TextStructExecutor` pattern (using `DIRECT_EXECUTOR_SERVICE` for the action executor and a helper method for generic pool dispatch). However, `TransportFindFieldStructureAction` does not use this helper class and continues to use its original constructor configuration. For better maintainability and architectural consistency, `TransportFindFieldStructureAction` should also be updated to utilize `TextStructExecutor`.
