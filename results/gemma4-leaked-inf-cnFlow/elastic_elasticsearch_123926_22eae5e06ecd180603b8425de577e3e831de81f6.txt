#K9T48: In the `dataStreamMigrationFailed` method, the exception message uses the `migrationInfo` object directly in string concatenation: `"error occurred while reindexing data stream [" + migrationInfo + "]"`. Since `SystemResourceMigrationInfo` does not override `toString()`, this will result in a default Java object reference (e.g., `...SystemDataStreamMigrationInfo@hash`) rather than the actual name of the resource. It should use `migrationInfo.getCurrentResourceName()` for clarity.
