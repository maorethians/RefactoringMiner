#0ZJ70: The assertion uses a ternary operator based on `RemoteClusterAware.isRemoteIndexName(pattern)`, but since `pattern` is hardcoded to `from("test1")`, this condition will always evaluate to the same result (`false`). Using conditional logic in a test case with constant inputs reduces clarity and makes the test appear dynamic when it is not. If both remote and local index scenarios need to be tested, they should be split into separate test methods or handled via a parameterized test.
