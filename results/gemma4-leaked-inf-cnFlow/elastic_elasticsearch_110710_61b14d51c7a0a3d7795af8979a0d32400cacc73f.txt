#FZ7RT: The methods `readNodesFrom` and `writeNodesTo` are implemented using `TransportAction.localOnly()`. Since `NodesFeaturesResponse` is the response for a `TransportNodesAction` (which is distributed by nature) and is registered as a public monitor API (`cluster:monitor/nodes/features`), it must be serializable over the network. Using `localOnly()` will cause any remote request to this action—including those from REST clients or other nodes—to fail with an `UnsupportedOperationException`. These methods should be implemented to properly serialize and deserialize the list of `NodeFeatures`.
