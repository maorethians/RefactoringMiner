#V4JK1: The method `replaceChangeCase` may throw a `NullPointerException` if `bc.right().fold()` returns `null`. Since `BytesRefs.toString(null)` returns `null`, calling `changeCase.caseType().matchesCase(foldedRight)` will trigger an NPE when attempting to call `.codePoints()` on the null string. A null check should be added for `foldedRight` before calling `matchesCase`.
