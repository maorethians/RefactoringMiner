#QE6V2: In `processDoubles`, `processInts`, and `processLongs`, when `valuesBlock.mvSortedAscending()` is true, the code uses relative indices (e.g., `0`, `valueCount - 1`, `lowerIndex`, `upperIndex`) instead of absolute indices when calling `getDouble`, `getInt`, or `getLong`. These calls should be offset by `firstValueIndex` to correctly access the values for the current position in the block.
Example (in `processDoubles`):
- `valuesBlock.getDouble(0)` should be `valuesBlock.getDouble(firstValueIndex)`
- `valuesBlock.getDouble(valueCount - 1)` should be `valuesBlock.getDouble(firstValueIndex + valueCount - 1)`
- `valuesBlock.getDouble(lowerIndex)` should be `valuesBlock.getDouble(firstValueIndex + lowerIndex)`
