#GWK7V: The assertions regarding async status headers are inconsistent with the implementation in `#CKG9M` and the constants defined in `#N3WAZ`:
1. **Header Name Mismatch**: The test asserts the presence of `X-Elasticsearch-Async-Id` and `X-Elasticsearch-Async-Is-Running`, but the implementation only adds headers named `Async-ID` and `Async-running`. Unless these are added by a separate infrastructure layer not shown here, these assertions will fail.
2. **Value Mismatch**: The test expects values `"?0"` or `"?1"` for the running status header. However, the implementation in `#CKG9M` uses `String.valueOf(esqlResponse.isRunning())`, which produces `"true"` or `"false"`.
