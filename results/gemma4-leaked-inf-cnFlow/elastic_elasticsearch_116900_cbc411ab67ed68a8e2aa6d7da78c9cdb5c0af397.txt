#ZX353, #SZ1KN: The removal of the parameterless `getAge()` method in favor of `getAge(Supplier<Long> now)` introduces a breaking API change and reduces ergonomics for callers who do not need to mock time (as seen in the updated test in `#SZ1KN`). 
To maintain backward compatibility and simplify usage, it is recommended to keep the original `getAge()` method as an overload that delegates to the new parameterized version using the default `nowSupplier`:
```java
public TimeValue getAge() {
    return getAge(this.nowSupplier);
}
```
