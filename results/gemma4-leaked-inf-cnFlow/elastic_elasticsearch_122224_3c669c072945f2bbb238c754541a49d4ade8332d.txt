#HCC2E, #1SWTS: There is a potential for duplicate `_id` fields to be added to nested Lucene documents in time-series indices if an explicit ID is provided (`idField != null`).
In `#HCC2E`, if `idField` is not null, the ID is immediately added to the document. However, since this is a time-series index, `TimeSeriesIdFieldMapper#postParse` (in `#1SWTS`) will also execute and add the same ID again to all non-root documents.
If time-series indices are strictly forbidden from having explicit IDs (meaning `idField` is always null), this is not an issue. Otherwise, you should ensure that the ID is only added once.
