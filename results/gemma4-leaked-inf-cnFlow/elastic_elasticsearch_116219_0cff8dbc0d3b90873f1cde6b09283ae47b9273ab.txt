#KXMMK: In the updated filter logic for data streams, if `MetadataIndexTemplateService.findV2Template` returns `null` (meaning no template currently matches the data stream), `dsTemplateName` will be `null`. This leads to a call to `metadata.templatesV2().get(null)`. While most Java `Map` implementations return `null` for a `null` key, some may throw a `NullPointerException`. It would be safer to explicitly check if `dsTemplateName` is `null` before attempting the map lookup.
