#C8X7D: Computing the file digest via `digestUtil.compute(path)` for files that are immediately marked as `omitted = true` in `RemoteBuildEventUploadMode.MINIMAL` is a performance regression. Computing a digest requires reading the entire file from disk; this overhead should be avoided for files that will not be uploaded and (presumably) omitted from the build event stream.

#FQ4EN: The test assertion loop expects all files to have a valid URI (`assertThat(conversion).isEqualTo(...)`), but the test is specifically designed to verify `RemoteBuildEventUploadMode.MINIMAL`, where only log files are uploaded. If omitted files are intended to be excluded from the BEP stream (returning `null` from `pathConverter.apply()`), this assertion will fail for the non-log files. The test should instead verify that only the expected files have URIs and others return `null`.
