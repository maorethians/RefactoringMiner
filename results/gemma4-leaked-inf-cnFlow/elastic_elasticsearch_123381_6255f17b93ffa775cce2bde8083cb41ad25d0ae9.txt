#H7ZRZ, #68BWW: There is a potential logic error when the folded value of the suffix or prefix is `null`. `BytesRefs.toString(null)` returns `null`, and in Java, concatenating a string with a null reference (e.g., `"*" + null`) results in the literal string `"null"`. This would cause the function to generate a Lucene query searching for the actual text "null" instead of handling the null value according to ESQL semantics.
