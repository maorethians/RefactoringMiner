#RVHE9: The method `isCompilationStopped()` violates the Command-Query Separation (CQS) principle. While its name and return type suggest it is a simple predicate (a query), it performs significant side effects, including:
- Modifying global state (`stoppedCompilationTime`).
- Canceling multiple pending compilations in the queue.
- Permanently shutting down the global compilation queue via `shutdownAndAwaitTermination`.
- Logging warnings to the engine logger.
Such a method should be renamed (e.g., to `checkAndHandleCompilationStop`) or split into a query and a separate handler to avoid misleading developers about its impact on the system state.
