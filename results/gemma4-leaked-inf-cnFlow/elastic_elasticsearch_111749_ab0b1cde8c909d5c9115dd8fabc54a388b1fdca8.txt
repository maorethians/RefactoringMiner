#DPPAT: In `processDoubles`, `processInts`, and `processLongs`, when `valuesBlock.mvSortedAscending()` is true, the code accesses values using relative indices (e.g., `0`, `valueCount - 1`, `lowerIndex`, `upperIndex`) instead of absolute indices. These must be offset by `firstValueIndex` to correctly retrieve data from the block.

#N0Y0J: The call to `MvPercentile.process` is missing a `try-catch` block for `IllegalArgumentException`. This is inconsistent with all other evaluators in this chapter (e.g., `#6D0HP`, `#RYMEE`), which catch this exception to register a warning and append a null value instead of allowing the exception to propagate and terminate evaluation.
