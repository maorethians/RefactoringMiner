#NFBQ1, #73AKB: The surrogate expressions for `CountDistinct` and `Median` return scalar values when the input field is foldable (e.g., a constant). This logic fails to account for cases where the source dataset is empty. In such scenarios, these aggregates should typically return 0 or null; however, the current implementation will return a constant value regardless of the number of documents, leading to incorrect results for empty sets.

#QGZHP: The assertions in `testMultiCountAllWithFilter` have been severely weakened. The original test verified that multiple count variants (`count()`, `count(*)`, and `count(1)`) were correctly normalized and deduplicated within the physical plan. Replacing these detailed checks with a simple `anyMatch(EsQueryExec.class::isInstance)` removes verification that the optimizer is still performing the expected deduplication logic.
