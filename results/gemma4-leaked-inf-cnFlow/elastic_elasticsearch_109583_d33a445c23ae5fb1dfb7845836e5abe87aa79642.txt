#JD7BP, #AP56C: In `planHashJoinAsEval`, an `IllegalArgumentException` is thrown if the local table contains anything other than exactly one row (`blocks[b].getPositionCount() != 1`). Because `planHashJoin` calls this method immediately when `matchFields()` is empty, any cross-join with a local table that has zero or multiple rows will now cause the entire planning process to fail. This optimization should be optional; if the "single-row" condition is not met, the planner should fall back to the standard `HashJoin` logic instead of throwing a fatal exception.
