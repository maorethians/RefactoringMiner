#KEMVM: The logic in `doCoordinatorRewrite` for `TermsQueryBuilder` is incorrect. A terms query acts as an OR operation; therefore, it should only be rewritten to a `MatchNoneQueryBuilder` if *none* of the provided terms match the constant field value. The current implementation returns `MatchNoneQueryBuilder` immediately upon encountering the first term that does not match, potentially ignoring subsequent terms that would have resulted in a match.
