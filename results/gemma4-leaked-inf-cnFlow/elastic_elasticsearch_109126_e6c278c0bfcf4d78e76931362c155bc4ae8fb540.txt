#T2D5M: In `buildTable`, the call to `table.addCell()` for the ingest time now passes a raw `long` value (`accumulatedStats.ingestStats.totalStats().ingestTimeInMillis()`). Previously, this value was wrapped in `TimeValue.timeValueMillis()`. Since `TimeValue` provides human-readable formatting (e.g., "10ms"), removing it will change the output of the CAT API from a formatted duration to a raw numeric value.
