#V01KT, #Q8W7W: The logic within `wrapSingleValueQuery` (specifically the creation and rewriting of `SingleValueMatchQuery`) determines if a field contains only single values across the index. This property is independent of the specific row `position`. However, because it is called inside `getQuery`, this expensive rewrite process is repeated for every position in the block. This should be computed once per `QueryList` instance and cached to avoid significant performance degradation.

#V01KT: The `IOException` caught during the rewrite of `singleValueQuery` is silently ignored. If an exception occurs, the unrewritten `singleValueQuery` is added to the `BooleanQuery`. Since Lucene queries generally must be rewritten before execution, this could lead to runtime exceptions or unpredictable behavior during the search phase.
