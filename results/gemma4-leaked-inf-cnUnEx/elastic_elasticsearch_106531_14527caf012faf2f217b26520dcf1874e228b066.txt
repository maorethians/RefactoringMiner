#T04CQ: In `#T04CQ`, the method `getApiKeyCreatorSubject(apiKeyInfo)` is called twice per element in the stream mapping. While the method is lightweight, calculating the subject once and reusing it would be slightly more efficient.
```java
// Current implementation:
apiKeyInfo -> getApiKeyCreatorSubject(apiKeyInfo) == null
    ? null
    : profileUidLookup.get(getApiKeyCreatorSubject(apiKeyInfo))
// Suggested improvement:
apiKeyInfo -> {
    Subject s = getApiKeyCreatorSubject(apiKeyInfo);
    return s == null ? null : profileUidLookup.get(s);
}
```
