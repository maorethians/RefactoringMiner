#NRBJJ, #4GXKG, #EHZJ9, #QV4Z1: The `writeTo` methods in these classes have been changed to serialize the actual `source()` instead of `Source.EMPTY`, but they lack a transport version check. 
Since this pull request introduces `TransportVersions.ESQL_SERIALIZE_SOURCE_FUNCTIONS_WARNINGS` specifically to guard the serialization of source information for other functions (e.g., in `#QHVZG`, `#A9C2C`), these classes should also use that version check. Without it, nodes running older versions will encounter deserialization errors when receiving data from a newer node, as the wire format has changed from a constant `false` (written by `Source.EMPTY`) to potentially `true` followed by source metadata.
