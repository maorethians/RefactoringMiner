#9NA3F, #97B54: The manual construction of a JSON string using string formatting and a custom escaping method is fragile and error-prone. Specifically, while values are processed via `escapeJson`, the keys (`entry.getKey()`) are not escaped. If a key contains double quotes or backslashes, the resulting JSON will be malformed. It is recommended to use a standard JSON serialization library (such as Jackson) to convert the map to a JSON string, which would ensure that both keys and values are correctly handled according to the JSON specification.
