#BCR52, #09SM0: The logic for marking `copy_to` target fields as void in synthetic source has been moved from a loop over a `Set` of unique target fields (previously in `IgnoredSourceFieldMapper.postParse`) to the `createCopyToContext` method. 
Because `createCopyToContext` is invoked for every source field that performs a copy operation, if multiple source fields are configured to copy to the same destination field, that destination field will be added to `ignoredFieldValues` multiple times. This results in redundant stored fields being written to the Lucene document during the post-parse phase, increasing index size and potentially impacting performance.
