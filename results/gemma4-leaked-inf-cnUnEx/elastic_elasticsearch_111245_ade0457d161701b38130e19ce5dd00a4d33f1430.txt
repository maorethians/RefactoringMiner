#YMTM5: The `toXContent` implementation in `getTruncatedInput()` calls `builder.value(TRUNCATED_RECORD_VALUE)`, which results in the "input" field being serialized as a plain string. However, the corresponding integration tests (e.g., in `#21BPQ`) and the logic for `getTruncatedWatchExecutionResult` suggest that this should be an object containing the `TRUNCATED_RECORD_KEY`. As currently written, any code attempting to cast the "input" field to a `Map` (as seen in the tests) will throw a `ClassCastException`.
