#FPRGN: The implementation of `updateTopicList` manually appends a separator to every element in the list, resulting in a trailing separator (e.g., `"topic1;topic2;"`). While this is handled by the subsequent split logic, it is cleaner and more idiomatic to use `String.join(TOPIC_NAME_SEPARATOR, topicList)`. Additionally, be aware that if the input list contains `null` elements, they will be appended as the string `"null"`, which may lead to misleading warning logs in the broker when looking up topic configurations.
