#6KD5S: In `processDoubles`, `processInts`, and `processLongs`, when `valuesBlock.mvSortedAscending()` is true, the code incorrectly uses absolute indices `0` and `valueCount - 1` to retrieve values from the blocks:
```java
if (percentile == 0) {
    builder.appendDouble(valuesBlock.getDouble(0)); // Should be firstValueIndex
} else if (percentile == 100) {
    builder.appendDouble(valuesBlock.getDouble(valueCount - 1)); // Should be firstValueIndex + valueCount - 1
}
```
Since values for a given position in a `Block` are stored between `getFirstValueIndex(position)` (inclusive) and `getFirstValueIndex(position) + getValueCount(position)` (exclusive), using index `0` will result in incorrect data retrieval or an `IndexOutOfBoundsException` if the first value index is not zero. These should be updated to use `firstValueIndex` and `firstValueIndex + valueCount - 1` respectively.
