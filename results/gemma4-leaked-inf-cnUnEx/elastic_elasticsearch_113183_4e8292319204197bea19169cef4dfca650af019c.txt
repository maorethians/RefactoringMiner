#C54JY: In `checkInvariant`, the loop intended to verify that all elements in a bucket are present when in heap mode contains a logic error:
```java
for (long l = rootIndex; l < common.endIndex(rootIndex); l++) {
    if (values.get(rootIndex) == null) {
        throw new AssertionError("values missing in heap mode");
    }
}
```
The check `values.get(rootIndex) == null` uses the constant root index instead of the loop variable `l`. It should be `values.get(l) == null` to correctly validate every element in the bucket.
