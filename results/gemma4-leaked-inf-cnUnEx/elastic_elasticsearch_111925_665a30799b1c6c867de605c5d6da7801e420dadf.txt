#MQW4Z: The assignment `floatArraySupplier = sim == COSINE ? FLOAT_ARRAY_RANDOM_FUNC : floatArraySupplier;` mutates the variable for all subsequent iterations of the loop. Since `COSINE` is the first element in the list, `floatArraySupplier` is set to `FLOAT_ARRAY_RANDOM_FUNC` and remains so for `DOT_PRODUCT`, `EUCLIDEAN`, and `MAXIMUM_INNER_PRODUCT`. If these other similarity types were intended to use a different supplier (the one originally held by `floatArraySupplier`), this logic is incorrect. A local variable should be used within the loop instead to avoid leaking state between iterations.
