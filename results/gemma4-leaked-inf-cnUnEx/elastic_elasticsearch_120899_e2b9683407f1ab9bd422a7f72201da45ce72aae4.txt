#0ZJ70: The method `RemoteClusterAware.isRemoteIndexName(pattern)` is called using the result of `from("test1")`, which returns a full ESQL clause (e.g., `"FROM test1"`) rather than an index expression. 
`isRemoteIndexName` expects an index expression and contains specific validation logic for the start of the string (e.g., checking that it does not start with `:` or `<`). By passing a string that begins with `"FROM "`, these prefix checks are bypassed, which is a misuse of the API and could lead to incorrect results if the index name itself starts with an invalid character. The check should be performed on the raw index name before it is wrapped in the `from()` helper.
