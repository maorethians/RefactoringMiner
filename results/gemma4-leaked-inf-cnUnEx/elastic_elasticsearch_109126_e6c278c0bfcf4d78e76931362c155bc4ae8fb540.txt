#T2D5M: The assertion `assert configs.size() == accumulatedStatsMap.size();` is potentially incorrect. It assumes that every model configuration has at least one corresponding deployment with stats. In scenarios where a model exists but is not yet deployed, `accumulatedStatsMap` will be smaller than `configs`, causing the assertion to fail if enabled. Since the subsequent loop already handles missing stats gracefully using `Objects.requireNonNullElse(..., AccumulatedStats.EMPTY)`, this assertion is unnecessary and risky.

#T2D5M: The cell for ingest time has been changed from adding a `TimeValue` object (`TimeValue.timeValueMillis(...)`) to adding a raw `long` value (`accumulatedStats.ingestStats.totalStats().ingestTimeInMillis()`). In Elasticsearch's `Table` implementation used for cat APIs, providing a `TimeValue` typically ensures the output is formatted as a human-readable duration (e.g., "10ms", "1s"). Switching to a raw long will result in the API returning raw milliseconds, which is a regression in output formatting.
