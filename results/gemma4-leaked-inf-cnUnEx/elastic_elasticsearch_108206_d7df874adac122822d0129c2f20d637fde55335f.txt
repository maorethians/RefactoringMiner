#W16R5: The implementation of `RealMockAppender.append` uses a flat map lookup (`mockAppenders.getOrDefault(event.getLoggerName(), ...)`) to find applicable appenders. This breaks the hierarchical nature of Log4j logging. 
Previously, calling `Loggers.addAppender(logger, this)` ensured that any log events for that logger or its descendants were captured. With the new map-based approach, a `MockLogAppender` registered for a package (e.g., `"org.elasticsearch.test"`) will no longer capture logs from classes within that package (e.g., `"org.elasticsearch.test.MyClass"`), as the logger name will not be an exact match in the map.
