#NFBQ1, #5NMNF: The surrogates for `CountDistinct` and `Median` return constant values when the input field is foldable (e.g., a literal). This logic fails to account for empty relations: an aggregate over zero rows should return 0 for counts or `null` for medians, but these implementations will return the value of the constant regardless of whether any rows exist.

#WNGXM: The condition for pushing statistics to the source is simplified from checking if there are multiple *distinct* stat names to simply checking if there are multiple stats (`stats.size() > 1`). This prevents the optimizer from pushing multiple identical statistics (e.g., `COUNT(*), COUNT(*)`) to the source, which is likely an unnecessary restriction and a regression in optimization potential.
