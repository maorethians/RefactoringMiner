#9415T: The cast to `Attribute` when adding the resolved expression to the `replaced` set (`replaced.add((Attribute) aliases.resolve(attr, attr))`) may cause a `ClassCastException`. If a projection defines an alias for a non-attribute expression (e.g., a function call or a constant) and that alias is subsequently used in a grouping, `aliases.resolve` will return the underlying `Expression`, which cannot be cast to `Attribute`.

#9415T: The mapping `.map(attr -> (Expression) attr)` in the return statement is redundant because `Attribute` already extends `Expression`. This can be simplified to `.toList()`.
