#TZZGT: The use of `field.startsWith(nestedObjectMapper.fullPath())` to determine if a sort field is under a nested object is potentially incorrect. If a nested object has a path that is a prefix of another field's name (e.g., a nested object named `user` and a keyword field named `username`), this check will return `true` for the unrelated field, incorrectly throwing an `IllegalArgumentException`. 
To correctly identify if a field is within a nested object, you should verify that the field either exactly matches the path or starts with the path followed by the delimiter (e.g., `field.equals(path) || field.startsWith(path + ".")`).
