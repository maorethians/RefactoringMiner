#N4HG7: The validation logic using `field.startsWith(nestedObjectMapper.fullPath())` may produce false positives. If a field intended for index sorting shares a prefix with a nested object's path but is not actually contained within it (e.g., sort field "username" and nested object "user"), an `IllegalArgumentException` will be incorrectly thrown. The check should verify that the field is either exactly equal to the nested path or starts with the nested path followed by a dot separator.
