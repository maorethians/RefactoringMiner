#58VK4, #56R62: The implementation uses `FoldContext.small()` to evaluate the constant expressions (`suffix` and `prefix`). According to the provided documentation for `FoldContext.small()`, this method is intended for use in tests; using it in production code is a signal that either `Expression#fold` should not be called or a shared `FoldContext` from the configuration should be used instead.

#58VK4, #56R62: There is a potential `NullPointerException` if the foldable expression (`suffix` or `prefix`) evaluates to `null`. In such cases, `BytesRefs.toString()` returns `null`, which is then passed directly into `QueryParser.escape()`. Since ESQL functions are expected to handle `null` arguments gracefully (returning `null`), the translation logic should explicitly check for `null` values after folding before attempting to escape and build the Lucene query.
