#91T4G: The logic in `newSnapshot` appears to be inconsistent with the condition used to trigger its call in `#1N64B`. While `#1N64B` triggers source synthesis if either recovery synthetic source is enabled OR inference fields are present, `newSnapshot` only returns a `LuceneSyntheticSourceChangesSnapshot` when recovery synthetic source is enabled. 
If inference fields are present but recovery synthetic source is disabled, `synthesizeSource` will be called (via `#1N64B`), but it will utilize a standard `LuceneChangesSnapshot` instead of the synthetic one, likely defeating the purpose of the synthesis for these documents. The condition in `newSnapshot` should be updated to include the check for inference fields: `engineConfig.getMapperService().mappingLookup().inferenceFields().isEmpty() == false`.
