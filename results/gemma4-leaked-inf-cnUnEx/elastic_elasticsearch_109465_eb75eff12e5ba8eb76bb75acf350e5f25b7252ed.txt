#8M346: In the static initializer block for `LOCALE_DATA`, the entry for the Irish locale (indicated by the variable name `gaData` and the specific locale data) is added using `new Locale("fr")`. This causes the previously defined French locale data to be overwritten, meaning requests for French locale names will return Irish data, and requests for Irish locale names will not find an entry in this provider. The key should be changed to `new Locale("ga")`.
