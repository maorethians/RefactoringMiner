#RTP4Y: The exit code is being set on the `executionInfo` builder, but it is not being set on the `result` (`TestResultData.Builder`) builder. However, several test cases (e.g., #GCPFY and #VN9JW) assert that the aggregate result data contains the correct non-zero exit code. Since this method already takes the `result` builder as a parameter and updates it for other fields (like `setRemotelyCached`), it should likely also call `result.setExitCode(spawnResult.exitCode())` to ensure the aggregate result is correctly populated.
