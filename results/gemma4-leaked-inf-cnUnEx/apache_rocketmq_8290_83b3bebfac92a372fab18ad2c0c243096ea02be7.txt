#ZSHSN: The logic used to determine whether to call `UtilAll.ipToIPv4Str(ip)` or `UtilAll.ipToIPv6Str(ip)` is incorrect. It currently relies on `UtilAll.isInternalIP(ip)`, which only checks if an IPv4 address belongs to private/internal ranges. If `UtilAll.getIP()` returns a public IPv4 address, `isInternalIP` will return `false`, causing the code to call `ipToIPv6Str`. Since a public IPv4 address has a length of 4 bytes and `ipToIPv6Str` requires exactly 16 bytes, it will return `null`, resulting in `LOCAL_ADDRESS` being null. The decision should be based on the length of the IP byte array (e.g., 4 for IPv4, 16 for IPv6) rather than whether the address is internal.
