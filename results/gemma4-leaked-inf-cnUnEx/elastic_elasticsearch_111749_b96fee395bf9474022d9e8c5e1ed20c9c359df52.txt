#NJN3B: In the methods `processDoubles`, `processInts`, and `processLongs`, when `valuesBlock.mvSortedAscending()` is true, the code uses relative indices (e.g., `0`, `valueCount - 1`, `lowerIndex`, `upperIndex`) to retrieve values from the block. However, according to the `DoubleBlock`/`IntBlock`/`LongBlock` API, these methods require absolute value indices. The retrieved `firstValueIndex` must be added to these offsets (e.g., `valuesBlock.getDouble(firstValueIndex + lowerIndex)`) to correctly access the data for the current position.
