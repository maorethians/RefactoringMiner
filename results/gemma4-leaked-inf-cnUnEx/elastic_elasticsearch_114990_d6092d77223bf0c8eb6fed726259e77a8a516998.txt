#FT0CW: The rewrite logic for `TermsQueryBuilder` is incorrect. A terms query should match if *any* of the provided values match the field (logical OR). However, the current implementation returns a `MatchNoneQueryBuilder` immediately when the first value in the list does not match (`tierFieldQuery instanceof MatchNoDocsQuery`). The loop should instead continue evaluating other values and only return `MatchNoneQueryBuilder` if all values fail to match.
