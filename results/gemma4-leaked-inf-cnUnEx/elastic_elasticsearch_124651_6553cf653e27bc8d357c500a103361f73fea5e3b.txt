#TDW5X: The method `resolveSystemDataStreamsToDelete` relies on `currentState.metadata().getProject()`, which is marked as `@Deprecated(forRemoval = true)` and intended to be removed as part of the multi-project transition. 
Given that this pull request introduces project-aware lookup methods in `Metadata` (e.g., `lookupProject` and `projectFor`) and implements multi-project logic in `MetadataDataStreamsService.deleteDataStreams`, this method should be updated to resolve data streams across all projects rather than assuming a single project context.
