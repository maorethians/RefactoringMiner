#1VVZJ: Using `ctx.getParent().getText()` in the error message for a depth limit violation can be problematic. Since this exception is thrown when expressions are deeply nested (up to 500 levels), the parent context may contain a very large string representation of the query, potentially leading to excessive memory allocation or performance degradation during the creation of the exception message.
