#YXCK1: In `MvMedianAbsoluteDeviation`, the `@MvEvaluator` annotation for the `Double` type is missing the `ascending` attribute:
```java
@MvEvaluator(extraName = "Double", finish = "finish", single = "single")
static void process(Doubles doubles, double v) { ... }
```
While a corresponding `ascending` method for doubles is implemented in the class, the omission of this attribute in the annotation means that the generated `MvMedianAbsoluteDeviationDoubleEvaluator` will not utilize the optimized path for sorted blocks (unlike the Int, Long, and UnsignedLong evaluators). Adding `ascending = "ascending"` to the annotation would enable this optimization.
