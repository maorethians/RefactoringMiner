#6GX73: The logic for deriving `routingHash` from the document ID assumes that `context.sourceToParse().id()` is both non-null and a valid Base64 encoded string. 
1. **Null Safety**: The code uses an `assert` to check if the ID is null. Since assertions are typically disabled in production, this will result in a `NullPointerException` when calling `Base64.getUrlDecoder().decode(null)`. Given that the deleted test in `#QQD59` specifically covered cases where the ID was null, this represents a regression from a controlled exception (or previous fallback logic) to a runtime crash.
2. **Encoding Assumption**: The use of `Base64.getUrlDecoder().decode(...)` will throw an `IllegalArgumentException` if the document ID is not a valid Base64 string (e.g., if it is a user-provided custom ID). 
Consider adding explicit null checks and handling potential decoding failures to ensure robustness.
