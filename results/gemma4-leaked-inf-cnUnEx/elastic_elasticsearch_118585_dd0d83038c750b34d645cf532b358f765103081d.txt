#PF9T2: The method `extractMinWindowSize` uses `Math.min` to determine the `rankWindowSize` for the `CompoundRetrieverBuilder`. If multiple rescorers are configured with different window sizes, using the minimum value will constrain all rescorers to that smallest window, effectively ignoring the larger windows requested by other rescorers. To ensure that every rescorer can operate on its intended number of documents, `Math.max` should be used instead.
