#KXMMK: In `findRolloverTargetDataStreams`, `MetadataIndexTemplateService.findV2Template` can return `null` if no template matches the data stream. If this happens, the code proceeds to call `metadata.templatesV2().get(dsTemplateName)` with a `null` key. Depending on the underlying map implementation used for templates in the cluster state, this could potentially throw a `NullPointerException`. It is safer to explicitly check if `dsTemplateName` is `null` and return `true` immediately, as any new matching template would then become the winner.
