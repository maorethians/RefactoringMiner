#QH0WS: The `configureAndRun` method calls `startElasticsearch()` regardless of whether the distribution is Docker-based. However, for Docker distributions, `runContainer(distribution(), builder)` is called first, which according to its documentation already runs the container and verifies that Elasticsearch has started successfully. This makes the subsequent call to `startElasticsearch()` redundant or potentially problematic if it attempts to start a second instance of the process within the same container.
