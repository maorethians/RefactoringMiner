#42A8K, #F6E8V: In the `equals` method of both `Lookup` and `HashJoinExec`, the `tableName` field is compared against `lookup.matchFields` (a list) instead of `lookup.tableName`. This will always return false when comparing two different objects and is a logic error.

#HFFJ1: In the `resolveLookup` method, if the first call to `maybeResolveAttribute(ua, localOutput)` successfully resolves the attribute (i.e., it no longer returns an `UnresolvedAttribute`), the code enters the `else` block and calls the exact same method again with the same arguments. This is redundant and serves no purpose.
