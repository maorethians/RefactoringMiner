#XCFTS, #080GS, #28MVQ, #70PH1, #EJ46D, #FTDPG, #B7N6C, #E5PBT: The replacement of `assertThat(..., containsInAnyOrder(values))` with a conditional check using `set.containsAll(Arrays.asList(values))` introduces a logic bug in the tests. 
`set.containsAll(...)` only verifies that all expected values are present (a superset check). If the result contains additional unexpected elements, `containsAll` will return `true`, and the actual assertion (`assertThat`) will be skipped. This changes the test from verifying an exact match to verifying a minimum set of values, meaning tests that should fail when extra data is returned will now incorrectly pass.
