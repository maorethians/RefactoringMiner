#V01KT: The `wrapSingleValueQuery` method is called within `getQuery(int position)`, meaning it executes for every single value in a block. Inside this method, `singleValueQuery.rewrite(...)` is called, which iterates over all leaves of the index reader to determine if the field is single-valued. Since the "single-valuedness" of a field is a property of the index and not the specific value at a position, performing this check per-row is highly inefficient. This logic should be computed once per operator or cached.

#V01KT: The `IOException` caught during the query rewrite in `wrapSingleValueQuery` is ignored. If an exception occurs, the method proceeds to use the unrewritten `singleValueQuery` within a `BooleanQuery`. Executing an unrewritten query can lead to runtime exceptions or incorrect results during the search phase; this exception should be handled more robustly (e.g., by wrapping it in a `RuntimeException`).
