#YK1DQ, #7A3D9, #Z938G: The helper methods for pretty-printing lists and arrays are susceptible to `NullPointerException`. Specifically:
1. In `prettyPrintList`, using `.map(Object::toString)` will throw an NPE if any element within the list is null. Using `String.valueOf` or a null-safe check would be more robust.
2. In `prettyPrintArrays`, calling `Arrays.asList(actualArray)` will throw an NPE if `actualArray` itself is null.
Since these methods are used to generate error messages for failing tests, a crash here would mask the original test failure with a `NullPointerException`, making debugging more difficult.
