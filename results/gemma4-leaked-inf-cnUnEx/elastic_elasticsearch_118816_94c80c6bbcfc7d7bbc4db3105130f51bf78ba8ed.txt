#WYSR9: In the `collect` method, calling `.toString()` on the result of `docValues.nextValue()` and then wrapping it in a `new BytesRef(...)` is inefficient. Since flattened field values are stored as binary (typically UTF-8 with null separators), this process involves unnecessary string decoding and re-encoding. If the expected type is `BytesRef`, it should be cast directly: `(BytesRef) docValues.nextValue()`.
