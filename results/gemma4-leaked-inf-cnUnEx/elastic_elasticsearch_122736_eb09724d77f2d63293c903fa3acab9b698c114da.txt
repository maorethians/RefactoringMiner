#99QNZ: The use of leading slashes in `.resolve("/config")`, `.resolve("/data1/")`, etc., will cause `Path.resolve` to treat these as absolute paths on Unix-like systems. According to the Java `Path.resolve` specification, if the passed argument is an absolute path, it returns the argument directly, ignoring the base path (`TEST_BASE_DIR`). To correctly resolve these relative to the temporary directory, the leading slashes should be removed (e.g., `.resolve("config")`).
