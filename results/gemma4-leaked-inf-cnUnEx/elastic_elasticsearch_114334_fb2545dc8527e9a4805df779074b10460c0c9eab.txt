#XTGC9, #A3H7F, #3XA9T: These methods implement the logic of converting `TEXT` to `KEYWORD` manually. For consistency and maintainability, they should use the `noText()` helper method introduced in `DataType.java` (#YR8HH), as is done in other parts of this chapter (e.g., #JE5T7, #1C1TV).

#SY850: The lazy evaluation implementation is highly inefficient. Creating a new `Page` object and an array of filtered blocks for every single position (`p`) within the loop will cause significant memory pressure and GC overhead, especially for large pages. Consider using a more performant way to evaluate positions individually without allocating new page structures per row.
