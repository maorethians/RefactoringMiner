#SWA5V: This change resolves a `TODO` by enabling nested fields in the random data generator when subobjects are not disabled (`subobjectsDisabled == false`). This increases the coverage of the random data challenge tests.

#TA369, #K7P7D: These changes remove manual object wrapping (`startObject`/`endObject`) within `NestedSyntheticFieldLoader`. By delegating the writing to `leafSourceLoader.write`, the responsibility for defining the object boundaries is moved to the child loader. This prevents double-wrapping and allows the child loader to decide if it should be written as a value or an empty object.

#D67T5: The logic in `SyntheticSourceFieldLoader` is refactored to ensure that every call to `write` (that doesn't return early) results in a balanced JSON object. Specifically, fragments (`isFragment == true`) are now wrapped in an object `{ ... }`, whereas previously they were written as raw fields. This change complements the removals in `#TA369` and `#K7P7D`.

#125DJ: The new test case `testSyntheticNestedWithEmptyObject` specifically verifies that a nested field containing an empty object is correctly serialized as `{}` in the synthetic source, confirming the fix for the "empty nested objects" bug mentioned in the `#SWA5V` comments.
