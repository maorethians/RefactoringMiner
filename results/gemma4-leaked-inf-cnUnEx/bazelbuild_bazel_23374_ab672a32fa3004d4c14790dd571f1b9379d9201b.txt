#C8X7D: In `readPathMetadata`, when `remoteBuildEventUploadMode` is `MINIMAL` and a file is determined to be unimportant, the code still calls `digestUtil.compute(path)`. Since these files are marked as `omitted = true` and will not be uploaded, computing their digest (which involves reading the file from disk) is an unnecessary performance overhead. Consider passing `null` for the digest in this case.
