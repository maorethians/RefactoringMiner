#ME3CJ: The `server` field is declared as `static`, but it is used within a class extending `ExternalResource` intended to be managed by test rules (e.g., `@ClassRule`). This will cause conflicts if multiple test classes instantiate this server, as they will share and overwrite the same static instance. It should be an instance field.

#ME3CJ: In `consumerThread()`, the `while (consumerRunning)` loop contains a conditional check `if (consumer != null)`. If the consumer has not yet been set via `addMessageConsumer`, the thread will enter a tight busy-wait loop, consuming excessive CPU cycles until the consumer is assigned. The blocking call `received.poll(...)` should be moved outside the `if (consumer != null)` block or a sleep/wait mechanism should be added to prevent spinning.
