#6V49M: The `NodesFeaturesResponse` class overrides `readNodesFrom` and `writeNodesTo` to call `TransportAction.localOnly()`. This effectively makes the response non-serializable over the transport layer. Since this action is registered in `ActionModule` with a public `ActionType`, it can be invoked by remote clients or via REST. Any such remote request will cause the coordinating node to throw an `UnsupportedOperationException` when attempting to serialize the response to send it back to the client. These methods should be implemented to support standard serialization of the node features list.
