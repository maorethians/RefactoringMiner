#C55PY: The exception message in `dataStreamMigrationFailed` concatenates the `migrationInfo` object directly into the string: `"error occurred while reindexing data stream [" + migrationInfo + "]"`. This will result in the default `toString()` representation (likely the class name and hashcode) being logged. It should instead use `migrationInfo.getDataStreamName()` to provide a meaningful error message.
