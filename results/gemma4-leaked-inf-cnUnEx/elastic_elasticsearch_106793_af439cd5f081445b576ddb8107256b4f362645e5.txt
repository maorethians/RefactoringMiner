#V572M: After calling `listener.onFailure(...)` when no clusters exist, the method should return immediately. While the current logic prevents subsequent blocks from executing, failing to return is a risky pattern that could lead to bugs if future modifications add code to the end of the method.

#RH5K1, #KNB3Y: The timeout for `latch.await` has been reduced from 10 seconds to 1 millisecond and wrapped in an assertion. A 1ms timeout is extremely aggressive and likely to cause flaky tests in CI environments where thread scheduling can introduce slight delays, even for nominally synchronous operations.
