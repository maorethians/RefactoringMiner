#JGFND: The check for `indexMigrationInProgress` uses `cause.equals(SystemIndices.MIGRATE_SYSTEM_INDEX_CAUSE)`. If the `cause` variable is null (which can occur during standard index creation requests), this will throw a `NullPointerException`. It is safer to use `SystemIndices.MIGRATE_SYSTEM_INDEX_CAUSE.equals(cause)` to avoid this risk.
