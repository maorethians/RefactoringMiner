#NB3T3: In `checkDataStreamMigrationStatus`, the `migrationInfo` object is passed directly to the logger (line 587) and concatenated into an exception message (line 591). Since `SystemResourceMigrationInfo` does not provide a consistent `toString()` implementation across its subclasses, this will result in inconsistent or unhelpful log output (e.g., default Object memory addresses for data streams). Use `migrationInfo.getCurrentResourceName()` instead to ensure the resource name is logged.
