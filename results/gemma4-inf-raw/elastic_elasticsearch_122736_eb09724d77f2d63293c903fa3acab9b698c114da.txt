#2DBNM: The use of `.resolve()` with paths starting with a leading slash (e.g., `TEST_BASE_DIR.resolve("/config")`) will likely result in the base directory being ignored. In Java, if the argument to `resolve` is an absolute path—and on both Unix and Windows, a path starting with `/` is considered absolute (relative to the root)—the method returns the argument itself rather than appending it to the base path. To ensure these paths are created within the temporary directory, remove the leading slashes (e.g., `.resolve("config")`).

#DXK13, #6CKFB: The removal of assertions in `FilesEntitlement` combined with the deletion of corresponding failure tests in `PolicyParserFailureTests` removes validation for path types (absolute vs. relative). If these invariants are necessary for the correct operation of `AbsolutePathFileData` and `RelativePathFileData`, this validation should be replaced with explicit checks that throw a `PolicyParserException` rather than being removed entirely.
