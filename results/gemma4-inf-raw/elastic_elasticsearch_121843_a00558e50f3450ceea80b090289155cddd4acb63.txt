#TAT9E: The logic for registering the completion listener on `asyncTask` appears to be incorrect. 
```java
if (asyncTask.addCompletionListener(() -> ActionListener.running(getResults)) == false) {
    getResults.run();
}
```
Assuming `addCompletionListener` accepts a `Runnable`, the provided lambda is a `Runnable` that, when executed, calls `ActionListener.running(getResults)`. Since `ActionListener.running()` is a factory method that returns an `ActionListener` instance without executing the underlying runnable, the `getResults` logic will never actually be triggered upon task completion. 
It should likely be changed to pass the `getResults` runnable directly:
`asyncTask.addCompletionListener(getResults)`
