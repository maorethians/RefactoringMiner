#DBFV1: The `ClassWriter` instantiation `new ClassWriter(classReader, 0)` is incorrect. The `org.objectweb.asm.ClassWriter` constructor does not accept a `ClassReader` as an argument; it only accepts an integer for compute frames (e.g., `new ClassWriter(0)`). This will cause a compilation error.

#DBFV1: The logic in the `transform` method iterates over `patchersToApply` and calls `outputs.file(...)` with the same filename (`-patched.jar`) for every matching patcher. If multiple patchers match the same input JAR, each subsequent call to `patchJar` will overwrite the previous one using the original `inputFile` as the source. Consequently, only the patches from the last matching patcher in the list will be preserved. To apply all applicable patches, you should aggregate all required class patches into a single map and perform the patching process once per JAR.
