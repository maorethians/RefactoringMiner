#D1DNN: In the `readComplete` method, there is a logic error when handling `Native.ERRNO_ECANCELED_NEGATIVE`. The code performs a check on the `pending` flag to decide whether to call `doBeginReadNow()`, but then immediately calls `doBeginReadNow()` unconditionally regardless of the result of that check. This results in either a duplicate call (if `pending` is true) or an incorrect call (if `pending` is false), potentially scheduling a read when it should not be.
