#21N6P: The logic change is correct. Previously, hidden indices (like data stream backing indices, e.g. `.ds-foo-000001`) would fall into the `else` branch which rejects match-all patterns (`*`). This meant a template with pattern `*` and a `DataStreamTemplate` would not match the hidden write index of a data stream. The fix correctly relaxes the matching for hidden indices *only* when the template explicitly declares a data stream template, preserving the existing stricter behavior for all other templates.

#CRDNJ: The test validates the fix by asserting that a match-all template with a `DataStreamTemplate` matches both a non-hidden and a hidden index name. This is the core scenario the fix targets.
