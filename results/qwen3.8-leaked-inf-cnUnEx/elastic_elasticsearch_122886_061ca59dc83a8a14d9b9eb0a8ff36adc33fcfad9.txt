#NM6HQ, #T8Z4N: The condition `System.getProperty("generateDocs") == null || true` is always `true`, which means both `renderSignature` and `renderDocs` will unconditionally return early and never execute their body. This looks like a debugging artifact (e.g., temporarily disabling doc generation during local development) that was accidentally left in. It will silently break documentation generation for all function tests. The `|| true` should be removed to restore the original guard: `if (System.getProperty("generateDocs") == null)`.
