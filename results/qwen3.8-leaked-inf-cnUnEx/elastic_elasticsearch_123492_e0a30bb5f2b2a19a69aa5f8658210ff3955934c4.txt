#QJ3B4: The change from `context.functionRegistry()` to `context.functionRegistry().snapshotRegistry()` in the implicit casting path is a significant behavioral shift. Based on the `SnapshotFunctionRegistry` constructor shown in this chapter, it throws `IllegalStateException` when `Build.current().isSnapshot() == false`. If `snapshotRegistry()` unconditionally constructs a `SnapshotFunctionRegistry`, then **every** implicit casting operation in a non-snapshot build would fail with that exception.
Please confirm that `snapshotRegistry()` is guarded (e.g., returns `this` in non-snapshot builds) or that this code path is only reachable in snapshot builds. If it is reachable in all builds, this will be a regression.
