#R46E3, #K5V5S, #21Q8S, #TBAY7: The regex fix in `#R46E3` (changing `".*\\s"` to `"\\S+\\s"`) is correct — the old greedy `.*` would consume the trailing newline as part of the `\\s` match, leaving nothing for `nextInt()`. The new pattern correctly skips only the first token.

#TBAY7: The second call to `scratch.file("cgroup/cpu/cpu.max", "max 1000\n")` will throw an `IOException` at runtime. Per the `FsApparatus.file()` implementation (shown in the dependency), it explicitly checks `if (file.exists())` and throws `"Could not create scratch file (file exists)"`. Since the file was already created by the first `scratch.file(...)` call in the same test, this second call will always fail.
You likely need to either:
- Delete the file before re-creating it (e.g., `scratch.path("cgroup/cpu/cpu.max").getPathFile().delete()`), or
- Use a different mechanism to overwrite the file content, or
- Split this into two separate test methods, each creating its own scratch file.
