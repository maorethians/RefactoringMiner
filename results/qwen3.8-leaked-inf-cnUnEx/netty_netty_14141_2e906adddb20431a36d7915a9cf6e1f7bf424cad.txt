#5TPQW: Minor style suggestion: the `else` branch after a `return` statement is redundant. The code can be simplified by removing the `else` and letting the final `return` fall through:
```java
if (hostString.charAt(0) == '[' && hostString.charAt(hostString.length() - 1) == ']') {
    return hostString;
}
return '[' + hostString + ']';
```
This is functionally identical but slightly more readable and avoids an unnecessary nesting level.
