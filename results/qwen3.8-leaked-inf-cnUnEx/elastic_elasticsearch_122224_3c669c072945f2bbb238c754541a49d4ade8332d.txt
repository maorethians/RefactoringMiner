#1SWTS: The `assert context.id() != null;` is redundant with the null-check already inside `DocumentParserContext#id()` (which throws `IllegalStateException` when `id` is null). While harmless, it may give the impression that `id()` could return null silently. Consider removing the assert to avoid suggesting a code path that `id()` already guards against, or alternatively keep it as documentation of the invariant — but be aware that in production (assertions disabled), the actual protection comes from `id()`'s internal check, not from this line.
