#Z090K, #M03EF: In `foldable()`, when a condition folds to a `List` (multivalued field), the method returns `true`, signaling the expression is foldable. However, `Case.fold()` has been removed (#Z090K), so the inherited `Expression.fold()` will throw `QlIllegalArgumentException("Should not fold expression")`. If any caller in the planner follows the pattern `if (expr.foldable()) { expr.fold(); }` without a catch, this will be an unhandled exception. Either `foldable()` should return `false` for the multivalued case (since the expression genuinely cannot be constant-folded), or the `fold()` override should be retained with a guard that throws a more descriptive error. As written, the contract between `foldable()` and `fold()` is inconsistent.
