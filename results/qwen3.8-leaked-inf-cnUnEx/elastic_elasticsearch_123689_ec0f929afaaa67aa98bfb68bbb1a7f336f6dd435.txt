#284E7HFED8FJ: This test uses Windows-specific path syntax (backslash separators, drive letters `C:\`, `D:\`, UNC-style `\\.\pipe\`) and asserts parent/child path relationships that only hold when backslashes are recognized as path separators. On a non-Windows platform, `Path.of("\\\\.\\pipe\\")` and `Path.of("\\\\.\\pipe\\bar")` are each a single path component (backslashes are literal characters), so the "child is readable under parent" assertion would fail. The test should be guarded with `assumeTrue(Platform.WINDOWS.isCurrent())` to skip on non-Windows CI, consistent with the pattern used in `testPathOrderWindows` and `testFollowLinks` in this same PR.
