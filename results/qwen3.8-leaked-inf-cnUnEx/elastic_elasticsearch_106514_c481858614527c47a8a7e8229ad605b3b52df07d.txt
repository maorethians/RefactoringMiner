#71RPM: The `REMOVE_MISSING` field is declared `public static` but is missing `final`. Every other shared constant in this class (`NOT_ACKNOWLEDGED`, `ACKNOWLEDGED_NO_ERRORS`, `ACTION_FIELD`, `SUCCESS_FIELD`, `ERROR_FIELD`) is `final`. Without `final`, the reference could be reassigned by any code in the same package or via reflection, silently breaking the "shared immutable sentinel" contract. It should be:
```java
public static final AliasActionResult REMOVE_MISSING = new AliasActionResult(
    AliasActions.Type.REMOVE,
    false,
    "aliases_not_found_exception"
);
```

#71RPM: There is no dedicated unit test exercising the new serialization round-trip of `IndicesAliasesResponse` and `AliasActionResult` (write → read via `StreamInput`/`StreamOutput`), including the BWC path where `getTransportVersion()` is *before* `ALIAS_ACTION_RESULTS` (i.e., the `else` branch that defaults `errors = false` and `actionResults = List.of()`). The existing tests in this chapter only update the response *type* in mocks; they do not verify that a response serialized by a new node is correctly deserialized by an old node (and vice-versa). A focused test that writes an `IndicesAliasesResponse` with a non-empty `actionResults` list at the new transport version, then reads it back at both the new and an older transport version, would guard against future serialization-order regressions.
