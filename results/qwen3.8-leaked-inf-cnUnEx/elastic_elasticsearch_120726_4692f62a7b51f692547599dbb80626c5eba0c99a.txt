In a production code path that affects query correctness, this is risky: if the rewrite fails, the code falls through and adds the *unrewritten* `SingleValueMatchQuery` into a `BooleanQuery` as a `FILTER` clause. If the intent is to degrade gracefully, the method should return the original `query` (as it does for `MatchAllDocsQuery`) rather than wrapping an unrewritten query.
