#6C9E4: The `circuitBreaker` parameter passed into the lambda is never used. The `example` state is created with a separate 100 MB breaker, and `createUsingParamsFrom(example)` registers the new state against `example.breaker` (the 100 MB one). Consequently, when the helper adds data to the returned state, it only touches the 100 MB breaker, so the small-limit breaker created by `testCircuitBreakerTrip` is never exercised. The test will always succeed on the first iteration without ever triggering a `CircuitBreakingException`, making it a no-op that provides no real coverage of the trip-and-release path.
Consider either:
- Creating `example` with the `circuitBreaker` parameter supplied by the helper, or
- Writing a dedicated test that directly asserts on the breaker actually used by `createUsingParamsFrom`.
