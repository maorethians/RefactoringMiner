#Z264M: The test verifies the plan *structure* (MvExpand is preserved, correct nesting), but does not assert that the `MvExpand`'s target expression is actually an `Alias` wrapping a null `Literal`. A check like `as(mvExpand.target(), Alias.class)` (or equivalent) would guard against a regression where the optimizer silently falls back to the generic branch and produces a bare `Literal`, which would pass the structural assertions but violate the `MvExpand` contract.
