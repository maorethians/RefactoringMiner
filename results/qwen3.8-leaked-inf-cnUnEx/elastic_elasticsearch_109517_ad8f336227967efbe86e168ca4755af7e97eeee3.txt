#C3RTA: The CARTESIAN_SHAPE test case uses `GEO.asWkt(...)` to serialize the geometry, but the original code (and the data type under test) is `CARTESIAN_SHAPE`. This should be `CARTESIAN.asWkt(...)`. It appears to be a copy-paste error from the GEO_SHAPE block above (#X8VDB). Using the wrong serializer will produce WKT in the wrong coordinate system, making the test validate the wrong output format.
