#C54JY: In `checkInvariant`, the heap-mode branch has a bug: the loop iterates with variable `l` but the null check always reads `values.get(rootIndex)` instead of `values.get(l)`. This means it only ever checks the root element `bucketSize` times rather than verifying every slot in the bucket is non-null.
```java
for (long l = rootIndex; l < common.endIndex(rootIndex); l++) {
    if (values.get(rootIndex) == null) {  // should be values.get(l)
        throw new AssertionError("values missing in heap mode");
    }
}
```

#C54JY: In the `merge` method, `other.checkInvariant(bucket)` passes the *target* bucket index to validate the *source* object's state. It should pass `otherBucket` so the invariant is checked against the correct bucket in `other`:
```java
other.checkInvariant(bucket);   // validates wrong bucket in 'other'
// should be:
other.checkInvariant(otherBucket);
```
