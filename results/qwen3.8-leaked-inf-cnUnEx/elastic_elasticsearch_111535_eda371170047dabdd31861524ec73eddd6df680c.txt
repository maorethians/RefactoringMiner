#8KEBJ: The `logger.debug` call uses direct string concatenation (`"Reloading plugin [" + p.getClass().getSimpleName() + "]"`), while the adjacent `logger.warn` call uses a lambda supplier (`() -> "Reload failed for plugin [" + ...`). For consistency and to avoid building the string when the debug level is disabled, consider using the same lambda pattern:
```java
logger.debug(() -> "Reloading plugin [" + p.getClass().getSimpleName() + "]");
```
