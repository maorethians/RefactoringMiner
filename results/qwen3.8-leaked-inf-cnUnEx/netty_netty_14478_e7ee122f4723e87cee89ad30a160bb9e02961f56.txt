#DXX7Z: The modulo constant is incorrect. TCP sequence numbers wrap at 2^32 (i.e., the value space is 0 through 0xFFFFFFFF, and 0xFFFFFFFF + 1 wraps to 0). Using `% 0xFFFFFFFFL` (which is 2^32 - 1) produces wrong results at the boundary:
- `0xFFFFFFFF + 1` → `0x100000000 % 0xFFFFFFFF` = **1** (should be **0**)
- `0xFFFFFFFF + 2` → `0x100000001 % 0xFFFFFFFF` = **2** (should be **1**)
The correct expression is:
```java
return (sequenceNumber + value) & 0xFFFFFFFFL;
```
or equivalently:
```java
return (sequenceNumber + value) % 0x100000000L;
```
