#B4DTH: The `suppliers.stream().toList().forEach(supplier -> { ... suppliers.add(...); })` pattern mutates `suppliers` while iterating over a snapshot of it. While this is safe (the snapshot is a separate list), it is an unusual idiom for "iterate over existing elements and append new ones." A plain indexed loop over the original size is more readable and makes the intent (iterate over the *pre-existing* entries) explicit:
```java
int size = suppliers.size();
for (int i = 0; i < size; i++) {
    TestCaseSupplier supplier = suppliers.get(i);
    // ... build and add warning cases
}
```
This avoids the subtle "am I iterating over the original or the growing list?" question that a reader might have with the `stream().toList().forEach` form.
