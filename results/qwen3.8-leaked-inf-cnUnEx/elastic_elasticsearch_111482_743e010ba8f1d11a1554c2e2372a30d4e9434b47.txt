#7YKK5: The variable name `allValuesNull` is misleading. The logic uses `anyMatch(Block::areAllValuesNull)`, which returns `true` if *any* block is entirely null — not if *all* values across all blocks are null. A name like `anyBlockAllNull` or `hasAllNullBlock` would more accurately reflect the semantics and prevent confusion for future readers.

#JQ5TA: `values.get(0)` will throw `IndexOutOfBoundsException` if `values` is an empty list. The `withNoRowsExpectingNull` helper (shown in the dependencies) creates `TypedData` instances with `List.of()` for multi-row data. If `asLiteral` is ever invoked on such a `TypedData`, this will crash. Consider guarding with a size check or documenting that `asLiteral` must not be called on empty multi-row data.
