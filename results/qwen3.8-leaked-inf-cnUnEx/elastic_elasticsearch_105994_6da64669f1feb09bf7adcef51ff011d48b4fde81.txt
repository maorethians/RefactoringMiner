#1NKF1: `mapper` is obtained from `context.nestedLookup().getNestedMappers().get(parentPath)` without a null check. If `parentPath` is not present as a key in the nested mappers map (e.g., due to a mapping inconsistency or a race during mapping updates), `mapper` will be `null` and the subsequent `mapper.nestedTypeFilter()` call will throw a `NullPointerException`. While in practice the enclosing code path likely guarantees that `parentPath` is a valid nested parent (otherwise we wouldn't be in this branch), a defensive guard—either an explicit null check with a meaningful error message, or an `Objects.requireNonNull(mapper, ...)` assertion—would make the failure mode clearer and easier to diagnose in production, rather than surfacing as an opaque NPE deep in query construction.
