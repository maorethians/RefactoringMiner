#FQ4EN: The test creates two files (OUTPUT and LOG), uploads them in MINIMAL mode, then iterates over *all* files asserting a valid bytestream URI:
```java
for (LocalFile file : filesToUpload.values()) {
    String conversion = pathConverter.apply(file.path);
    assertThat(conversion)
        .isEqualTo("bytestream://localhost/instance/blobs/" + hash + "/" + size);
}
```
However, in MINIMAL mode the OUTPUT file is marked `omitted=true` in `readPathMetadata`, so `pathConverter.apply` will return `null` for it (per the `PathConverter` contract: "may return null, in which case the associated BuildEventArtifactUploader was permanently unable to upload the file"). The assertion will fail with a null-vs-string mismatch. The loop should either skip omitted files or assert `null` for the OUTPUT file.

return new PathMetadata(

Since the file will never be uploaded, the digest is never used. Passing `null` (as is done for the directory and symlink cases just below) would avoid a full file read for every non-matching file in MINIMAL mode.
