#8ECZT, #WRD7D, #MYHA8: **Leading separator when column 0 is dropped.** The guard `if (i > 0)` assumes the first visible column is always at index 0. When `dropColumns[0]` is `true`, the first non-dropped column is at index ≥ 1, so `i > 0` is already true and a `|` (or `+`) is emitted before any column content. Compare with `#PAJ4Y`, which correctly uses a `firstColumn` flag. Replace the `i > 0` check with a `boolean firstColumn = true` flag in all three loops, and add a test case where the **first** column is entirely null to lock in the fix.
