#58VK4, #56R62: Both `asQuery` implementations call `suffix.fold(FoldContext.small())` / `prefix.fold(FoldContext.small())` in production code. The `FoldContext.small()` javadoc explicitly states it is "Fine in tests but otherwise calling this is a signal that you either, shouldn't be calling `Expression#fold` at all, or should pass in a shared `FoldContext` made by `Configuration`." The TODO acknowledges this, but since `asQuery` is on the hot path of query translation (called per query, not per row), allocating a new `FoldContext` each time is wasteful. Consider threading a `FoldContext` through the `TranslatorHandler` or the translation pipeline so it can be shared across all fold operations in a single query.

#JKTSQ, #3NHW1: The test method names are misleading. `testLuceneQuery_NonFoldableSuffix_Translatable` and `testLuceneQuery_NonFoldablePrefix_Translatable` both use a `Literal` as the suffix/prefix, which *is* foldable. The "NonFoldable" in the name contradicts the actual test setup. These should be renamed to something like `testLuceneQuery_FoldableSuffix_Translatable` / `testLuceneQuery_FoldablePrefix_Translatable` (or `LiteralSuffix_Translatable` / `LiteralPrefix_Translatable`) to accurately describe what is being tested and to contrast properly with the `NonFoldableSuffix_NonTranslatable` / `NonFoldablePrefix_NonTranslatable` tests.
