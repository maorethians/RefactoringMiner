#55AZA, #FEB5S: The cache is keyed on `Alias.unwrap(ne)` (the unwrapped aggregate expression), but the value is computed using `ne.name()` (the alias). If two `NamedExpression` instances wrap the same underlying aggregate with different aliases (e.g., `SUM(x) AS a` and `SUM(x) AS b`), the second call will hit the cache and return temporary attributes named after the *first* alias (`$$a$...` instead of `$$b$...`). Consider including the name in the cache key, or documenting that this scenario is guaranteed not to occur by the caller.
