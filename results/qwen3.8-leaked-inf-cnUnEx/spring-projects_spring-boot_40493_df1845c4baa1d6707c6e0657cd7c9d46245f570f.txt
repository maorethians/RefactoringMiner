#97B54: The key (`entry.getKey()`) is not passed through `escapeJson`, only the value is. If a key ever contains a double-quote, backslash, or other special character, the generated JSON string will be malformed. For consistency and robustness, the key should also be escaped:
```java
.map((entry) -> "\"%s\":\"%s\"".formatted(escapeJson(entry.getKey()), escapeJson(entry.getValue())))
```
Even if current Pulsar authentication parameter keys are conventionally simple identifiers, this is a low-cost guard against a class of malformed-JSON bugs.

#9NA3F, #Y6G4Z, #14TD0, #0F890, #W0220: The test data exercises newlines, tabs, and embedded quotes, but no test value contains a literal backslash (`\`). Since the first replacement in `escapeJson` is the backslash escape (and it must run before all others to avoid double-escaping), this is the most order-sensitive branch in the method. Adding a value like `C:\path\to\file` (or a value containing `\\`) to the test map would verify that the backslash-escaping path works correctly and that the replacement order is preserved.
