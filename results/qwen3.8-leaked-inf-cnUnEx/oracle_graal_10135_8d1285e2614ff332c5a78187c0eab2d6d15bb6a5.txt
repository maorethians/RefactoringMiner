#RVHE9, #JANT2: The `isCompilationStopped()` method is invoked inside `synchronized (this)` on the `OptimizedCallTarget`. In the `SHUTDOWN_COMPILATION` branch, `shutdownAndAwaitTermination(100)` can block for up to 100 ms while the caller still holds the per-target monitor. Any other thread attempting to compile the same target (or any thread that needs that monitor) will be stalled for the full duration. Consider performing the shutdown outside the synchronized block, or guarding it so it only executes once (e.g., with an `AtomicBoolean` "already shut down" flag) to avoid repeated blocking calls.

#RVHE9: In the `SHUTDOWN_COMPILATION` branch, `runtime().getCompileQueue().shutdownAndAwaitTermination(100)` is invoked on **every** call to `isCompilationStopped()`. After the first invocation the executor is already terminated, so subsequent calls still acquire the `BackgroundCompileQueue` monitor, call `shutdownNow()` (no-op), and call `awaitTermination()` (returns immediately). While not incorrect, this is unnecessary overhead on a hot path. A one-shot guard (e.g., an `AtomicBoolean` in `OptimizedTruffleRuntime`) would let you skip the call after the first shutdown.

#RVHE9: The `sct` value is read once at the top of the method and then used in the `STOP_COMPILATION → RUN_COMPILATION` transition:
```java
if (sct != 0 && System.currentTimeMillis() - sct > engine.stoppedCompilationRetryDelay) {
    runtime().stoppedCompilationTime().compareAndSet(sct, 0);
    compilationActivityMode = RUN_COMPILATION;
}
```
If another thread updates `stoppedCompilationTime` between the initial read and the CAS, the CAS fails but the code still switches to `RUN_COMPILATION` and proceeds to submit a compilation. This is a benign race (the next check will re-enter STOP mode), but it means a compilation can be submitted immediately after the code cache has gone full again. If this is intentional, a brief comment noting the tolerance would help future readers; otherwise, consider re-reading the value after a failed CAS before deciding to switch modes.
