#FC55Q: The error message `"Broker[" + brokerName + "] master node does not exist"` is misleading in the branch where `brokerName` is `null`. In that path, `brokerAddr` is derived from `RemotingHelper.parseSocketAddressAddr(msg.getStoreHost())`, so a blank result means the store host could not be resolved — not that a named broker's master node is missing. The message would render as `"Broker[null] master node does not exist"`, which is confusing for operators debugging the issue.
Consider differentiating the message based on which path produced the blank address, e.g.:
```java
if (UtilAll.isBlank(brokerAddr)) {
    String reason = (brokerName != null)
        ? "Broker[" + brokerName + "] master node does not exist"
        : "Cannot resolve broker address from store host: " + msg.getStoreHost();
    throw new MQClientException(reason, null);
}
```
This makes the root cause immediately clear in both scenarios.
