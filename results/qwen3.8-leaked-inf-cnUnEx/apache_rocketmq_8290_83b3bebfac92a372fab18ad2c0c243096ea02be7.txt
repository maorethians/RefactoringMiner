#ZSHSN: The logic here is incorrect. `UtilAll.isInternalIP(ip)` is used to decide between IPv4 and IPv6 string formatting, but:
1. **It will throw a `RuntimeException`** for IPv6 addresses. `isInternalIP` explicitly checks `if (ip.length != 4) { throw new RuntimeException("illegal ipv4 bytes"); }`. If `UtilAll.getIP()` returns a 16-byte IPv6 address, this static initializer will crash class loading.
2. **The semantic intent is wrong.** The goal is to pick the correct string formatter based on the address family (IPv4 vs IPv6), not based on whether the address falls in a private range. The correct condition should be the byte length:
```java
static {
    byte[] ip = UtilAll.getIP();
    if (ip.length == 4) {
        LOCAL_ADDRESS = UtilAll.ipToIPv4Str(ip);
    } else {
        LOCAL_ADDRESS = UtilAll.ipToIPv6Str(ip);
    }
}
```

#2GFD4: If `getLocalInetAddress()` returns `null` (which it can, after the `catch` block in #H2WZA), then `normalizeHostAddress(null)` will throw a `NullPointerException` at `localHost.getHostAddress()`. The old implementation returned `null` directly in the failure path. Consider adding a null guard:
```java
public static String getLocalAddress() {
    InetAddress localHost = getLocalInetAddress();
    if (localHost == null) {
        return null;
    }
    return normalizeHostAddress(localHost);
}
```
