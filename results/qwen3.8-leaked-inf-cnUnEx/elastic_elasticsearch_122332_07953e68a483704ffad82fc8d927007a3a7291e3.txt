#VZ0GC, #Z4E1Z, #C9C13: The test previously set/cleared the system property `"es.serverless"`, but the constant `SERVERLESS_TRANSPORT_SYSTEM_PROPERTY` resolves to `"es.serverless_transport"`. Replacing the hardcoded string with the constant therefore changes *which* property the test manipulates. If the production code in `TransportService` reads `"es.serverless_transport"`, then the old test was exercising the wrong property and this is a legitimate fix. However, if there is (or was) a separate code path that reads `"es.serverless"`, this change silently stops the test from covering that path. Worth confirming that no other component in the transport handshake still keys off the shorter property name.
