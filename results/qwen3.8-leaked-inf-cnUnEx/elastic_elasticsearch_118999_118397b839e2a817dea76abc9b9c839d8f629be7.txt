The test then blocks on `latch.await(30, TimeUnit.SECONDS)` and fails with a timeout rather than surfacing the original assertion error. Consider wrapping the callback invocation in a `try/finally` so the latch is always released, and capturing the exception to rethrow after the await:
```java
@Override
public void onSuccess(Response response) {
    try {
        if (responseConsumerCallback != null) {
            responseConsumerCallback.accept(response);
        }
    } catch (Exception e) {
        failure = e;
    } finally {
        latch.countDown();
    }
}
```
