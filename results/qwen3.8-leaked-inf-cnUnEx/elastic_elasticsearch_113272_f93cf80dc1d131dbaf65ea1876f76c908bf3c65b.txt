#ART37, #Y3NZ3: The `name` argument passed to `addSuppliers` already contains angle brackets (e.g., `"<no alt geo_point>"`, `"<with alt cartesian_point>"`). Since `addSuppliers` wraps the name in its own brackets (`"<single " + name + ">"` and `"<" + name + "s>"`), the resulting supplier names become awkwardly nested: `"<single <no alt geo_point>>"` and `"<no alt geo_point>s>"`.
All other call sites pass plain names like `"0 int"`, `"positive double"`, `"random boolean"`, producing clean results like `"<single 0 int>"` / `"<0 ints>"`. For consistency, the geo and cartesian point names should drop the embedded brackets, e.g. `"no alt geo_point"` and `"with alt geo_point"`, yielding `"<single no alt geo_point>"` / `"<no alt geo_points>"`.
