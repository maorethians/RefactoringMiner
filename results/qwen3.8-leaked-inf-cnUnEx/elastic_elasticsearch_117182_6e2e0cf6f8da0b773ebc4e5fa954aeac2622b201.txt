#3VA9W: The test only covers the "field absent from source" path. Consider adding a complementary test where the document source *does* contain the field (e.g., `b -> b.field("field", "some_value")`) and asserting the synthetic source reflects the source value rather than the mapping value. This would guard against a regression where `Fallback` accidentally starts emitting the mapping-defined constant instead of the original source value, which would be a subtle correctness issue for reindexing scenarios.
