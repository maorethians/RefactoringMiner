#PK5VJ: The error message `"Invalid query [{}]"` is quite generic. Since the `EmptyStackException` here is specifically triggered by an unmatched closing delimiter (as the comment notes), a slightly more descriptive message such as `"Invalid query [{}]: unexpected closing delimiter"` would help users quickly identify the problem rather than having to manually inspect the query for the issue. This is a minor suggestion, but it improves the developer/user experience when debugging ESQL queries.

#JFRC2: The test method name `testUnclosedParenthesis` is misleading. "Unclosed" conventionally means an *opening* delimiter without a matching *closing* one (e.g., `row a = (`). However, all three test queries contain an *extra closing* delimiter (`)`, `]`, `]`). A name like `testExtraClosingDelimiter` or `testUnmatchedClosingParenthesis` would accurately describe what is being tested and avoid confusion for future readers.
