#KMH4P: The method name `isConfigationSet` contains a typo — it should be `isConfigurationSet`. This is a private method so the impact is limited, but it will be confusing when reading the code or searching for it.

#4EF59: The loop `for (boolean useDocValues : new boolean[] { false })` only ever iterates with `false`, making the ternary `useDocValues ? airports : airportsNoDocValues` always resolve to `airportsNoDocValues`. If the intent is to only test the no-doc-values case here (with the doc-values case covered by `testSpatialTypesAndStatsUseDocValues`), the loop and ternary are misleading. Consider either removing the loop entirely or restoring `new boolean[] { true, false }` to match the original test coverage.

#7GFVH: The `DEFAULT` implementation of `isIndexed(FieldAttribute)` returns `attr.field().isAggregatable()`, which is semantically incorrect — `isAggregatable` typically means "has doc values," not "is indexed." A field can have doc values without being indexed (e.g., `"index": false, "doc_values": true`). The TODO comment acknowledges this, but since this `DEFAULT` is used by `PlannerUtils.detectFilter` (which is documented as only safe for `@timestamp`/date fields), consider adding a stronger guard or assertion to prevent accidental use with non-date fields where this conflation could cause incorrect pushdown decisions.

#5Y6QM: In `isIndexedAndDocValues`, the expression:
```java
return attr.field().isAggregatable() || stats.isIndexed(attr.name()) && stats.hasDocValues(attr.name());
```
short-circuits on `isAggregatable()`, meaning a field that is aggregatable (has doc values) but **not** indexed will still be considered pushable. The inline comment acknowledges this risk. If the intent is to allow pushdown only when the field is actually indexed (so Lucene can serve the query), the `isAggregatable()` check should perhaps be an additional condition rather than a short-circuit, or at minimum the comment should be elevated to a warning-level note since this could silently produce incorrect plans for non-indexed fields.
