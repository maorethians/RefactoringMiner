#VM7NJ, #9Z9PA: The use of a raw `Map.Entry[]` array (created via `new Map.Entry[values().length]`) combined with the `@SuppressWarnings({ "unchecked", "rawtypes" })` annotation is a pragmatic workaround for Java's inability to create generic arrays, but it introduces an unchecked assignment at the `Map.ofEntries(linksBySymbolEntries)` call site. A slightly cleaner alternative that avoids the raw type entirely would be to collect entries in a `List<Map.Entry<String, LinkComponents>>` and pass `list.toArray(new Map.Entry[0])` to `Map.ofEntries`, or simply build the map incrementally with a `HashMap` and return `Map.copyOf(map)`. This would eliminate the need for the suppression annotation and make the type flow explicit.

#ZVBJ9: `testShowAllLinks` contains no assertions — it only logs output. While the accompanying comment clarifies it is for manual verification, a test method that cannot fail (it will always pass regardless of the link content) may give a false sense of coverage in CI dashboards. Consider either renaming it to make its non-asserting nature explicit (e.g., `logAllLinksForManualVerification`) or guarding it behind a system property / `@Disabled` so it doesn't run in the default test suite.
