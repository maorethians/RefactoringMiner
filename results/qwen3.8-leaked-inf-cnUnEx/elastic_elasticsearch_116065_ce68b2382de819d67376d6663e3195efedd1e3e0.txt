#1VJZH: The method `inNestedScope()` was `public` and is now replaced by a package-private `inArrayScope()` with different semantics (checks `Scope.ARRAY` instead of `Scope.NESTED`). While the rename and semantic shift are appropriate for the new logic, the visibility reduction from `public` to package-private means any external callers (e.g., in plugin code or tests in other packages) that referenced `inNestedScope()` would get a compile error. If this method was ever part of a semi-public API surface, a deprecation cycle might be warranted. That said, given it's an internal parser detail being reworked, this is likely acceptable.
