#RJ2J2: **Infinite recursion.** This 3-argument `parseLong` calls itself with identical arguments, resulting in a `StackOverflowError` at runtime. It should delegate to the 4-argument overload (introduced in #8HP28) with `isFiltered = false`:
```java
public static long parseLong(String s, long minValue, String key) {
    return parseLong(s, minValue, key, false);
}
```

#ZYKT5, #PPNG5: **NullPointerException when weigher is null.** `createCache` unconditionally calls `.weigher(weigher)`, but `CacheBuilder.weigher()` contains `Objects.requireNonNull(weigher)`. The call site in `#PPNG5` passes `null` as the weigher (preserving the old behavior of no weigher), which will throw an NPE at construction time.
The weigher should be applied conditionally:
```java
private Cache<CacheKey, CacheValue> createCache(long maxWeight, ToLongBiFunction<CacheKey, CacheValue> weigher) {
    CacheBuilder<CacheKey, CacheValue> builder = CacheBuilder.<CacheKey, CacheValue>builder()
        .setMaximumWeight(maxWeight)
        .removalListener(notification -> sizeInBytes.getAndAdd(-1 * notification.getValue().sizeInBytes));
    if (weigher != null) {
        builder.weigher(weigher);
    }
    return builder.build();
}
```
