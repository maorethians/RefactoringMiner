#1YCJK: The `Math.min(2, ...)` cap is applied to the *result* of `SystemPropertyUtil.getInt(...)`, which means a user who explicitly sets `io.netty.allocator.centralQueueCapacity=16` will still get a value of 2. This effectively renders the system-property override useless for any value greater than 2, defeating its purpose. If the intent is to cap only the *default* (i.e., `availableProcessors()`), the cap should be applied to the default argument instead:
```java
private static final int CENTRAL_QUEUE_CAPACITY = SystemPropertyUtil.getInt(
        "io.netty.allocator.centralQueueCapacity",
        Math.min(2, NettyRuntime.availableProcessors()));
```
This preserves the ability for operators to override the value while still limiting the default on high-core-count machines.
