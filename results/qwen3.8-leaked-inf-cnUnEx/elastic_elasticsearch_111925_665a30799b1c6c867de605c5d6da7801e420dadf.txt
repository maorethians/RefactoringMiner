#MQW4Z: The comment "Use the random supplier for COSINE, which returns values in the normalized range" is slightly misleading. `FLOAT_ARRAY_RANDOM_FUNC` does not normalize its output — it simply generates arbitrary random floats. What is true is that *cosine similarity* produces results in a normalized range ([-1, 1]) regardless of input magnitude, which is why arbitrary random inputs are safe for this case. Consider rewording to something like:
```java
// COSINE similarity is scale-invariant, so arbitrary random floats are safe inputs
```
This makes the rationale clearer for future readers who might wonder why only COSINE gets a different supplier.
