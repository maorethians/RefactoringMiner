#YQWZA: **Potential `NullPointerException` from `profileBoundAddresses()`.** The Javadoc on `Transport.profileBoundAddresses()` explicitly states:
> `@return <code>null</code> iff profiles are unsupported, otherwise a map with name of profile and its bound transport address`
Yet the code calls `.values()` on the result without a null guard:
```java
for (final BoundTransportAddress profileAddresses : transport.profileBoundAddresses().values()) {
```
If any `Transport` implementation in the cluster does not support profiles, this will throw an NPE and fail the test. A null check is needed, e.g.:
```java
final Map<String, BoundTransportAddress> profiles = transport.profileBoundAddresses();
if (profiles != null) {
    for (final BoundTransportAddress profileAddresses : profiles.values()) {
        for (final TransportAddress transportAddress : profileAddresses.boundAddresses()) {
            addresses.add(transportAddress);
        }
    }
}
```
