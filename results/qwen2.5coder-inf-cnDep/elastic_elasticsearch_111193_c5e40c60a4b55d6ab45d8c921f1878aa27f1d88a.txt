#1TPMB, #5506R: The method `isPointGeometry` is introduced to check if the provided geometries array contains a single point geometry. However, the usage of this method in `pointShapeQuery` can be improved for clarity and maintainability. The condition `if (isPointGeometry(luceneGeometries) == false && relation == ShapeField.QueryRelation.CONTAINS)` can be simplified to `if (!isPointGeometry(luceneGeometries) && relation == ShapeField.QueryRelation.CONTAINS)` for better readability.
