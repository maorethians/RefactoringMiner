#ES472: The logic for checking future versions seems correct, but there is a potential issue with the assumption that all nodes will have the same version ID when `IndexVersion.current().id() == maxIndexVersion.id()`. If some nodes are on different patch versions within the same major/minor version, this check might not work as intended. Consider adding a more robust check to ensure all relevant nodes are compatible.
