#SKS3B: In the `write` method of `CapturingHandler`, there are two assertions checking if the current thread's name is in the stuck thread names list. The first assertion checks that the list is either empty or contains the current thread's name, while the second asserts that it does contain the current thread's name. This can be simplified by removing the first assertion since the second one already covers the case where the list should not be empty and must contain the current thread's name.
