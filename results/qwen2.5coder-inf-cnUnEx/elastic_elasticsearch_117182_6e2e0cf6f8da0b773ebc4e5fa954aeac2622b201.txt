#K4CKM: The change from using a custom `SourceLoader.SyntheticFieldLoader` to `SyntheticSourceSupport.Fallback` is intended to ensure that synthetic source does not include a value if there was no value in the document. However, this change might not fully capture the behavior of the previous implementation, especially regarding the `fieldName()` method which returned `fullPath()`. The `Fallback` class may not handle this specific requirement correctly.

#3VA9W: The test case `testNoValueInDocumentSyntheticSource` is added to verify that synthetic source does not include a value if there was no value in the document. This is good coverage for the new behavior introduced by using `SyntheticSourceSupport.Fallback`. However, it would be beneficial to add more test cases to ensure that when a value is present, it is correctly included in the synthetic source.
