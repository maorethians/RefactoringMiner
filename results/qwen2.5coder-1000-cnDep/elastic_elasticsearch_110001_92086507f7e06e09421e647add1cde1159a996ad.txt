#XCFTS, #080GS, #28MVQ, #70PH1, #EJ46D, #FTDPG, #B7N6C, #E5PBT: The condition `if (false == set.containsAll(Arrays.asList(values)))` is redundant. The `assertThat(set, containsInAnyOrder(values));` will already fail if the sets do not contain the same elements, so the explicit check is unnecessary.

#XCFTS, #080GS, #28MVQ, #70PH1: The use of `TreeSet<?>` without specifying a comparator for objects of type `Object[]` can lead to `ClassCastException` if the elements are not mutually comparable. It's better to ensure that the elements in the set are of a type that implements `Comparable`, or provide an appropriate comparator.
