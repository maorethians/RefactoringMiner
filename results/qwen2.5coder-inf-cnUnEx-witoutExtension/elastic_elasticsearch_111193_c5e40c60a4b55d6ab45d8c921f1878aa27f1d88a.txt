#1TPMB, #5506R: The method `isPointGeometry` is introduced to check if the provided geometries array contains a single point geometry. However, the usage of this method in `pointShapeQuery` does not handle cases where `luceneGeometries` might be null or have more than one element that could potentially be a point. The current implementation assumes that if there's only one geometry and it is a point, then it's a point geometry, but it doesn't account for scenarios where the array might contain multiple geometries with only one being a point.
