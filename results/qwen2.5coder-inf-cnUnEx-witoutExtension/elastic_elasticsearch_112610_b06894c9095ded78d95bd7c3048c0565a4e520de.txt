#5W338, #VD6V6, #F8STX, #PW2XT: The introduction of `typeMapping` allows for dynamic type adjustments, but there is no validation or error handling if a specified type does not exist or is incompatible with the data. This could lead to runtime errors when attempting to convert data types.

#BBARN: The method `readMappingFile` modifies the mapping JSON based on `typeMapping`. If the `propertiesNode` does not contain a key from `typeMapping`, it silently ignores the type change request. This behavior might lead to confusion if users expect all mappings to be updated but some are ignored.
