#W982J, #0W1GC, #J4K3M, #EJ6VS: The introduction of `resolvedPipelineCache` is intended to optimize pipeline resolution by caching results per index. However, this cache is not thread-safe as it uses a plain `HashMap`. In a concurrent environment, multiple threads could attempt to compute and update the cache simultaneously, leading to potential data corruption or inconsistent states. Consider using a thread-safe alternative like `ConcurrentHashMap` for `resolvedPipelineCache`.

#T3R1H: The method `isRolloverOnWrite` checks if rollover is enabled for a data stream by examining its backing indices. However, it assumes that the index name provided in the `IndexRequest` directly corresponds to a data stream name. This might not always be the case, especially if the request targets a specific backing index of a data stream rather than the data stream itself. Consider adding additional checks or documentation to clarify this assumption.
