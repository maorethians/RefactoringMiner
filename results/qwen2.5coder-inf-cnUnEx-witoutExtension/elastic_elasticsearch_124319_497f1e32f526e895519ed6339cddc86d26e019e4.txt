#NMZDW, #F4DFD: The method `getDataStreamBackingIndexNames` assumes that there is exactly one data stream returned by the API call. #NMZDW, #F4DFD: In `getDataStreamBackingIndexNames`, the method uses `getFirst()` on a list without checking if the list is empty. This can lead to a `NoSuchElementException` if the list is empty. It would be better to check the size of the list before accessing its elements.

#NMZDW, #F4DFD: The `getDataStreamBackingIndexNames` method in both `ESIntegTestCase` and `ESRestTestCase` does not handle potential exceptions that might be thrown by the client calls. It would be good practice to add exception handling to manage any errors gracefully.
