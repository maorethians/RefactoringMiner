#0ZJ70: The use of `RemoteClusterAware.isRemoteIndexName(pattern)` within the assertion can lead to incorrect test behavior if the index name "test1" is ever considered a remote index. The test should be designed to fail specifically for the case where the index does not exist, regardless of whether it's a remote index or not. Currently, the test will pass if "test1" is a remote index and the error message contains "parsing_exception", which might not be the intended behavior.
