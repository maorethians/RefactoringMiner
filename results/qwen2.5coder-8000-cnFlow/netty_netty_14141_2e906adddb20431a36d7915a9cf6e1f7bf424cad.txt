#5TPQW: The check for brackets around the IPv6 address can be simplified by using `String.startsWith` and `String.endsWith`, which improves readability and maintainability.
```java
if (hostString.startsWith("[") && hostString.endsWith("]")) {
    return hostString;
} else {
    // Add brackets to the IPv6 address.
    return '[' + hostString + ']';
}
```
