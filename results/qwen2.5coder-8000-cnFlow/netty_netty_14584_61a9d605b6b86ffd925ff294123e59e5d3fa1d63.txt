#6V64K: The change to `CENTRAL_QUEUE_CAPACITY` ensures that it is at least 2 by using `Math.min(2, ...)`. However, this logic seems incorrect because `Math.min(2, ...)` will always return 2 if the system property value or `NettyRuntime.availableProcessors()` is greater than 2. This effectively caps the capacity to a minimum of 2 but not above it, which contradicts the original intention of setting it based on the number of available processors.
