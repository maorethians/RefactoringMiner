#90ZWA: In the method `onConnectionClosed`, there are two consecutive checks for `executor == EsExecutors.DIRECT_EXECUTOR_SERVICE`. The first check assigns `threadPool.generic()` to `executor` if it is `EsExecutors.DIRECT_EXECUTOR_SERVICE`, and the second check immediately follows. This can be simplified by removing the redundant check:
```java
if (executor == EsExecutors.DIRECT_EXECUTOR_SERVICE) {
    executor = threadPool.generic();
}
handler.handleException(exception);
```
can be changed to:
```java
if (executor == EsExecutors.DIRECT_EXECUTOR_SERVICE) {
    executor = threadPool.generic();
}
executor.execute(new ForkingResponseHandlerRunnable(handler, exception, executor) {
    @Override
    protected void doRun() {
        handler.handleException(exception);
    }
});
```
This ensures that the `executor` is only reassigned once and simplifies the logic.
