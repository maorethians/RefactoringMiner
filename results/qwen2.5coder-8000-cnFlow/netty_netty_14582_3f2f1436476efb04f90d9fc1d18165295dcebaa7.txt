#1YCJK: The change to `CENTRAL_QUEUE_CAPACITY` ensures that it is at least 2 by using `Math.min(2, ...)`. However, this logic seems incorrect because `Math.min(2, ...)` will always return 2 if the system property value or `NettyRuntime.availableProcessors()` is greater than 2. This means the capacity will never be more than 2, which contradicts the comment stating that the default size is `NettyRuntime.availableProcessors()`. The intention might have been to set a minimum value of 2 while allowing it to go up to `NettyRuntime.availableProcessors()` if the system property is not set or set to a higher value. Consider using `Math.max(2, ...)` instead.
