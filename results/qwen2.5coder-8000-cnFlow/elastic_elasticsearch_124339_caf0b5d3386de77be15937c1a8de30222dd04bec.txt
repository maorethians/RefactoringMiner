#QHJEF: The change to allow `positionCount` to be 0 introduces a potential issue in the test case. When `positionCount` is 0, the block `b` will have no positions, and thus `b.values()` will be empty. This means that the loop `for (int p = 0; p < b.values().size(); p++)` will not execute any iterations, and the assertions within this loop will not be tested. Additionally, the variable `anyNonNullValue` will be determined based on an empty stream, which will always result in `false`. This might not accurately reflect the intended behavior of `hadMultivaluedFields()` when there are no positions.
