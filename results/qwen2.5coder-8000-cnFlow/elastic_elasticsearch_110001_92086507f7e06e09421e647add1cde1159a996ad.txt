#XCFTS, #0C7EF, #8WSF3, #35RH5, #ZHNPY, #080GS, #28MVQ, #70PH1: The introduction of `TreeSet` and the subsequent check with `containsAll` is unnecessary and can lead to incorrect behavior. The original code uses `assertThat((List<?>) BlockUtils.toJavaObject(result, 0), containsInAnyOrder(values));` which checks if the list contains all elements in any order. The new code creates a `TreeSet` from the result and then checks if it contains all elements from `values`. This can fail because `TreeSet` does not allow duplicate elements, whereas the original list might contain duplicates. Additionally, creating a `TreeSet` is more expensive than simply checking the contents of a list.
