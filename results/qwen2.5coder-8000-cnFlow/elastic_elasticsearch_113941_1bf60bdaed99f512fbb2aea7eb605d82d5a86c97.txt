#F4KMX, #1YM5G: The change from `VersionUtils.randomVersionBetween(random(), Version.CURRENT.minimumCompatibilityVersion(), VersionUtils.getPreviousVersion())` to `VersionUtils.randomCompatibleVersion(random(), VersionUtils.getPreviousVersion())` assumes that `randomCompatibleVersion` will always generate a version compatible with the current version and between the minimum compatibility version and the previous version. This assumption should be validated to ensure it holds true in all scenarios.

#CE1K4: The change introduces a new instance of `VersionInformation` for `oldVersion`, which is not appropriate as `oldVersion` should be a `Version` object, not a `VersionInformation`. This will cause type mismatches and likely runtime errors.
