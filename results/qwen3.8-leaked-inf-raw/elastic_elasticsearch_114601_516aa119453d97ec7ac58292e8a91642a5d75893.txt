#R27K1: The use of `fullPath().lastIndexOf(leafName())` to locate the parent path is fragile. If the leaf name appears as a substring of an earlier path segment, the index will be wrong. For example, if a field named `sparse_field` is nested inside an object also named `sparse_field` (path: `"sparse_field.sparse_field"`), then:
- `lastIndexOf("sparse_field")` returns `12`
- `substring(0, 11)` yields `"sparse_fiel"` — an incorrect parent path
The same issue applies to shorter names (e.g., a field `"t"` inside object `"test"` → path `"test.t"`, `lastIndexOf("t")` = 7, `substring(0, 6)` = `"test."`).
A safer approach is to split on the last dot delimiter:
```java
int lastDot = fullPath().lastIndexOf('.');
if (lastDot > 0) {
    String parentPath = fullPath().substring(0, lastDot);
    ObjectMapper parentMapper = mappers.objectMappers().get(parentPath);
    ...
}
```
This correctly isolates the parent path regardless of whether the leaf name is a substring of earlier segments.
