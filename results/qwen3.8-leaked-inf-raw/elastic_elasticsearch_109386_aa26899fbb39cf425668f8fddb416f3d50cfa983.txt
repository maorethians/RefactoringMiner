```java
try (T other = build(SortOrder.ASC, 3)) {
    collect(sort, 1, 0);  // should be: collect(other, 1, 0)

```
As written, `other` remains empty and the merge is a no-op. The test passes by coincidence because the extra collects into the already-heapified `sort` happen to produce the same final state.
