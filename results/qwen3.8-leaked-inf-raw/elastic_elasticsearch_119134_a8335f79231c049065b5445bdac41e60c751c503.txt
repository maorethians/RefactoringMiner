#K5KSM: The test hardcodes the field-level `ignore_malformed` to `false` for the timestamp field:
```java
mapping.startObject(FIELD_TIMESTAMP).field("type", "date").field("ignore_malformed", false).endObject();
```
Since the index-level setting is already randomized (`randomBoolean()`), the field-level value should also be randomized to exercise both `true` and `false` propagation paths through `addTimestampField` (#YYN6Y). As written, the test only verifies that a `false` field-level value is copied, leaving the `true` case untested. Consider:
```java
mapping.startObject(FIELD_TIMESTAMP).field("type", "date").field("ignore_malformed", randomBoolean()).endObject();
```
