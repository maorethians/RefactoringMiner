#YDT7C: The field name checked here is `_ts_metric_name_hash` (singular "name"), but the actual field registered in `TimeSeriesMetricNamesHashFieldMapper.NAME` is `_ts_metric_names_hash` (plural "names"). Because of this mismatch, the condition `fieldName.equals("_ts_metric_name_hash") == false` will be `true` for the real field, causing it to be **excluded** from the TSDB codec format — the exact opposite of the stated intent. The field will fall through to the generic `fieldName.startsWith("_")` exclusion. This should be `_ts_metric_names_hash` to match the constant.

#4YY0M: The cache guard `if (metricNamesHash != 0)` uses `0` as a "not yet computed" sentinel. However, when `metricNames` is empty, the Murmur3 hash of zero-length input with seed 0 is exactly `0`, so the cache will never be effective for documents with no metrics — every call to `buildMetricNamesHash()` will recompute. Consider using a separate `boolean computed` flag or initializing `metricNamesHash` to a value that cannot be a valid hash (e.g., `-1`), or simply removing the cache since the computation is lightweight.
