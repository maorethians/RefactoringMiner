#Y7MR3: In the REST-based helper, if the API response is malformed or the data stream doesn't exist, `response.get("data_streams")` could return `null`, causing a `NullPointerException` at `dataStreams.size()` rather than a clear assertion failure. Similarly, `dataStream.get("indices")` could be `null`. Consider adding a null guard or using `assertThat(dataStreams, notNullValue())` before the size assertion to produce a more diagnostic failure message in test output. This is a minor concern since the data stream is expected to exist at the call sites, but it would make debugging flaky tests easier.
