#C88WT: The `Math.min(2, ...)` silently caps the value of a user-configurable system property. If an operator explicitly sets `io.netty.allocator.centralQueueCapacity` to, say, 8, the value will be reduced to 2 with no log warning or indication that the configured value was overridden. This can make troubleshooting confusing. Consider either:
- Logging a warning when the effective value differs from the configured value, or
- Documenting the hard cap in the property's description so operators know the ceiling.

#C88WT: The literal `2` is a magic number. Given that this is a tuning constant with a specific rationale (limiting memory footprint), extracting it into a named constant (e.g., `MAX_CENTRAL_QUEUE_CAPACITY`) would make the intent self-documenting and easier to reference in tests or related logic.
