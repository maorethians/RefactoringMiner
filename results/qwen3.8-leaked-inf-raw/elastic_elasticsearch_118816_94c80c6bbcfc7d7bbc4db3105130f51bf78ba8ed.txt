#03VHX: Two concerns:
1. In `collect()`, `isEmpty = false` is set before the values are actually collected into the list. If `label.collect(values)` throws, the producer is left in a non-empty state with no usable data. Consider setting `isEmpty = false` after successful collection, or wrapping in a try/catch that resets state.
2. In `write()`, the lambda passed to `FlattenedFieldSyntheticWriterHelper` returns `null` to signal end-of-iteration:
```java
var helper = new FlattenedFieldSyntheticWriterHelper(() -> {
    if (iterator.hasNext()) {
        return (BytesRef) iterator.next();
    } else {
        return null;
    }
});
```
This relies on the helper treating `null` as a termination signal. If the helper's `write()` method does `new KeyValue(sortedKeyedValues.next())` without a null check (as the visible code in `#X83VH` suggests), this would NPE. Please confirm the helper handles the null sentinel correctly, or consider using a different termination mechanism (e.g., a sentinel `BytesRef` or a checked exception).
