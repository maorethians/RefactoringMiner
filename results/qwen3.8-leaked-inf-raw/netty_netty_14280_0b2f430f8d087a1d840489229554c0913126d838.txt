#TKZVT: The variable names `mehtodNameAscii` and `mehtodName` contain a typo — "mehtod" should be "method". While this is in test code, it reduces readability and could cause confusion when searching for related identifiers.

#1YHCA: This is a behavioral change worth calling out: the previous validation only rejected ISO control characters and whitespace, while `HttpUtil.validateToken` rejects **all** non-token characters (e.g. `(`, `)`, `/`, `:`, `;`, `@`, `"`, `[`, `]`, `{`, `}`, etc.). This is more correct per RFC 7231 (method = token), but it is a breaking change for any caller that previously constructed an `HttpMethod` with characters like `/` or `:`. If this is intentional, consider noting it in the release notes or changelog so downstream users are aware.
