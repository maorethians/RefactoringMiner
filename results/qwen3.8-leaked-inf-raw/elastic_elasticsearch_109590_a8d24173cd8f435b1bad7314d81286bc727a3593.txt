#Y0GVB, #12SZ6: The refactored test logic is a solid improvement over the old fixed-range port iteration. A few observations:
1. **Defensive check for empty address list**: If `internalCluster().getInstances(Transport.class)` returns no instances, or if none of them have bound addresses (a misconfigured cluster), `addresses` will be empty and `randomNonEmptySubsetOf(addresses)` will throw an `IllegalArgumentException` with a generic message. An explicit `assertThat(addresses, not(empty()))` (or similar) before the subset call would give a clearer failure diagnostic in CI.
2. **Potential duplicate addresses**: If multiple `Transport` instances bind to the same address (e.g., a shared profile), the `addresses` list can contain duplicates. This is harmless for connectivity testing, but using a `LinkedHashSet` instead of `ArrayList` would keep the subset selection unbiased toward the more common address. Minor, but worth considering.
