#C2DYT: The `snapshotFunctions()` method is invoked twice in the `SnapshotFunctionRegistry` constructor — once for `register(...)` and once for `buildDataTypesForStringLiteralConversion(...)`. If this method performs any non-trivial work (e.g., building or filtering a list of definitions), the redundant call is wasteful. Consider storing the result in a local variable:
```java
FunctionDefinition[]... funcs = snapshotFunctions();
register(funcs);
buildDataTypesForStringLiteralConversion(funcs);
```
This also guards against any subtle inconsistency if the method were ever to have side effects or return a different collection on successive calls.
