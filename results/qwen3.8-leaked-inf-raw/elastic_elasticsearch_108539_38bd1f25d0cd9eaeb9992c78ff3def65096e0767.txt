#TTFKA: In `onRejection`, calling `doRun()` directly bypasses the exception-handling wrapper that `AbstractRunnable.run()` provides (i.e., the try/catch that routes exceptions to `onFailure`). If `doRun()` throws, the exception will propagate out of the rejection handler rather than being logged via the `onFailure` path you just added. Consider calling `run()` instead, or wrapping the call:
```java
@Override
public void onRejection(Exception e) {
    try {
        doRun();
    } catch (Exception ex) {
        onFailure(ex);
    }
}
```
This keeps error reporting consistent between the normal execution path and the shutdown-rejection path.
