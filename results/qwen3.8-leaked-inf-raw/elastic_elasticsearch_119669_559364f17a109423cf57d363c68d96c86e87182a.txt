#1HCBS, #YA3MW, #E11G2, #3JNJ7: The `parseLegacyVersion(getOldClusterVersion())` call is made twice — once to compute `originalClusterHasTransportVersion` and again inside the `if` branch to extract the version ID. Storing the `Optional<Version>` in a local variable would avoid the redundant call and make the intent clearer:
```java
Optional<Version> oldVersion = parseLegacyVersion(getOldClusterVersion());
boolean originalClusterHasTransportVersion = oldVersion.map(v -> v.onOrAfter(VERSION_INTRODUCING_TRANSPORT_VERSIONS)).orElse(true);
TransportVersion transportVersion;
if (originalClusterHasTransportVersion == false) {
    transportVersion = TransportVersion.fromId(oldVersion.map(Version::id).orElse(TransportVersions.MINIMUM_COMPATIBLE.id()));
} else {
    transportVersion = TransportVersion.readVersion(input);
}
```
This also makes it immediately visible that the `.orElse(TransportVersions.MINIMUM_COMPATIBLE.id())` in the `if` branch is actually unreachable (the branch is only entered when the `Optional` is present and the version is before the transport-version threshold), so a reader can decide whether to simplify it or leave it as a defensive guard.
