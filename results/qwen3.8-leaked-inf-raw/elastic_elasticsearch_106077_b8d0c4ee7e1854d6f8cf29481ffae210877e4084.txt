#P9XZV, #1Y5WS: The `MapperService.parseMapping` public methods have their signatures changed (a `MergeReason` parameter is inserted) without preserving the old two-argument overloads. In contrast, `MappingParser` (package-private) does keep the old `parse(type, source)` overload. Since `MapperService` is a public API consumed by plugins and other modules, removing the old signatures is a breaking change. If backward compatibility for plugin developers matters, consider keeping the old two-arg overloads that delegate with `MergeReason.MAPPING_UPDATE`, mirroring what was done in `MappingParser` and `MapperBuilderContext.root()`.
