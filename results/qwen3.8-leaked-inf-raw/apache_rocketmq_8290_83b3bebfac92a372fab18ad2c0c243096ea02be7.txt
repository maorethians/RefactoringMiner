#VHPYF, #SKH80: The static block correctly handles both IPv4 and IPv6 formatting based on the IP type, which is an improvement over the previous unconditional `ipToIPv4Str` call. However, if `UtilAll.getIP()` returns `null` (which is possible if no valid network interface is found), `UtilAll.isInternalIP(null)` will throw a `NullPointerException` during class initialization, causing an `ExceptionInInitializerError` that prevents `TraceBean` from ever being loaded. Consider adding a null guard or a fallback value (e.g., `"127.0.0.1"`) in the static block.

#XWXQ8: Two concerns with `getLocalInetAddressList()`:
1. **Redundant validation introducing a new dependency.** The `InetAddress` objects returned by `NetworkInterface.getInetAddresses()` are already valid, fully-parsed addresses. Converting them to a string via `UtilAll.ipToIPv4Str`/`ipToIPv6Str` and then validating that string with `InetAddressValidator` is circular — it will always succeed for a well-formed 4-byte or 16-byte array. This adds a dependency on `org.apache.commons.validator` (see #R9VNP) for no functional benefit. If the intent is to filter out link-local or otherwise unusable addresses, `UtilAll.isInternalIP` / `UtilAll.isInternalV6IP` (already used in `getLocalInetAddress()`) would be more appropriate and avoid the extra dependency.
2. **`InetAddressValidator.getInstance()` is called inside the per-interface loop.** Although it returns a singleton, it is cleaner and slightly more efficient to hoist it (or remove it entirely, per point 1) outside the loop.

#6R9TV: `getLocalAddress()` does not guard against `getLocalInetAddress()` returning `null`. The `getLocalInetAddress()` method catches all exceptions and falls through to `return null`. Calling `normalizeHostAddress(null)` will then throw a `NullPointerException` at `localHost.getHostAddress()` (since `null instanceof Inet6Address` is `false`). The old code had this call inside a `try-catch`, so the NPE was swallowed; the new code does not.
Suggested fix:
```java
public static String getLocalAddress() {
    InetAddress localHost = getLocalInetAddress();
    if (localHost == null) {
        return null;
    }
    return normalizeHostAddress(localHost);
}
```
