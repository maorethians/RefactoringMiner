#TVT9S, #8B94A, #MENEK, #H9DSH: Inconsistent implementation of the TEXT→KEYWORD conversion. `Max` uses the new `noText()` helper:
```java
return field().dataType().noText();
```
But `Min`, `Top`, and `Values` each duplicate the logic inline:
```java
DataType t = field().dataType();
return t == TEXT ? KEYWORD : t;
```
Since the `noText()` method was added to `DataType` specifically for this purpose, all four aggregate functions should use it uniformly. This avoids duplicating the mapping logic in multiple places and makes future changes (e.g., if another type needs similar treatment) a single-point edit.
