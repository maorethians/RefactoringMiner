#HY92G: Changing `platformLibDir` from `private` to `public` exposes an internal implementation detail to all callers. A `public static Path getPlatformLibDir()` accessor (or simply `public static Path platformLibDir()` following the existing naming convention in the class) would preserve encapsulation while still allowing `JnaNativeLibraryProvider` to read the value. This matters because `LoaderHelper` is a shared utility in `org.elasticsearch.nativeaccess.lib`; making the field public invites external code to depend on it directly, and any future refactoring (e.g., making it lazily computed or relocating the directory) would break all consumers.
