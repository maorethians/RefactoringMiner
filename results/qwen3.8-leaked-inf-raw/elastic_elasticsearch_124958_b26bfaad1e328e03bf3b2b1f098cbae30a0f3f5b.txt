#C078M: **Test method name is misleading**: The method is named `testUnclosedParenthesis`, but every test case actually exercises an *extra closing* delimiter (`)`, `]`, `]]`), not an unclosed one. A name like `testExtraClosingDelimiter` or `testUnexpectedClosingParenthesis` would more accurately describe what is being tested and avoid confusion for future readers.

#JZP5F: **Error message is generic**: `"Invalid query [{}]"` tells the user the query is invalid but not *why*. Since the root cause is specifically an unexpected closing delimiter (an `EmptyStackException` from popping an empty mode stack), a slightly more specific message such as `"Invalid query [{}]: unexpected closing delimiter"` would help users diagnose the problem faster without needing to inspect the query character by character. This is a minor UX improvement, not a blocker.
