#AYCXF: The new test exercises the `children.size() > 1` (array) branch with an empty nested object, but there is no test for the `children.size() == 1` branch where the single nested object is empty (all fields null). That path uses `b.field(leafName())` followed by `leafSourceLoader.write()`, which is a structurally different code path. A test like indexing a single `{"path": {"foo": null}}` document and asserting the synthetic source is `{"path":{}}` would cover this boundary.

#TRPN9, #SKRDQ: In `ObjectMapper.SourceLoader.write()`, there is an early `return` (visible in the context at line 843) that skips writing the object entirely. In the single-child branch of `NestedObjectMapper`, `b.field(leafName())` is written *before* `leafSourceLoader.write()` is called. If that early return is ever reached (e.g., a nested document exists in the `children` list but the source loader has no data to emit), the output would contain a dangling field name with no value, producing malformed JSON. In practice this may be unreachable because a child ID in the list implies the document was indexed, but a defensive guard (or an assertion) would make the invariant explicit and prevent a subtle regression if the early-return condition is ever broadened.
