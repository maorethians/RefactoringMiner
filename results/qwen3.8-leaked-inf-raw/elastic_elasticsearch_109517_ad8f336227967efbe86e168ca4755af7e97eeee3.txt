#CKTZJ: In the `CARTESIAN_SHAPE` test case, the WKT serialization was changed from `CARTESIAN.asWkt(...)` (original) to `GEO.asWkt(...)` (new). This appears to be a copy-paste error from the `GEO_SHAPE` block above. The `CARTESIAN` and `GEO` shape types use different coordinate systems and WKT representations, so serializing a cartesian geometry with `GEO.asWkt()` will produce incorrect output and likely cause the test to fail or compare against the wrong expected value.
The two occurrences in this hunk should be:
```java
new BytesRef(
    CARTESIAN.asWkt(
        randomValueOtherThanMany(g -> g.visit(pointCounter) > 500, () -> ShapeTestUtils.randomGeometry(randomBoolean()))
    )
)
```
