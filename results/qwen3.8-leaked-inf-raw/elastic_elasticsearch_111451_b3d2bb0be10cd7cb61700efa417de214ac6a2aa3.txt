#H4H4S: `prettyPrintList` maps elements with `Object::toString`, which will throw a `NullPointerException` if the list contains a `null` element. While unlikely in practice for query-result arrays, a safer mapping would be `String::valueOf`, which renders `null` as the string `"null"` instead of crashing:
```java
return "[" + list.stream().map(String::valueOf).collect(Collectors.joining(", ")) + "]";
```
This keeps the diagnostic output resilient even if a future matcher is applied to a collection that may contain nulls.
