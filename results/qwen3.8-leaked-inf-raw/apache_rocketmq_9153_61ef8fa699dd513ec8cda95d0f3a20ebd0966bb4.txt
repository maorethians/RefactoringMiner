#PD503: `updateTopicList` appends a trailing separator after every element, producing a string like `"topic1;topic2;"`. While `StringUtils.split` in `fetchTopicList()` tolerates the trailing delimiter (it ignores trailing empty tokens), this is fragile and makes the wire format harder to reason about. A cleaner approach:
```java
public void updateTopicList(List<String> topicList) {
    if (topicList == null || topicList.isEmpty()) {
        return;
    }
    this.setTopicList(String.join(TOPIC_NAME_SEPARATOR, topicList));
}
```
This avoids the trailing separator entirely and also short-circuits on an empty list instead of setting the field to `""`.
