#VQQS7: In the `id == null` branch (async request completed immediately without `keep_on_completion`), the assertion checks the wrong header name:
```java
assertNull(response.getHeader("is_running"));
```
The `else` branch correctly uses `"X-Elasticsearch-Async-Is-Running"`, and the async API's standard status header is `X-Elasticsearch-Async-Is-Running`. The header `"is_running"` (lowercase, no prefix) is a JSON body field, not a response header, so this assertion will always pass trivially and does not actually verify that no async status header was returned. It should be:
```java
assertNull(response.getHeader("X-Elasticsearch-Async-Is-Running"));
```
