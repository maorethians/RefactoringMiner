#K8EYZ, #91WK9: The test uses `randomIdentifier()` for the third shard's index name:
```java
final var s3ContextShard3 = dummyContext(snapshotId3, laterStartTime, randomIdentifier(), 1);
```
The expected order assumes this name sorts after `"later-index-name"`, but `randomIdentifier()` can produce any alphanumeric string (e.g., `"a"`, `"B"`, `"0"`), which would sort before `"early-index-name"`. Since `ShardId.compareTo` compares index name first, this makes the test non-deterministic and flaky. Replace it with a fixed string that is guaranteed to sort after `"later-index-name"`, such as `"zzz-index-name"`.
