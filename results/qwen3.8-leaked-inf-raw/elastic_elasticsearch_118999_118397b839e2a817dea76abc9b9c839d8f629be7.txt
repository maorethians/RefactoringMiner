#NMVJ7: In `execAsyncCall`, the `responseConsumerCallback` is invoked inside the `ResponseListener.onSuccess` callback:
```java
public void onSuccess(Response response) {
    if (responseConsumerCallback != null) {
        responseConsumerCallback.accept(response);
    }
    latch.countDown();
}
```
If the consumer throws (e.g., `assertThat` fails with an `AssertionError`), `latch.countDown()` is never reached and the test will block indefinitely on `latch.await(...)` until the test framework's global timeout fires. Consider wrapping the callback invocation in a try/catch that stores the exception and re-throws it after `latch.countDown()`, or at minimum call `latch.countDown()` in a `finally` block so the test thread can surface the real failure:
```java
public void onSuccess(Response response) {
    try {
        if (responseConsumerCallback != null) {
            responseConsumerCallback.accept(response);
        }
    } finally {
        latch.countDown();
    }
}
```
This is low-severity (test-only code) but will make debugging a failed header assertion much less painful.
