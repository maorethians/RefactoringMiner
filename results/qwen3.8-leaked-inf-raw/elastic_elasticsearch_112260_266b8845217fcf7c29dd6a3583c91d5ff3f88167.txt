#QN7D1, #MS4BT, #6F21Q: The refactoring from a `volatile` array with double-checked locking to a `ConcurrentHashMap` with `putIfAbsent` is a clean improvement in clarity and thread-safety. One minor observation: in the rare race where two threads simultaneously call `putIfAbsent` for the same `ctx.id()`, both will invoke `storedFieldLoader.getLoader(ctx, null)` and construct a `LeafStoredFieldSourceProvider`, but only one is retained. If `getLoader` is ever expensive or has side effects, the discarded instance is wasted work. In practice this is almost certainly negligible, but worth being aware of.

#M2TAC: The test indexes `field1` values directly into the document source while also declaring `field1` as a runtime field with no `script` definition. This is a valid scenario to exercise, but the test name `testWithRuntimeMapping` is slightly broad. Consider whether the test should also verify that the runtime field is actually being used for the DLS filter (e.g., by asserting a different result when the runtime field definition is removed), to make the test's intent more explicit and guard against it passing for the wrong reason.
