#FE8K2: In `testRemainingTime`, the first assertion is:
```java
assertThat(remainingTime.get(), Matchers.greaterThan(TimeValue.ZERO));
```
This only verifies the value is positive, which would still pass if the clock advanced by 29.99 s between the two `Instant.now()` calls (extremely unlikely, but the assertion doesn't pin the expected magnitude). A tighter bound such as `greaterThan(TimeValue.timeValueSeconds(29))` would make the test's intent clearer and catch a regression where, say, the timeout is accidentally set to 1 s instead of 30 s.
