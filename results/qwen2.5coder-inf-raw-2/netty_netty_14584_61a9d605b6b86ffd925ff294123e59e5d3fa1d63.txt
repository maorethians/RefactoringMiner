#C88WT: The use of `Math.min(2, ...)` limits the `CENTRAL_QUEUE_CAPACITY` to a maximum value of 2, which might be too restrictive given that it is based on the number of available processors (`NettyRuntime.availableProcessors()`). This could lead to performance bottlenecks if the system has more than two processors and the allocator needs to handle more concurrent requests. Consider whether this limit is necessary or if a higher default value should be used.
