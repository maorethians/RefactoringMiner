#BCR52, #09SM0: The logic for marking fields as containing copied data has been moved from `IgnoredSourceFieldMapper#postParse` to `DocumentParserContext#createCopyToContext`. This change is intended to ensure that ignored source values take precedence over standard synthetic source implementation, preventing duplicate values in copied fields after reindexing. However, the removal of the loop that processes `context.getCopyToFields()` in `IgnoredSourceFieldMapper#postParse` might lead to a loss of functionality if there are copy-to fields that were not initially added to `ignoredFieldValues`.
