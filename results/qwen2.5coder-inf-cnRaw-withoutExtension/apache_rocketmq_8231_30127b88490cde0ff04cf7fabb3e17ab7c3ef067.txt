#HB7JH, #KE236, #QR74G, #0R09S: The addition of `StringUtils.isNotBlank(request.getGroup().getName())` checks for a non-blank group name before adding it to the access resource or context. This is a good practice to avoid processing empty or null group names, but it assumes that `request.getGroup()` can never be null itself. If there's a possibility that `request.getGroup()` could be null, this check should also include a null check to prevent potential NullPointerExceptions.
