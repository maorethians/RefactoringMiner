#H9HS1, #P1YFQ: The `limit` field is set to `null` when deserializing from a `StreamInput`, and there's an assertion that `limit == null` when writing to a `StreamOutput`. This might be intentional if the limit is only needed on the coordinator node, but it should be clearly documented. Additionally, this could lead to issues if the limit is ever set and needs to be serialized.

#X7MHK: The tests assume a default limit of 1000, which should be clarified or parameterized to avoid hardcoding values.
