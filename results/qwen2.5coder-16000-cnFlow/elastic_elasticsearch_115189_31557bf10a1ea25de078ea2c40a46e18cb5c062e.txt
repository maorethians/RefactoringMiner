#ZZ2A4, #NMYD8: The logic change in `isEmpty` method from checking `totalTargetAllocations()` to `getNumberOfAllocations()` might not be correct. The original check was summing up all target allocations across model assignments, while the new check is only verifying if the number of allocations requested by the user for each assignment is zero. This could lead to incorrect behavior if there are multiple model assignments with non-zero target allocations but each has a `numberOfAllocations` of zero.
