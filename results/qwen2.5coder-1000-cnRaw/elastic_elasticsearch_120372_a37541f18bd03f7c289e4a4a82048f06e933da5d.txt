#PWMWN: The logic for adding `IndexResolver.INDEX_METADATA_FIELD` to `fieldNames` is incorrect. The current implementation unconditionally adds `IndexResolver.INDEX_METADATA_FIELD` as a string, which will result in an error since `fieldNames` is a set of strings and `IndexResolver.INDEX_METADATA_FIELD` is expected to be a single field name. This should be added only if `fieldNames` is empty after all other fields have been collected.
