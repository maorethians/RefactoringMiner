#XPRE6, #QQYA4, #9M17H, #MJYS6, #YTAZT, #NKFJP, #C2NX9, #007SN, #JSBWW, #QF3CZ, #HC6VG, #H1AJ3, #ECM0R, #FY2F8, #3EPMG, #S1DAF, #CECJZ, #40HEG, #NB5P9: The changes introduce `EntityUtils.consumeQuietly` to ensure resources are released after processing HTTP entities. This is generally a good practice to prevent resource leaks. However, the introduction of `assertOKAndConsume` and modifying methods like `putTransform`, `deleteTransform`, etc., to use `assertAcknowledged` instead of `assertOK` might not be consistent with the expected behavior in all cases. For instance, `assertOK` checks for status codes 200 or 201, while `assertAcknowledged` expects a JSON response containing `"acknowledged":true`. This change could lead to unexpected failures if the response does not contain this field.

#JSBWW, #QF3CZ: The methods `putTransform(String id, String config, RequestOptions options)` and its overloaded version `putTransform(String id, String config, boolean deferValidation, RequestOptions options)` have been changed from returning a `Response` to void. This change might break any code that relies on the response for further processing or validation.
